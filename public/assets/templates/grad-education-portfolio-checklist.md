# 教育類備審 Checklist（CV、自傳與研究計畫分工）

> 教育類群備審要證明的是「教育實務 × 學術潛力」，而最常見的失敗是三份文件寫成同一份經歷流水帳。這份 Checklist 帶你完成經驗盤點、CV 欄位、每段經歷該寫出的七件事、推薦信素材，最後做一致性檢核。
>
> **匯入 Notion**：Import → Markdown。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 一、三份文件的分工

| 文件 | 核心任務 | 讀者看完該知道 |
|---|---|---|
| CV | 列事實 | 我做過哪些事 |
| 自傳 | 講軌跡 | 我是怎麼走到現在的方向 |
| 研究計畫 | 寫未來 | 我進去之後要做什麼 |

- [ ] 同一段經歷在三份文件裡做的事不同（CV 是一行事實／自傳是一段轉折／計畫是執行能力的證據）
- [ ] 三份文件沒有大段重複

## 二、經驗盤點表

| 經歷 | 單位與對象 | 期間與頻率 | 我的身分與職責 | 具體處理的問題 | 我的判斷與作法 | 結果與反思 | 指向的研究問題 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

> 後三欄（判斷與作法、結果與反思、指向的研究問題）是多數人漏掉的部分，也是「實務熱忱」與「研究潛力」的分水嶺。只寫到「身分與職責」的經歷，是服務紀錄；寫到最後一欄的，才是研究動機的來源。

## 三、教育類學術 CV 欄位

依實際狀況取捨與排序，最強的放前面。

- [ ] 基本資料與申請方向（目標次領域）
- [ ] 學歷與在校表現（系排／班排，有優勢才列）
- [ ] 相關核心修課（教育學、心理學、統計、研究方法、課程與教學、輔導或特教專業科目）
- [ ] 教育現場經驗（單位、期間、對象、身分、實際負責的事）
- [ ] 輔導與諮商相關經驗（注意去識別化）
- [ ] 實習經驗（單位、期間、內容、督導）
- [ ] 專題與研究經驗（題目、指導教授、方法、我負責的部分、成果形式）
- [ ] 大專生研究計畫或補助（名稱、年度、角色）
- [ ] 研究方法能力（質性訪談、課室觀察、問卷設計、統計軟體、質性分析工具——具體列）
- [ ] 獎項與證照
- [ ] 研習與工作坊（與目標次領域直接相關的才列）
- [ ] 其他技能（教材製作、數位工具、簡報、外語）

**寫法檢核**

- [ ] 沒有形容詞與感想（「深刻體會偏鄉教育困境」是雜訊）
- [ ] 每一行都有可查證的事實（單位／期間／頻率／對象／規模）
- [ ] 一到兩頁，分類清楚可快速掃讀

## 四、自傳：選三段寫成一條線

| 段落 | 要寫什麼 | 我選的經歷 |
|---|---|---|
| 第一段 | 最早接觸現場、產生初步困惑 |  |
| 第二段 | 問題重複出現、開始有意識觀察 |  |
| 第三段 | 嘗試處理或深入理解、發現需要更專業的訓練 |  |

**要避免的寫法**

- [ ] 從小立志當老師的故事
- [ ] 一整段對教育現況的抒發
- [ ] 每段經歷平均分配篇幅
- [ ] 用「深刻體會」「獲益良多」取代具體判斷

## 五、讀書計畫的系所連結

- [ ] 想處理的問題與階段規劃
- [ ] 想修的課、想補強的方法能力
- [ ] 該所的課程、研究中心、實習場域、合作學校（要寫得出具體名稱與內容）
- [ ] 需要的實務資源與取得方式
- [ ] 哪位教授或研究中心與計畫最相關

> **遮名字測試**：把系所名字遮起來，這份讀書計畫還能投給別所嗎？可以的話，就還沒寫完。

## 六、推薦信素材

- [ ] 一頁摘要（申請校所與次領域、研究方向一段話、希望這封信著重的能力）
- [ ] 具體事蹟三則（他親自看過的事）
- [ ] 我的 CV 與研究計畫摘要
- [ ] 時程與繳交方式（截止日、系統流程、是否需他自行上傳）
- [ ] 組合：學術推薦人一位＋現場推薦人一位
- [ ] 提早三到四週提出請求（中小學現場老師學期中非常忙）

## 七、送件前一致性檢核

- [ ] CV、自傳與計畫各司其職，沒有大段重複
- [ ] 自傳裡的實務經歷連成一條通往研究計畫的線
- [ ] 我能具體說出現場的教學痛點、政策問題或輔導困境
- [ ] 讀書計畫對準了該所的實務資源、研究中心或教授專長
- [ ] 我能回答「為什麼非這間不可」
- [ ] 只有熱忱、沒有能力證據的空泛陳述已刪除
- [ ] 涉及個案或特定學生的內容全部去識別化
- [ ] 各文件裡的期間、單位、身分一致
- [ ] 沒有誇大身分（協助≠主導、觀摩≠教學）

## 送出前檢核

- [ ] 每段經歷都寫出了現場、角色與具體事件
- [ ] 自傳的三段連成一條線，不是三件事並列
- [ ] 研究計畫的問題來自我寫下的某個現場
- [ ] 涉及學生或個案的內容已去識別化
- [ ] 讀書計畫連得到該系所的實際課程與師資
- [ ] 推薦人能具體描述我在現場的表現
