# 創作母題發展與研究計畫模板（藝術研究所）

> 藝術研究計畫不是感性描述，也不是替創作外掛理論，而是一份把既有創作往前延伸的工作計畫。先用第一節從作品裡辨認母題，再用第二節的十節提綱寫，最後用可行性檢核確認這兩年做得完。
>

> **用 Google Docs / Sheets**：表格可直接貼上。

## 一、作品盤點與母題辨認

母題不是宣告出來的，是從作品裡被辨認出來的。先把做過的作品全部攤開再說。

| 作品名稱 | 年份 | 媒材／形式 | 當時想處理什麼 | 事後回看，它其實在處理什麼 | 屬於哪個系列 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

填完後回答：

- 反覆出現的主題／材料／形式是什麼？
- 哪一件是這條線的起點？
- 哪一件之後方向改變了？為什麼？
- 哪裡有缺口——需要補一件作品才接得起來？

> 檢查：把你的母題敘述換成任何一位同學的名字，還成立嗎？「我關注人與環境的關係」放在誰身上都對，那它還不是問題意識，只是題材類別。

## 二、十節計畫提綱

字數限制較嚴時，優先保留 2、3、5、6、7 節。

| 節次 | 要回答什麼 | 我的內容 |
|---|---|---|
| 1. 創作背景 | 從哪裡開始創作、目前的實踐狀態 |  |
| 2. 問題意識 | 持續在處理什麼問題（整份計畫的軸） |  |
| 3. 創作母題 | 問題長成什麼母題、出現在哪些作品 |  |
| 4. 相關藝術家與文獻 | 誰在處理相近問題、我和他們的差別 |  |
| 5. 既有作品脈絡 | 過去作品的發展順序與各自的位置 |  |
| 6. 媒材與方法 | 為什麼是這個媒材、技術如何服務概念 |  |
| 7. 未來創作計畫 | 分幾階段、各階段解決什麼問題 |  |
| 8. 展示與觀者關係 | 空間、尺度、時間長度、觀者位置 |  |
| 9. 預期成果 | 作品量、形式、展覽或發表規劃 |  |
| 10. 可行性與時程 | 製作週期、設備、成本、風險與備案 |  |

> 第 5 節最常被省略，卻是藝術類群差最多的一節。沒有既有作品脈絡的計畫，等於要教授相信一個他沒看過證據的承諾。

## 五、送出前檢核

- [ ] 計畫延續既有作品，能指出至少兩件作品作為線索
- [ ] 清楚說明媒材與形式的選擇理由，不只是描述用了什麼
- [ ] 能指出相關藝術家或理論脈絡，並說明自己與他們的差別
- [ ] 提出具體可執行的創作方法，而不只是預期成果
- [ ] 評估過製作時間、設備需求與材料成本
- [ ] 能在碩士修業年限內完成
- [ ] 這一版已針對投遞的校所調整資源與對話對象
- [ ] 給一位不熟悉我創作的人讀過，他說得出「我這兩年打算做什麼、怎麼做」
