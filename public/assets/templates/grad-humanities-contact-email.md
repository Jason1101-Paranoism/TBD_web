# 人文社科聯繫教授信結構模板

> 人文社科不是每一種申請都需要事前聯繫教授。先用第一節判斷該不該寄，再用第二節的七段結構寫，最後用檢核表確認不要寄出一封群發罐頭信。
>
> **匯入 Notion**：Import → Markdown。
> **用 Google Docs**：可直接貼上。

## 一、先判斷：這封信該不該寄

### 適合主動聯繫

- [ ] 研究題目高度專門
- [ ] 需要特殊語言、史料或檔案能力
- [ ] 研究方法與教授專長高度相關
- [ ] 希望確認教授是否仍收學生
- [ ] 教授的研究計畫與我的題目直接相關
- [ ] 我手上有成熟的文字作品或研究成果可供參考

### 不適合聯繫

- [ ] 只想詢問錄取機率
- [ ] 沒有讀過教授的研究
- [ ] 信件內容只有自我介紹與崇拜
- [ ] 使用群發模板
- [ ] 研究方向仍完全不清楚
- [ ] 校所明確採統一招生且不鼓勵事前聯繫

> 上面兩組各勾幾項？「適合」欄勾到兩項以上、且「不適合」欄一項都沒勾，才建議寄。

## 二、七段信件結構

| 段落 | 要寫什麼 | 我的內容 |
|---|---|---|
| 1. 簡短自我介紹 | 校系、年級、姓名，兩行以內 |  |
| 2. 目前的研究興趣 | 研究對象＋大致取徑，不要只寫領域 |  |
| 3. 已完成的文字作品或專題 | 題目、材料、方法、結論各一句 |  |
| 4. 與教授研究的具體連結 | 讀過哪一篇、哪個觀點與我的問題相關 |  |
| 5. 一個明確且必要的問題 | 只問一個，且要是他才答得出來的 |  |
| 6. 附件說明 | CV、研究摘要或代表作，列出檔名 |  |
| 7. 禮貌結尾 | 感謝＋不強求回覆 |  |

## 三、寫作原則：把「有興趣」換成具體內容

不要只寫：

> 我對老師的研究很有興趣。

要具體說明四件事：

1. 看過哪一篇研究（篇名或主題）
2. 哪個觀點與自己的問題相關
3. 自己想從何處延伸
4. 為什麼需要向這位教授請教

## 四、寄信前檢核

- [ ] 信件長度控制在螢幕一頁內，細節放附件
- [ ] 全信只有一個明確問題，且不是「老師會不會收我」
- [ ] 提到的教授研究是我真的讀過的，篇名與論點沒有寫錯
- [ ] 附件檔名清楚（姓名_學校_文件類型）
- [ ] 附件內容與信中敘述一致
- [ ] 收件人姓名、職稱、系所沒有沿用上一封信
- [ ] 避開九月開學後的教學與行政高峰
- [ ] 沒有回覆時，最多禮貌追蹤一次
