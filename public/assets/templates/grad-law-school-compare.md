# 校所、研究取向與教授比較表（法政研究所）

> 法政類群同一個系所裡，不同教授的研究取向可能天差地別——實體法與程序法、規範法學與實證法學、政治理論與量化政治分析、公共政策理論與政策評估、比較政治與國際關係，訓練出來的是不同的人。所以選教授不能只看名字或校所排名，要看「研究什麼」與「怎麼研究」兩件事是否都對得上。

## 陷阱檢核

- [ ] **題目相同 ≠ 方法相同**：同一個法制爭議，用判決分析、比較法或量化政策評估來處理，是三種完全不同的學術訓練。我確認過自己想用的方法與教授的專業相容。
- [ ] **教授知名 ≠ 帶得動我的題目**：我讀過他近五年的實際產出，不是只看職稱與知名度。
- [ ] **系所有名 ≠ 這一組適合我**：法政系所常分組（例如公法組、財經法組、國際關係組、政策組），組別的必修結構與師資才是你實際會遇到的訓練。
- [ ] 價值立場的相容性已評估過（立場可以不同，但要能被理解）
- [ ] 同一個組名在不同學校範圍可能不同，已逐校確認

## 填完後檢核

- [ ] 題目和教授研究什麼一致
- [ ] 方法和教授怎麼研究一致
- [ ] 查過教授近五年期刊論文與研究計畫
- [ ] 確認教授當年度實際可收學生（沒有退休、借調或已收滿）
- [ ] 保留三到五所，其中至少一所在方法與指導關係上明確可行（那是底線選項）

## 查證管道

| 查證管道 | 說明 |
|---|---|
| 當年度招生簡章 | 組別名額、筆試科目與書審佔比每年會調整，一律以此為準 |
| 臺灣博碩士論文知識加值系統 | 每位目標教授看三到五本論文的摘要與目次 |
| 臺灣期刊論文索引系統 / Google 學術搜尋 | 查近五年期刊論文；看引用了誰就知道他的學術社群 |
| 國科會研究計畫資料庫 | 查教授近年主持的計畫 |
| 系所公告與現任學生 | 退休、借調、收生名額與指導方式 |

> 查法提示：教授的個人頁面告訴你他「想被看見的樣子」，但**近五年的實際產出才是準的**。法政研究範疇會隨修法、釋憲、政治環境與學術趨勢快速變動，五年前的專長頁面可能早已不是他現在在做的事。期刊論文與研究計畫可用 Google 學術搜尋與「臺灣期刊論文索引系統」（tpl.ncl.edu.tw）查；碩博士論文可在國家圖書館「臺灣博碩士論文知識加值系統」（ndltd.ncl.edu.tw）以校所或教授姓名檢索，多數看得到摘要與目次。看論文時順便看他引用了哪些人——那組名字就是他所屬的學術社群，也是你未來要對話的對象。
