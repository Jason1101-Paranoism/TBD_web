faqItems:
  - q: 排名比較好的學校，但實驗室資源普通；排名普通的學校，但實驗室資源好——怎麼選？
    a: 在這個類群，多數情況下選資源。原因很具體：你的碩士論文需要的儀器、耗材與樣區，是由實驗室的計畫經費決定的，不是由校名決定的。一間有穩定計畫經費、儀器能排得到、樣區進得去的實驗室，會讓你兩年做得完；反過來則可能面臨題目被迫縮水或延畢。但有兩個例外值得考慮：如果你的職涯方向明確需要某個校名的門檻（例如特定公部門或國外博班的申請），或該校有你要的跨領域資源（例如生物資訊的運算叢集），那校名的權重會提高。判斷的方式是回到「我畢業時要帶著什麼離開」，而不是入學時的名次。
  - q: 怎麼問得到實驗室的真實狀況，而不是官網上的版本？
    a: 最有效的來源是現在或剛畢業的學長姐，其次是實驗室的近期論文與計畫清單。問學長姐時避免問「這個實驗室好不好」——這種問題只會得到客套答案。改問可驗證的事實：最近兩年碩士生平均幾年畢業、有沒有人延畢與原因、耗材需要自己想辦法嗎、儀器排得到嗎、教授大概多久跟你討論一次、假日進實驗室是常態還是選項。論文與計畫清單則能看出經費是否連續、方向有沒有變。如果完全問不到人，這件事本身就是一個訊號。
  - q: 教授的研究方向和我想做的不完全一樣，還能申請嗎？
    a: 可以，但要先分清楚差多遠。如果是同一套技術與材料、不同的題目，通常可行——你進去之後多半會在教授現有的計畫架構裡找一個切入點。如果是不同的技術體系或完全不同的生物材料，風險就高：實驗室不會為了一個碩士生建立一條新的技術線，而你也很難在兩年內自己建起來。實務上的判斷方式是看教授近三年的論文用了哪些方法與材料，問自己「我的題目能不能用這些做出來」。答案是否定的，就要考慮換一個切入點，或換一間實驗室。

<section class="article-section" id="three-layers">
## 領域、實驗室、教授三層

農生與環境類群的研究所選擇，建議照這個順序收斂：

**領域 → 實驗室 → 指導教授**

先確定領域，是因為這個類群底下的日常差異極大。分子生物的日子是在無菌操作台、PCR 機與冰箱之間；生態或環境監測的日子有一大半在樣區、在車上、在等天氣；農藝的節奏跟著作物的期作走；生物資訊則多半在終端機前面。這四種生活型態沒有優劣，但選錯會很痛苦，而且入學後很難改。

接著才是實驗室，最後才是教授個人。這個順序常被反過來——先看到某位教授的論文很吸引人，才回頭找他在哪。問題是**教授的研究能不能執行，取決於他實驗室現在有什麼**，而不是他過去發表過什麼。

一個實用的檢查：把你想做的題目寫成一句話，然後問「這句話需要哪些條件才成立」。條件清單會直接告訴你要找哪一種實驗室。
</section>

<section class="article-section" id="not-ranking">
## 為什麼不能只看排名

這個類群的研究日常，是由一組很具體的東西構成的：

- 硬體設備與儀器
- 生物材料的生長週期
- 計畫經費（耗材、定序、抗體都很貴）
- 溫室、農場或試驗田
- 野外樣區與進場許可
- 田調的交通與安全支援

這些東西**跟著實驗室走，不跟著校名走**。同一所學校裡，兩間隔壁的實驗室資源可能差一個量級。

如果進到一間經費不足、缺少指定儀器、耗材要自己想辦法、沒有穩定樣區或田調交通不足的實驗室，實際會發生的是：

- 題目被迫縮水，但已經來不及換
- 實驗排不到機台，進度整段停住
- 樣本或樣區取得失敗，成果做不完
- 最後延畢

這不是危言聳聽，而是這個類群裡相當常見的卡關樣態。而且它有一個特性：**你通常要到進去之後才會發現**，那時候換題目的成本已經很高了。

所以排名在這個類群仍然有參考價值（它多少反映整體資源與同儕水準），但它的權重應該低於「這間實驗室現在能不能支持我的研究」。
</section>

<section class="article-section" id="questions">
## 三個必問的評估問題

### 1. 經費與硬體是否足夠

> 這個實驗室的計畫經費是否足以支持我的研究所需——定序、抗體、高階儀器時數，或田野調查的交通與安全裝備？

判斷方式不是直接問教授「你有沒有錢」，而是看**近三年的計畫清單與論文產出**。連續有計畫、論文用得起昂貴方法，通常代表經費穩定。反過來，如果近幾年產出稀疏或方法明顯轉向低成本，可能正在經費空窗。

### 2. 實驗室的生活型態適不適合我

> 照顧細胞、動植物或進行野外採樣的週期，符合我的生活步調嗎？教授對假日進實驗室、長期駐點野外的態度是什麼？

這是農生環境**最容易被忽略、卻最影響兩年品質**的契合度。細胞要餵、菌要接、苗要澆、樣區的季節不等人——這些工作沒有辦法配合你的行事曆。有些實驗室輪值制度完善，有些則預設你自己排開。先問清楚，不要進去之後才發現作息無法承受。

### 3. 畢業狀況與職涯出口符合期待嗎

> 這個實驗室近幾年的碩士生是否都能在兩年內畢業？畢業生的去向，跟我想走的生技產業或環境公部門對得上嗎？

畢業時間是最誠實的指標之一。如果連續幾屆都延畢，原因通常是結構性的——題目太大、資源不足、或指導節奏太鬆。這件事問學長姐比看官網準確得多。
</section>

## 實驗室比較表怎麼填

把候選實驗室放進同一張表，差異才會浮出來。建議至少填三間：

| 項目 | 實驗室 A | 實驗室 B | 實驗室 C |
|---|---|---|---|
| 研究領域與近三年方向 |  |  |  |
| 計畫經費（連續性、來源） |  |  |  |
| 高階儀器（自有／共用／要排隊） |  |  |  |
| 實驗耗材（實驗室支應／自付） |  |  |  |
| 田野樣區（穩定性、可進入季節、交通） |  |  |  |
| 生活節奏（假日、輪值、駐點） |  |  |  |
| 教授指導風格（頻率、放養或緊迫） |  |  |  |
| 近三年碩士生畢業狀況 |  |  |  |
| 畢業生去向 |  |  |  |
| 契合度總評 |  |  |  |

填表時有兩個提醒：

- **空白格本身就是資訊**。查不到經費、問不到畢業狀況，代表這間實驗室的資訊透明度低，那是一個需要納入判斷的事實，不是「還沒查完」。
- **不要只填優點**。每一間都寫出一個你最擔心的地方，比較才有意義。三間都完美通常代表你查得不夠深。
</section>

<section class="article-section" id="verify">
## 資訊從哪裡查得到

- **近三年論文**：看方法、材料與作者序，判斷技術線與碩士生的參與程度。
- **計畫清單**：多數實驗室網頁或教授個人頁面會列，看得出經費的連續性。
- **系所的碩士論文庫**：翻近幾屆的題目與完成年份，可以推出畢業節奏與題目規模。
- **學長姐**：最有效但也最需要問對問題——問可驗證的事實，不要問「好不好」。
- **實驗室參訪或旁聽 meeting**：如果有機會，這是判斷生活型態最直接的方式。

把三層收斂完、比較表填完之後，下一步是[聯繫教授](/pages/resources/graduate-contact-professor.html)，並開始把[研究計畫](/pages/resources/agriculture-graduate-proposal.html)寫給你選定的那組資源條件。
</section>
