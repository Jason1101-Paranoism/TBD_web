## 節次架構

| 節次 | 要回答的問題 | 常見失分 | 我的重點 | 完成 |
|---|---|---|---|---|
| 1 研究背景 | 這個領域現在的狀況 | 寫成文獻回顧而不是研究設計 |  |  |
| 2 問題意識 | 你要解決什麼具體問題 | 問題範圍太寬沒有聚焦 |  |  |
| 3 研究目的或假設 | 目的或假設是否明確可驗證 | 假設不可檢驗 |  |  |
| 4 文獻缺口 | 既有研究還沒回答什麼 | 只摘要文獻沒指出缺口 |  |  |

## 生醫檢核

- [ ] 聚焦特定分子機轉或明確生物問題
- [ ] 實驗設計有正負對照組
- [ ] 說明樣本細胞動物檢體來源
- [ ] 有替代實驗方案
- [ ] 時程能在碩士階段完成
- [ ] 已考量 IRB／IACUC／生物安全規範且時程已算進去
- [ ] 需要的設備與技術能力已確認可取得

## 公衛檢核

- [ ] 研究問題具體可回答不是模糊的觀察
- [ ] 母群體與樣本來源合理且具代表性
- [ ] 變項操作化清楚可測量
- [ ] 統計方法能回答研究問題
- [ ] 已考量偏差混淆與資料缺失
- [ ] 能取得足夠樣本且符合倫理與隱私規範

## 常見失分點自我對照

- [ ] 寫成文獻回顧而不是研究設計
- [ ] 只寫順利的版本沒有談障礙
- [ ] 規模過大碩士兩年做不完
- [ ] 強調引用但缺乏具體方法
