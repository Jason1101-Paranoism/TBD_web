# 文字作品選件與備審 Checklist（人文與社會科學研究所）

> 人文社科備審要證明的是：申請者已經開始學習如何閱讀、提問、論證與寫作。這份模板分四段：作品選件評估、學術 CV 欄位、自傳要素、五份文件分工。
>
> **匯入 Notion**：Import → Markdown 後，表格可切換成資料庫。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 一、文字作品選件評估表

把候選作品全部列出來，逐項評分（1–5），再決定送哪一到兩份。

| 評估項目 | 作品 A | 作品 B | 作品 C |
|---|---|---|---|
| 作品名稱與性質（課堂報告／專題／論文／評論／田野紀錄） |  |  |  |
| 字數與完成時間 |  |  |  |
| 問題是否清楚（一頁內看得出在問什麼） |  |  |  |
| 論證是否完整（有主張、證據、推論） |  |  |  |
| 是否展現文獻運用 |  |  |  |
| 是否展現一手材料處理 |  |  |  |
| 與研究計畫方向的連結 |  |  |  |
| 有無教師回饋與修改歷程 |  |  |  |
| 是否代表目前最高寫作水準 |  |  |  |
| 我能不能為其中每個判斷辯護 |  |  |  |
| 總評與是否送件 |  |  |  |

> 選件原則：**不建議只因為分數高就選入**。與申請方向無關、論證薄弱或本質上只是資料彙整的作品，價值有限；而且教授會針對作品追問，選一份自己撐不住的，等於給自己挖坑。若送兩份，讓它們展示不同能力，不要兩份同類型。

### 送件前的作品處理

- [ ] 重讀一次並修訂論證薄弱的段落
- [ ] 把問題重寫成明確的問句
- [ ] 把文獻段從摘要改寫成觀點對話
- [ ] 統一注釋與參考書目體例
- [ ] 附一頁摘要：問題、材料、方法、結論
- [ ] 若有修訂歷程，簡述改了什麼與為什麼

## 二、學術 CV 欄位檢核

| 欄位 | 有無 | 內容重點 |
|---|---|---|
| Education 學歷 |  | 校系、期間、學業表現（有優勢再放） |
| Research Interests 研究興趣 |  | 兩到三行，要能看出研究主軸 |
| Research Experience 研究經歷 |  | 專題、大專生計畫、研究助理、田野 |
| Selected Coursework 相關修課 |  | 只列與研究方向相關的課 |
| Projects 專題與計畫 |  |  |
| Publications／Presentations 發表與研討會 |  | 有才列 |
| Writing Samples 文字作品 |  | 標題、性質、字數、指導老師 |
| Fieldwork／Survey Experience 田野或調查 |  |  |
| Language Skills 語言能力 |  | 外語檢定、古文獻或研究語言閱讀能力 |
| Research Methods 方法訓練 |  | 方法課、統計或質性軟體 |
| Awards 獎項 |  |  |
| Activities 活動 |  | 只保留與研究方向相關的 |

> 排序原則：研究相關的往前，其餘往後或刪掉。**Language Skills 與 Research Methods 在人文社科特別重要，卻最常被漏掉。**
>
> 唯一的總檢核：教授掃過三十秒，看不看得出你的研究主軸？

## 三、自傳要素

| 要素 | 我的內容 |
|---|---|
| 研究興趣如何形成 |  |
| 哪些課程、文本或經驗帶來轉折 |  |
| 如何從興趣走向問題 |  |
| 如何累積閱讀與研究能力 |  |
| 為何選擇此校所（具體到取徑與教授） |  |
| 未來想深入處理什麼問題 |  |

> 「轉折」最常被寫掉，卻最關鍵。「我從小喜歡歷史」不是轉折；「讀到某本書後發現原本的理解是錯的，於是開始追這條線」才是。轉折能證明你會被材料改變想法。

## 四、五份文件分工

| 文件 | 負責證明什麼 | 是否已避免與其他文件重複 |
|---|---|---|
| CV | 快速呈現學術經歷與能力證據 |  |
| 自傳 | 說明研究興趣如何形成 |  |
| 研究計畫 | 展示未來想處理的問題 |  |
| 文字作品 | 直接證明閱讀、分析與論證能力 |  |
| 推薦信 | 由教師證明學術態度與研究潛力 |  |

### 推薦信素材包（給推薦人）

- [ ] 研究方向與研究計畫摘要
- [ ] 代表作（含一頁摘要）
- [ ] 修課紀錄與在該課的具體表現
- [ ] 申請校所清單與各校截止時間
- [ ] 送出方式與系統連結

## 五、送件前的五個檢核問題

- [ ] CV 是否能在三十秒內看出研究主軸？
- [ ] 文字作品是否真正代表目前最高水準，而不是分數最高？
- [ ] 自傳是否呈現從興趣到研究問題的轉變？
- [ ] 各份文件是否互相支持，而非重複相同內容？
- [ ] 是否已完成作品修訂、摘要撰寫與引用格式整理？

## 常見失分點自我對照

- [ ] 文字作品選件依成績而不是依研究方向
- [ ] 作品沒有經過送件前的修訂，仍是課堂報告的樣子
- [ ] CV 把課程報告寫成研究成果
- [ ] 自傳寫成個人興趣陳述，看不出學術軌跡
- [ ] 研究計畫的取徑在文字作品裡看不到對應
- [ ] 推薦人給的素材不足，信件寫不出具體內容

## 送出前檢核

- [ ] 文字作品是依研究方向挑的，不是依成績
- [ ] 作品送件前修訂過，不是課堂報告原樣
- [ ] CV 沒有把課程報告寫成研究成果
- [ ] 自傳看得出學術軌跡，不是興趣陳述
- [ ] 研究計畫的取徑在文字作品裡看得到對應
- [ ] 推薦人拿到了作品與計畫初稿
