# 作品集選件與備審 Checklist（藝術研究所）

> 作品集不是所有作品的集合，而是經過選擇與編排的創作論述。用第一節逐件評分決定選件，第二節排序，第三節補齊每件的說明欄位，第四、五節處理 CV 與自傳的分工。

## 一、選件評分表

每件作品逐項給 1–5 分。**選件的核心判準只有一個：拿掉它，脈絡會不會斷？**不會斷的作品，就是可以拿掉的。

## 二、排序決定

三種排法各有適用情境，選一種並寫下理由：

- [ ] **依時間排**：最容易看出發展；早期作品明顯較弱時不建議。
- [ ] **依系列排**：已有兩三條清楚線索時最適合。
- [ ] **代表作開場、再回頭鋪陳**：有一件強度明顯較高的作品時使用。

> 無論哪一種，**第一件作品要能立刻讓人知道你在做什麼**——書審的注意力就是從那裡開始分配的。

> 最後一欄最常被漏掉，卻是藝術類群最關鍵的一欄——它讓作品從「一張圖」變成「一條線上的節點」。

### 圖像檢核

- [ ] 代表作有一組正式圖像（非隨手紀錄照）
- [ ] 沒有明顯偏色、背景雜亂或細節糊掉
- [ ] 裝置與空間性作品另附能看出尺度與展呈關係的環境照
- [ ] 時基作品的影音連結可正常開啟、不需密碼、不會過期
- [ ] 解析度與檔案大小符合各校簡章規定

## 五、五份文件的分工

| 文件 | 負責回答 | 不該做的事 | 是否已檢查 |
|---|---|---|---|
| 作品集 | 直接證明創作能力與脈絡 | 變成無選擇的作品全集 |  |
| 藝術 CV | 呈現可查證的經歷與專業活動 | 混入與創作無關的經歷 |  |
| 自傳 | 說明創作歷程、轉折與動機 | 重述 CV 的條列內容 |  |
| 創作研究計畫 | 說明未來的發展方向與方法 | 和既有作品完全斷裂 |  |
| 推薦信 | 由教師證明學習態度與創作潛力 | 只寫「該生上課認真」 |  |

## 六、送件前總檢核

- [ ] 作品集有清楚的系列與排序，第一件作品立刻說明得了我在做什麼
- [ ] 每件作品都有完整的八個說明欄位
- [ ] 自傳呈現創作轉折，而不是重述 CV
- [ ] CV 沒有混入無關經歷，技術能力寫得具體
- [ ] 作品集與創作計畫互相支持——計畫提到的方向，在作品集裡找得到線索
- [ ] 四份文件講的是同一個人、同一條線
- [ ] 各校所的頁數、檔案大小與繳交格式都已符合
- [ ] 推薦人已拿到作品集版本與創作計畫摘要

## 常見失分點自我對照

- [ ] 選件依「我最滿意」而不是依研究方向排序
- [ ] 作品說明只寫媒材與尺寸，沒有寫在處理什麼問題
- [ ] 新舊作品之間看不出發展線索，像各自獨立的成果
- [ ] 圖像品質不一致，或翻拍有色偏與變形
- [ ] CV 只列展覽名稱，沒有標明角色（個展／聯展／策展／協力）
- [ ] 三份文件各說各話：作品集、創作論述與研究計畫指向不同方向
