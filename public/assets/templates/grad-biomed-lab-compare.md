## 陷阱檢核

- [ ] 選校的第一個動作不是打開排名表
- [ ] 看的是近兩三年的論文而不是十年前的代表作
- [ ] 已查過 GRB 政府研究資訊系統的教授進行中計畫
- [ ] 教授如何處理實驗失敗，已向學長姐確認過，不是看招生文宣
- [ ] 工時、值班、作者排序與實質畢業門檻都問過學長姐
- [ ] 網頁未更新或成員斷層的實驗室已確認過現在的運作狀態
- [ ] 頻繁的人員流動或大量延畢，已追問過原因

## 填完後檢核

- [ ] 以這個實驗室的樣本、設備與經費，我的題目能在碩士時程內做完
- [ ] 教授在學生實驗失敗時的處理方式，我承受得住
- [ ] 工時、值班與畢業門檻和我的生活與規劃一致
- [ ] 已確認教授今年實際收得到學生
- [ ] 名單中保留一所資源與指導關係明確可行的底線選項

## 查證管道

| 查證管道 | 說明 |
|---|---|
| GRB 政府研究資訊系統 | 查教授進行中與近年的計畫 |
| 臺灣博碩士論文知識加值系統 | 查歷屆碩士論文題目，看實際做得出什麼 |
| 實驗室網頁 | 看更新頻率與成員名單變化，會洩露營運狀態 |
| 現任或畢業學長姐 | 工時、值班、失敗指導、數據歸屬、作者排序、實質畢業門檻 |
| 招生簡章與官方文宣 | 可信度最低，通常看不到實質差異 |

> 查法提示：教授近年主持的計畫可公開查詢，看研究方向與活躍度；實驗室網頁看設備、成員與更新頻率；工時、值班、失敗後有沒有指導、作者排序與畢業門檻等隱性資訊，問學長姐最準。
