<section class="article-section" id="notion-right-use">
## Notion 最有效率的用法

<a href="https://www.notion.so" target="_blank" rel="noopener noreferrer">Notion</a> 能做很多事：筆記、資料庫、專案管理、作品集、甚至個人網站。但高中生最容易陷入的錯誤，是把太多時間花在建立系統上，卻沒有真正產出什麼。

你可能認識這種感覺：花了兩個小時設計一個漂亮的 Notion 頁面，最後發現裡面什麼內容都沒有。

**Notion 的核心價值，是讓你能快速找到你需要的東西，以及讓你的進度對自己透明**。如果你的 Notion 架構需要花很多時間維護，或者你每次想記錄什麼都要想很久要放在哪裡，這個架構太複雜了。

最好的 Notion 架構，是你能在三十秒內找到任何你需要的東西的架構——不是最漂亮的，不是最完整的，是最能讓你繼續做事的。
</section>

<section class="article-section" id="basic-structure">
## 建議的基本架構

對高中生來說，一個簡單的 Notion 工作空間通常只需要四個區塊：

**1. 現在在做的事（Now）**

一個簡單的頁面或清單，列出你這週在做的事情和每件事的下一步。不需要複雜的資料庫，一個頁面就夠了。它的目的是讓你每次打開 Notion 都能立刻知道現在應該做什麼。

**2. Side Project 管理（Projects）**

每個 Side Project 一個頁面，裡面記錄：這個 Project 的目標、目前的進度、遇到的問題、下一步要做什麼。加上一個簡單的 Database 追蹤每個 Project 的狀態（進行中、暫停、完成），讓你一眼看清楚自己手上有哪些事情。

**3. 學習筆記（Notes）**

按主題分類（例如：Python、資料分析、某個競賽的準備）。每篇筆記不需要很完整，重點是把你學到的關鍵概念和你自己的理解記下來，讓你下次需要的時候能快速找到。

**4. 備審素材（Portfolio）**

把你做過的所有事情整理成一個可以快速瀏覽的清單：活動名稱、時間、你做了什麼、學到了什麼、可以連結的相關成果（GitHub 連結、報告 PDF 等）。這個區塊是你高三整理備審時最重要的資料庫。
</section>

<section class="article-section" id="for-side-projects">
## Side Project 管理

對 Side Project，Notion 最實用的功能是幫你維持方向感和進度感——在你沒有辦法每天做的情況下，讓你每次回來都知道上次做到哪裡、下一步是什麼。

每個 Side Project 頁面建議包含：

- **目標**：這個專案要解決什麼問題，定義好了之後不要一直改
- **目前版本**：現在做到什麼程度，能不能展示
- **下一步**：最具體的下一個行動，例如「完成 API 串接」而不是「繼續做後端」
- **遇到的問題**：記錄你卡住的地方和你試過的解法，方便下次回來繼續

把每次工作的重要決策或發現記在「開發日誌」裡，幾行就夠，不需要寫成完整文章。這些紀錄之後整理備審的時候非常有用，因為你有真實的過程記錄，不需要靠回憶重建故事。關於 Side Project 執行的完整流程，可以參考[從 0 到 1 的 Side Project 指南](/pages/resources/side-project-from-zero.html)。
</section>

<section class="article-section" id="for-portfolio">
## 學習歷程與備審素材整理

備審最大的挑戰，通常不是「沒有東西可以寫」，而是「做了很多事但沒有記錄，整理的時候全靠回憶」。Notion 能解決這個問題，但前提是你養成邊做邊記的習慣，而不是到高三才開始補。

建議的備審素材整理方式：

建一個 Database，每一行是你做過的一件事——競賽、Side Project、閱讀、課程、活動都算。每一行記錄幾個欄位：時間、類型、你投入了多久、最重要的收穫、和你的申請方向的連結、可以附上的成果連結。

這個 Database 不需要每天更新，但每隔一兩週花十分鐘補一下，高三的時候你會很感謝這個習慣。

整理完之後，你能用 Filter 功能快速找到「所有和 AI 相關的經歷」、「所有有具體成果可以展示的活動」，讓備審的選材變得有效率得多。素材整理好之後，下一步是[從這些材料裡找到你的申請主線](/pages/resources/scatter-to-story.html)。
</section>

<section class="article-section" id="avoid">
## 不要在 Notion 上浪費時間的事

**過度美化頁面。** 換字體、換封面圖、找漂亮的 icon——這些事情花時間但對你的學習和準備沒有任何幫助。Notion 的頁面不需要漂亮，需要的是你能快速找到東西和快速記錄東西。

**建立你不會真正用到的系統。** 看到別人分享的複雜 Notion 系統，想要複製過來，但裡面很多功能你的情境根本不需要。空的系統不會幫你做任何事，只會讓你每次打開都不知道要怎麼用。從最簡單的開始，有需要再擴充。

**把 Notion 當成待辦清單的替代品。** Notion 很適合管理複雜的專案和整理結構性的資料，但對於日常的「今天要做什麼」，一個簡單的紙本或手機備忘錄反而更快。不要讓打開 Notion 成為開始做事的障礙。
</section>
