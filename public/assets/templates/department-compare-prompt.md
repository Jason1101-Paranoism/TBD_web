# 科系比較 Prompt 產生器（Meta Prompt）

> 用法：把下方「Meta Prompt」整段複製給任何 AI，並填入五個變數，AI 就會為你產生一份完整的「科系深度比較 Prompt」（8 階段版），再把產出的 Prompt 丟給 AI 執行即可。
> 方法說明與示範：〈怎麼認識一個科系？比較兩個科系的 8 層拆法〉 tbd-web.vercel.app/pages/resources/department-compare-method.html
>
> **匯入 Notion**：Import → Markdown。**用 Google Docs**：直接貼上。

## 先填五個變數

| 變數 | 說明 | 我的填入 |
|---|---|---|
| {學校} | 例：台大 |  |
| {科系A} | 例：化學系 |  |
| {科系B} | 例：化學工程系 |  |
| {常見標籤說法} | 你聽過的簡化說法 2–4 句，例：「化學偏理論、化工偏應用」 |  |
| {共同產業案例} | 兩系都會接觸的產業 2–3 個，例：製藥、半導體、電池 |  |

## Meta Prompt（整段複製，填入變數）

——

你是升學內容策略顧問，語氣專業而親切、不誇大。請為「{學校}{科系A} vs {學校}{科系B}」產生一份可直接使用的「科系深度比較 Prompt」。

已知資訊：
- 常見的標籤式說法：{常見標籤說法}
- 兩系共同的產業案例：{共同產業案例}

輸出必須是三段結構：

【第一段｜前段回覆】先指出上述標籤式說法為何隔靴搔癢（不可行動、把「解什麼問題／用什麼工具／在哪個尺度／產出什麼」四個維度壓成一個形容詞），再以 8 行預告將用 8 個階段拆解，並提醒資料要交叉查官方必修、課綱、教授實驗室與實際職缺，不能只看系所宣傳。

【第二段｜完整 Prompt 本體】供讀者整段複製給任何 AI。必須包含以下 8 個 Stage，每個 Stage 都要有明確的產出要求與至少一條反面禁令，且內容必須針對 {科系A}／{科系B} 客製（課名、問題、產業、職務都要是該領域真實存在的），不得是通用模板換名詞：

1. 拆除模糊標籤：列出該組合 3–5 個常見簡化說法，分析哪裡正確、哪裡誤導、省略了什麼；先建立比較面向，禁止急著下結論。
2. 實際在解什麼問題：兩系各 4 個以上「具體到能想像」的典型問題，並用共同產業案例說明各處理哪一層；禁止只給抽象定義。
3. 課程→能力：點名至少 10–12 門兩系核心課（含同名課），分析研究對象、作業形式、使用工具、訓練的思考能力、另一系學不學與目的差異；最後整理兩條知識主線、真正重疊區、看似相似但目的不同的課；禁止只列課名。
4. 同一案例跨尺度：指定 3–5 個候選案例，從最微觀尺度到量產／落地拆成 7–9 層，標出各系深耕層、切角不同層與必須合作層。
5. 四年實況：大二到大四的上課、作業、實驗、報告、數學與程式使用、專題、最易挫折點；呈現典型差異，但禁止把所有學生說成同一種人。
6. 研究所與職涯：禁止「兩系都能進某產業」式回答；要求比較同一間公司內兩系常見職務的分工、依產業列出職務貼近度、標明哪些職涯需要碩博、哪些差異其實取決於選修／實驗室／研究所；並區分研發、分析檢測、製程、設備、品管、生產、學術等職能。
7. 適合誰判斷題：12–15 題情境題，涵蓋興趣對象（追問微觀的「為什麼」vs 限制條件下設計「怎麼做」）、工具偏好（建模／實作／分析）、工作場景想像；每題標示偏向哪一系、為什麼、有哪些例外；禁止「喜歡 X 就讀 X 系」式結論。
8. 整合：回答「這兩系到底差在哪」，必須包含：為何一般答案隔靴搔癢、兩系精確但不過度簡化的描述、至少一個共同案例、選修／專題／研究所帶來的交集與變化、可實際執行的探索方法；禁止把任一系化約成單一刻板印象。

Prompt 本體結尾必須附「資料查核條款」：優先來源清單（兩系官方必修與課程資料、教授與實驗室、課程大綱、研究所招生、企業官方職缺、學生經驗分享）；每項重要陳述標示來源與資料日期；系所宣傳文字須轉譯為「學生實際做什麼／用什麼知識／產出什麼／與另一系差在哪」；資料不足時明確標示「無法由公開資料確認」，不得自行補造。

【第三段｜收尾預告】一句話說明之後會實跑這套流程並整理成完整比較。

輸出前自查：8 個 Stage 是否都有反面禁令？課名與職務是否為該領域真實存在？整份 Prompt 是否可被高中生直接複製使用？

——

## 使用提醒

- [ ] AI 產出後，逐項用官方課表與課綱覆核，特別是課名與職缺
- [ ] 「無法確認」的內容保留標註，不要讓 AI 替你補造
- [ ] 第 7、8 階段（判斷與整合）自己做——AI 只負責整理資料
