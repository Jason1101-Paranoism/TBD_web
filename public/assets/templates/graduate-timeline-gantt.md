# 研究所推甄時程倒數與任務甘特圖

> 填一個日期——你第一間的送件截止日——其餘 17 個任務的建議起訖自動回推。
>
> **這份的完整版是 CSV。** CSV 裡的日期欄是公式，改一個儲存格全部跟著動；
> 這份 Markdown 是紙本／Notion 版，日期要自己填。要當工具用請下載 CSV。
>
> **用 Google 試算表**：檔案 → 匯入 → 上傳 CSV → 匯入位置選「取代試算表」。
> **用 Excel**：資料 → 從文字/CSV → 匯入。
> **匯入 Notion**：Import → Markdown（公式不會過來，日期請手填）。

## 怎麼用

1. 打開 CSV，把 **B2** 改成你第一間的送件截止日（格式 `2026/10/15`）
2. 所有「建議開始」「建議完成」會自動重算
3. 「距送件」是負數代表送件前幾天，正數代表送件後幾天
4. 「狀態」自己填：未開始／進行中／完成

日期是**建議值不是規定**。各校送件時間差很多，有些九月初就截止——`graduate-timeline.html`
那篇講的是通則，你的目標科所一定要個別去官網確認。推幾間、怎麼排優先，也在那篇裡。

## 為什麼推薦信要抓那麼早

表裡「開始與教授建立互動」從送件前 210 天就開始，不是排版錯誤。推薦信需要一位**認識你**
的教授來寫，而「認識你」是要時間累積的。大四上才去請，通常只能拿到一封很制式的信。
正式請託那一列另外抓了三週，那是給教授寫信的時間，不是給你的。

## 想要真的長出甘特圖的長條

CSV 匯入後只有日期，沒有色條。要看到長條需要自己加一次條件式格式（做一次就好）：

1. 選 H 欄以右的空白區域，第一列填入從「最早開始日」起算的日期序列
2. 選整個區域 → 格式 → 條件式格式 → 自訂公式
3. 公式填 `=AND(H$5>=$C6, H$5<=$D6)`，設一個底色
4. 套用範圍設成你剛才選的區域

沒做這一步也完全可用——日期與倒數天數本身就是這份表的重點，色條是視覺加分。

## 如果距今天大量出現負數怎麼辦

負數代表這項照建議時程早該開始了。時間會很趕，但不是完全沒機會——優先順序這樣排：

1. **研究計畫書初稿**（沒有這個其他都免談）
2. **推薦信**（先確認教授願不願意，再談時間）
3. **把申請名單縮到 2–3 所**，難度分層
4. **成績單與 CV 這類文書**可以壓到最後兩週

先跳過：聯繫指導教授、找研究室或實習——這兩項需要的前置時間，現在補不回來。
