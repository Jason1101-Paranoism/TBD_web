# 升大學前 30 天準備 Checklist

> 一個月四週的節奏：探索選題 → 做第一版 → 優化紀錄 → 整理表達。
> 目標：月底時，你手上有一個真正完成、而且能說清楚的成果。
>
> **匯入 Notion**：在 Notion 左下／右上「⋯」→ Import → Markdown，選這個檔案，勾選項會變成 Notion 的 to-do。
> **用 Google Docs**：直接貼上，或開啟「以 Markdown 貼上」。

## 我這個月的目標

> 一句話：我這個月要做出 ＿＿＿＿＿＿，讓它可以 ＿＿＿＿＿＿。

## 第 1 週：探索與選題

- [ ] 列出三個有興趣且與方向相關的題目
- [ ] 上目標科系系網看課程地圖
- [ ] 找一位學長姐或從業者聊十分鐘
- [ ] 把題目縮小到一個月做得完的版本
- [ ] 寫下一句話目標

## 第 2 週：動手做第一版

- [ ] 把作品拆成三到五個小步驟
- [ ] 每天推進至少一個小步驟
- [ ] 做出一個雖然粗糙但完整的第一版

## 第 3 週：優化與紀錄

- [ ] 挑出最弱的一兩個地方集中改善
- [ ] 補上數據／截圖／案例等讓作品更有說服力的元素
- [ ] 開始寫過程紀錄（為什麼做／遇到什麼／怎麼解決）
- [ ] 程式作品放上 GitHub 並寫好 README

## 第 4 週：整理與表達

- [ ] 把成果整理成可分享的形式（連結／簡報／說明）
- [ ] 寫一段 150 字以內的作品簡介
- [ ] 練習用兩分鐘口頭說明這個作品
- [ ] 把成果與紀錄收進作品／經歷資料夾
