## 為什麼藝術所不能只看排名

藝術研究所的選校，排名能給你的資訊比其他領域更少。原因很簡單：**同一個系名底下的訓練內容，差異可能大到像兩個不同的科系。**

實際上，不同藝術研究所可能分別偏重純藝術創作、當代藝術、跨域與新媒體、藝術理論、藝術教育、策展、社會實踐、地方創生、科技藝術，或工藝與媒材研究。一個以傳統媒材深度磨練為核心的系所，和一個以科技藝術與跨域實驗為核心的系所，可能名字只差兩個字，但你進去之後每天在做的事完全不同。

所以藝術類群的選校順序，應該倒過來走：

> **創作方向 → 教學與研究取向 → 教授與工作室 → 校所**

先確認自己現在在做什麼、想往哪裡深化，再去看哪些系所在訓練這種人，接著看誰能指導、有沒有設備，最後才落到學校名字。從校名往回推，很容易選到一個聲譽很好、但完全不支援你創作的地方——而藝術研究所的兩年，卡在沒有設備、沒有對話對象的狀態，是很難補救的。
</section>

<section class="article-section" id="layer1">
## 第一層：先確認自己的創作方向

這一層是自己對自己的盤點，做不完的話後面兩層都會失焦。建議先寫下你目前主要關注的：

- **母題**：你反覆處理的主題是什麼？不必是宏大的概念，可能是身體經驗、家族記憶、特定地景、材料本身的物性。
- **媒材**：你實際用得最熟、也最想繼續用的媒材是哪些？
- **形式**：平面、立體、影像、時基、裝置、參與式、書寫——你的作品通常以什麼形式完成？
- **議題**：你的創作是否連結到特定的社會或文化議題？
- **空間與觀看方式**：作品預設觀者怎麼靠近、待多久、從哪個位置看？

這五項寫完，你手上就有一組關鍵字，可以拿去對照系所的課程結構與教授的創作。如果寫不出來，代表要先回到[作品盤點與母題收斂](/pages/resources/arts-graduate-timeline.html)那一步，選校再急也沒有用——你會一直用別人的標準在挑學校。
</section>

<section class="article-section" id="layer2">
## 第二層：教授、工作室與資源

確認方向之後，才進到查教授。這一層要查的不只是「他研究什麼」，而是「他怎麼工作、能給你什麼」：

- **教授近期的作品與研究**：近三到五年在做什麼？和你的關注有沒有交集？
- **是否仍持續創作**：這會直接影響他能給你的建議是概念層級還是實作層級。
- **工作室、設備與技術資源**：你的媒材需要什麼？系上有沒有？要不要排隊、要不要另外付費、有沒有技術人員支援？
- **是否支持跨域創作**：如果你的作品橫跨兩種媒材或領域，這一點比什麼都關鍵。
- **展覽、駐村或策展資源**：學生有沒有實際的發表機會？是系上安排還是自己找？
- **指導方式**：定期個別討論、集體評圖、還是放養？沒有哪一種比較好，只有適不適合你。
- **學生作品與論文方向**：這是最誠實的一份資料——它顯示這位教授實際帶得出什麼樣的創作。

**查法上，投報率最高的是近年的畢業製作與碩士論文。**系所官網的課程地圖告訴你他們想訓練什麼人，教授的個人網站與展歷告訴你他關注什麼，但畢業展與論文清單告訴你**這裡實際做得出什麼**——用什麼材料、做到什麼完成度、論述寫到什麼深度。建議每所至少看三到五位畢業生的作品與論文摘要。
</section>

## 第三層：系所文化與發展出口

第三層決定的是你這兩年的日常，以及畢業後的路。應該了解：

- **偏創作還是偏理論**：畢業製作與論文的比重如何？有沒有純創作組與理論組的分流？
- **是否重視展覽成果**：畢業展規模、是否有校外展出機會、系上是否協助策展與宣傳。
- **是否鼓勵跨校或跨系合作**：跨域創作者特別要問。
- **國際交換與駐村管道**：有沒有實際送出去的紀錄，不是只有簽約。
- **畢業條件**：作品量、論文字數、展覽要求、外語門檻，先看清楚再決定。
- **畢業生發展**：繼續創作、進入藝術機構、教學、轉行——比例大致如何？
- **校內外藝術資源**：美術館、替代空間、藝術聚落、駐村機構的地緣關係，對創作者的實際影響比想像中大。

這一層的資訊，官網通常只寫得到一半。**問學長姐是效率最高的作法**，而且問題要問得具體：不要問「這裡好不好」，要問「工作室幾點關」「設備要排多久」「老師多久看一次作品」「畢業展的預算誰出」。這些答案才會告訴你真正的日常。
</section>

<section class="article-section" id="fit">
## 最容易被忽略的契合度

藝術類群有幾個契合度問題，在申請階段很少被討論，卻常常是入學後最大的落差來源：

- **教授的創作語言是否真的能支持你**：他很厲害，不代表他理解你在做的事。一位長期做繪畫的教授，未必能給參與式創作有效的建議，反之亦然。
- **系所是否接受你的媒材與形式**：有些系所在評圖與畢業展上，對某些形式的接受度確實比較低。這不一定會寫在官網上，但從歷屆作品看得出來。
- **是否需要特定設備**：暗房、窯、版畫室、金工、木工、錄音室、程式與電子設備——先確認有沒有、能不能用、要不要排隊。
- **你希望被高度指導，還是自由發展**：這一題沒有標準答案，但選錯會很痛苦。習慣明確方向的人進到放養型工作室，容易整年空轉；需要空間的人被密集干預，作品也做不出來。
- **是否願意接受長期批評與反覆修改**：藝術研究所的評圖強度通常高於大學部。這件事最好在申請前就想清楚。
- **作品是否適合該校所的學術與創作文化**：有些系所重視理論厚度，有些重視技術完成度，有些重視議題參與。你的作品放進去，是被看懂還是被誤讀？

這幾項也正是**值得寫進聯繫教授信裡的問題**——它們具體、有正當性，而且只有那位教授答得出來（怎麼寫見[聯繫教授的藝術類群重點](/pages/resources/graduate-contact-professor.html#arts-tips)）。
</section>

## 把名單收斂成一張比較表

查到的資訊如果散在不同分頁與筆記裡，很難做決定。建議把每一所拉進同一張表逐項填，空著的格子就是你還沒查的東西：

| 項目 | 系所 A | 系所 B | 系所 C |

| 目標教授與其近年創作方向 |  |  |  |
| 教授是否仍持續創作、今年是否收生 |  |  |  |
| 媒材資源與工作室設備 |  |  |  |
| 設備使用限制（排隊／費用／技術支援） |  |  |  |
| 指導方式（個別討論／集體評圖／自由發展） |  |  |  |
| 展覽、駐村與策展資源 |  |  |  |
| 畢業要求（作品／論文／展覽／外語） |  |  |  |
| 對跨領域背景的接受度 |  |  |  |
| 與我的母題契合度（1–5） |  |  |  |
| 與我的媒材需求契合度（1–5） |  |  |  |

完整版（含查詢提示、兩個陷阱的自我檢核與填完後的檢核問題）可以直接下載：[教授與工作室比較表](/assets/templates/grad-arts-school-compare.md)（Markdown，可匯入 Notion）或 [CSV 版](/assets/templates/grad-arts-school-compare.csv)（Excel / Google 試算表）。

填完之後，別急著只留下分數最高的那一所。藝術類群的錄取結果變動大，建議保留三到五所，並確認其中至少有一所在媒材與設備上是明確可行的——那是你的底線選項，不是備胎。

名單收斂完，下一步是把創作方向寫成一份能被教授追問的計畫——[創作研究計畫怎麼寫](/pages/resources/arts-graduate-proposal.html)會接著談架構與常見錯誤。
