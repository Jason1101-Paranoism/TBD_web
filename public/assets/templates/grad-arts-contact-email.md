# 藝術類群聯繫教授信結構模板

> 藝術類群要不要事前聯繫教授，取決於招生制度、媒材需求與你手上作品的成熟度。先用第一節判斷該不該寄，再用第二節的七段結構寫，最後用檢核表確認不要寄出一封只有稱讚的罐頭信。
>
> **匯入 Notion**：Import → Markdown。
> **用 Google Docs**：可直接貼上。

## 一、先判斷：這封信該不該寄

### 適合主動聯繫

- [ ] 創作方向高度專門
- [ ] 使用特殊媒材或技術
- [ ] 需要確認工作室、設備或製作條件
- [ ] 教授近期創作與我的關注高度相關
- [ ] 我已有可供閱讀的作品集版本（連結可開、圖清楚、不需密碼）
- [ ] 想確認教授是否指導這類型的創作、今年是否收生

### 不適合聯繫

- [ ] 作品集還沒整理
- [ ] 只想詢問錄取機率
- [ ] 沒看過教授的作品
- [ ] 使用群發模板
- [ ] 信裡只有「我很喜歡老師的作品」
- [ ] 提不出任何具體問題

> 上面兩組各勾幾項？「適合」欄勾到兩項以上、且「不適合」欄一項都沒勾，才建議寄。作品集沒整理好就先不要寄——藝術類群的信，作品才是主體。

## 二、七段信件結構

| 段落 | 要寫什麼 | 我的內容 |
|---|---|---|
| 1. 簡短自我介紹 | 校系、年級、姓名，兩行以內 |  |
| 2. 目前的創作母題 | 反覆處理的問題，不要只寫領域 |  |
| 3. 主要媒材與形式 | 用什麼做、以什麼形式完成 |  |
| 4. 代表作品或作品集連結 | 一到兩件代表作＋可開啟的連結 |  |
| 5. 與教授創作／研究的具體連結 | 看過哪一件、哪個觀點與我的問題相關 |  |
| 6. 一個明確且必要的問題 | 只問一個，且要是他才答得出來的 |  |
| 7. 禮貌結尾 | 感謝＋不強求回覆 |  |

## 三、寫作原則：把「喜歡」換成具體內容

不要只寫：

> 我很喜歡老師的作品。

要具體說明四件事：

1. 哪一件作品或哪個創作觀點引起共鳴
2. 它和我目前處理的問題有什麼關係
3. 我自己目前遇到什麼創作問題
4. 為什麼認為這位教授可能適合指導

## 四、值得問的問題（挑一個）

這幾類問題具體、有正當性，而且真的只有他答得出來：

- 工作室設備是否支援某種製作方式或尺度
- 系上是否接受某種形式的畢業製作
- 是否指導過相近媒材或跨域的學生
- 我的創作方向在該所的訓練取向下是否可行

## 五、寄信前檢核

- [ ] 信件長度控制在螢幕一頁內，細節放作品集連結
- [ ] 作品集連結已實測可開、不需密碼、不會過期
- [ ] 圖像清楚，代表作看得出尺度與完成度
- [ ] 全信只有一個明確問題，且不是「老師會不會收我」
- [ ] 提到的教授作品是我真的看過的，作品名與年份沒有寫錯
- [ ] 收件人姓名、職稱、系所沒有沿用上一封信
- [ ] 避開九月開學後的教學與行政高峰
- [ ] 沒有回覆時，最多禮貌追蹤一次
