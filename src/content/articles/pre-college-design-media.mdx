<section class="article-section" id="mindset">
## 觀念：工具是起點，設計思維才是核心

設計傳播很容易讓人以為「會用軟體就好」。但科系真正在意的，是你的**設計思維與敘事能力**——你為什麼這樣做、想傳達什麼、解決了什麼問題。工具只是把想法實現出來的手段。

升大學前的時間，最好的安排是：先把工具練到「不卡手」，這樣你才有餘力去想更重要的事——審美、敘事與設計決策。
</section>

<section class="article-section" id="foundation">
## 值得先修的底層能力

- **核心工具**：依方向選一兩個練到上手——平面 / UI 方向的 <a href="https://www.figma.com" target="_blank" rel="noopener noreferrer">Figma</a>、影像方向的剪輯軟體、攝影方向的基本後製。目標是熟練到能順暢地把腦中的東西做出來。
- **基本的視覺原則**：了解排版、對齊、留白、配色、字體的基本邏輯。這些原則學起來，會讓你的作品立刻看起來更專業（可延伸參考[備審排版與視覺設計](/pages/resources/portfolio-design.html)）。
- **敘事能力**：設計與傳播都是在「說一個故事」。練習把一個作品背後的想法說清楚——它要解決什麼、為誰而做、你的選擇是什麼。
- **觀察與記錄**：開始有意識地收集你覺得好的設計、影像、廣告，並問自己「它為什麼有效」。
</section>

<section class="article-section" id="project">
## 第一個作品與作品集起步

設計傳播方向，作品就是你的語言。升大學前能做出一兩個完整作品，會非常有幫助。

- **一個有主題的小作品**：一組海報、一支短片、一個 App 的 UI 原型、一個品牌的視覺設計——範圍小沒關係，重點是完整、有想法。
- **記錄你的設計過程**：不要只放最終成品。把你的發想、草稿、修改與決策也整理出來——科系評審和老師最想看的是「你怎麼想」，而不只是「結果多漂亮」。
- **建立一個作品集載體**：把作品整理到 Behance、個人網站或一份精緻的 PDF。怎麼建一個[個人網站作品集](/pages/resources/portfolio-website.html)，可以參考這篇。

一個有過程、有想法的作品，遠勝過十張漂亮但說不出所以然的圖。
</section>

<section class="article-section" id="explore">
## 審美累積與方向確認

- **大量輸入、有意識地看**：審美是累積出來的。多看好作品，並養成分析「它為什麼好」的習慣，而不只是覺得「好看」。
- **確認方向**：設計傳播底下差異很大——視覺設計、UI/UX、影像、新聞、廣告、公關的日常完全不同。找學長姐聊聊，了解實際在學什麼。
- **善用 AI、但守住你的觀點**：AI 可以加速發想與製作，但你的審美判斷與創作意圖才是不可取代的（參考[AI 工具實用指南](/pages/resources/ai-tools-guide.html)）。
</section>

<section class="article-section" id="checklist">
## 設計傳播升大學前行動清單

- [ ] 選一兩個核心工具（Figma / 剪輯 / 後製）練到上手。
- [ ] 學會基本的視覺原則：排版、對齊、留白、配色。
- [ ] 做出一個有主題、有想法的完整作品。
- [ ] 把作品連同過程整理到 Behance / 個人網站 / PDF。
- [ ] 開始有意識地收集並分析你覺得好的作品。
- [ ] 找一位該領域學長姐聊各方向的差別。

把這些做完，你會帶著「能把想法做出來、也說得清楚」的能力進大學——這正是設計傳播最看重的事。
</section>
