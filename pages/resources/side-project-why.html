Side Project 指南

為什麼升學越來越重視 Side Project？

成績只是入場券。這篇文章說明，為什麼自主發起的專案，正在成為書審、特殊選才與研究所推甄中最有說服力的能力證明。

什麼是 Side Project？

Side Project 指的是在正式課程以外，由學生自己主動發起的作品、研究或行動。它可以是一個解決生活問題的小程式、一份自主研究報告、一個改善校園環境的提案，或者一個記錄某個興趣的作品集。

它不必規模龐大，也不必有獎項。重要的是它來自你自己的問題意識，並且你真的花時間做出了東西。

幾個具體的例子：

  • 用 Python 寫一個幫家人追蹤藥物服用時間的小工具
  • 針對家鄉的交通問題做一份深度田野報告
  • 參考論文，自己動手複現一個簡單的機器學習模型
  • 把學了三年的日文做成一個分享給同學的學習資源包

這些看起來「不大」的事，在申請上的重量，往往遠超過一張沒有說明的獎狀。

申請評審邏輯的轉變

台灣的大學申請，包含個人申請、特殊選才與研究所推甄，都在逐步走向更整體的評估方式。評審委員不只在看你的學科成績，也在問一個更根本的問題：

這個學生，在沒有人要求的情況下，會主動做什麼？

這個問題之所以重要，是因為大學不只想錄取會考試的學生，而是想錄取入學後會主動學習、能在研究室或課堂上產生貢獻的人。

而 Side Project 正是最直接回答這個問題的方式。它展現的不是你「知道多少」，而是你「在沒有人要求你的情況下，做了什麼」。這個差距，是成績無法替代的。

Side Project 能展現哪些成績無法證明的能力？

成績能說明你在特定測驗範圍內的掌握程度，但它沒辦法說明幾件事：

  • 主動性：你是否在沒有人要求的情況下，主動探索某個問題？
  • 問題解決：面對困難時，你是放棄還是想辦法繞過去？
  • 執行力：你能不能把一個想法真正做成東西，哪怕是粗糙的版本？
  • 反思能力：做完之後，你有沒有回頭思考哪裡做得不夠好、下次可以怎麼改？

這四種能力，在書審與面試中都是評審會主動追問的方向。而 Side Project 提供了一個最具體的切入點，讓你用真實的行動去回答這些問題，而不是用泛泛的自我描述。

台灣升學語境下，Side Project 適用嗎？

很多學生會有疑問：「Side Project 是國外申請的概念，台灣升學真的看這個嗎？」

答案是：108 課綱本來就是在推這件事，只是台灣用不同的語言來說。

學習歷程裡的「自主學習計畫」，本質上就是在問你有沒有能力主動探索一個主題。特殊選才的審查標準，核心就是「你有沒有在某個領域做出超出課程要求的東西」。研究所推甄的研究計畫，也在問你能不能自己定義問題、推進一個有結構的探究過程。

Side Project 不只是國際申請用的概念，而是台灣升學系統正在越來越重視的能力展現方式。只是很多學生還沒意識到，他們已經在做的某些事，就是 Side Project——只是還沒有被有效整理和呈現。

常見誤解：Side Project 一定要很厲害嗎？

很多學生聽到「Side Project」，第一個反應是：「我沒有什麼特別的成就，我能做什麼？」

這個誤解來自把 Side Project 等同於「得獎的大型專題」。但評審更在意的，其實是這三件事：

  • 這個問題是你自己發現的，還是老師叫你做的？
  • 你在做的過程中遇到什麼困難，你怎麼處理？
  • 做完之後，你對這個領域的理解有沒有改變？

一個解決實際問題的小工具，配上清楚的思考脈絡，比一個放在 GitHub 上卻說不清楚動機的大型專案更有說服力。

Side Project 的核心不是「規模」，而是「你對它有沒有真正的主導權和反思」。

如何開始你的第一個 Side Project？

最簡單的起點是從「生活中讓你覺得不夠好的地方」開始。不需要解決世界問題，只需要找一個你真的有感覺的小摩擦點。

幾個找起點的方法：

  • 科系反推：你想申請的系所最在意什麼能力？這個能力有沒有可以用專案展現的方式？
  • 興趣延伸：你平常在做什麼讓你忘記時間的事？這件事有沒有辦法做成一個有結構的成果？
  • 問題出發：你的生活、學校或社區有什麼你覺得可以更好的地方？你能用你學過的工具做點什麼？

開始不需要完美。一個有清楚目的、有執行紀錄、有反思的小專案，已經是很好的起點。重要的是，你真的做了，並且能說清楚為什麼做、做了什麼、學到什麼。

如果你不確定自己的方向，可以先聊聊

Side Project 的起點往往不是「找到完美的題目」，而是「先理解自己在哪裡、想去哪裡」。如果你有很多想法但不知道哪個值得投入，或者有一些過去的經歷但不知道怎麼整理，第一次策略諮詢可以幫你把這些想法結構化。
