# 研究問題縮小與研究計畫架構模板（法政研究所）

> 法政研究計畫最常見的兩種死法：寫成一整篇文獻整理（有議題、沒有研究問題），或題目大到碩士兩年根本做不完（「AI 倫理」「兩岸關係」「轉型正義」）。這份模板分三段用：先把題目縮小成一個具體爭點，再套十節架構寫，最後用方法與可行性檢核擋掉會被口試打穿的地方。
>
> **匯入 Notion**：Import → Markdown 後，各表可切換成資料庫追蹤進度。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 第一段：研究問題縮小五步

每一步都要寫出文字，不能只在腦中想過。第 3 步是最多人卡住、也最值得花時間的地方。

| 步驟 | 要做的事 | 我的答案 |
|---|---|---|
| 1. 起點 | 我在哪一門課、哪一次報告、哪一段實務經驗中產生了這個困惑？ |  |
| 2. 議題 | 用一句話寫出這個議題（此時還很大，沒關係）。 |  |
| 3. 收斂成爭點 | 把議題縮小到一個具體的法制爭議、政策設計問題或理論衝突。它應該是**可辯論的**——正反雙方都說得出理由。 |  |
| 4. 寫成研究問題 | 改寫成一個問句。避免「探討○○」這種不是問句的寫法。 |  |
| 5. 界定範圍 | 限定時間、地域、法規範圍、政策層級或個案數量，讓它兩年做得完。 |  |

**縮小前後對照練習**（照著填一次，會很有感）

| 太大的題目 | 收斂後的研究問題 |
|---|---|
| 例：AI 的法律規範 | 例：某一部特定法規草案中的演算法問責條款，在既有行政程序法制下產生哪些適用衝突？ |
| 我的太大版本： | 我的收斂版本： |

## 第二段：十節架構

每一節都附「這一節要回答的問題」。寫完一節就回頭確認它真的回答了那個問題。

| 節次 | 這一節要回答的問題 | 常見失分 | 完成 |
|---|---|---|---|
| 1. 研究背景 | 這個問題所處的法制、政治或政策脈絡是什麼？ | 從盤古開天寫起，前三頁看不到重點 | [ ] |
| 2. 問題意識 | 為什麼這件事值得研究？現況出了什麼問題？ | 只描述現象，沒有指出張力所在 | [ ] |
| 3. 核心研究問題 | 我要回答的那一個問句是什麼？ | 列了五個問題，其實一個都沒收斂 | [ ] |
| 4. 文獻回顧 | 前人做到哪裡？留下什麼缺口？ | 堆疊摘要、沒有評述，看不出你的立場 | [ ] |
| 5. 理論／法理架構 | 我用什麼理論或法理來分析？為什麼是它？ | 掛一個理論名字當裝飾，後面完全沒用到 | [ ] |
| 6. 研究方法 | 我怎麼取得與處理材料？ | 只寫「文獻分析法」四個字，看不出實際操作 | [ ] |
| 7. 研究範圍 | 我做什麼、明確不做什麼？ | 沒有寫「不做什麼」，等於沒有界定範圍 | [ ] |
| 8. 預期發現或貢獻 | 做完之後，學界或實務界會多知道什麼？ | 寫成「希望能提供建議」這類空話 | [ ] |
| 9. 可行性 | 兩年內做得完嗎？資料拿得到嗎？ | 完全沒談，等口試被問才發現拿不到資料 | [ ] |
| 10. 研究限制 | 我的方法答不了什麼？ | 迴避不談，反而讓人懷疑你沒想清楚 | [ ] |

## 第三段：方法選用對照

先確認你的問題屬於哪一類，再選方法。方法是問題與結論之間的橋樑，不是裝飾。

| 我的問題長什麼樣 | 常見的對應方法 | 要先確認的可行性 |
|---|---|---|
| 某項法律規範在實務上如何被適用 | 判決分析、實務見解整理 | 判決是否公開可檢索、樣本量是否足夠 |
| 兩個以上法域對同一問題的處理差異 | 比較法研究 | 是否具備該國語言能力、是否有可靠的譯本或二手文獻 |
| 某項法制或政策在規範層面是否融貫 | 規範分析、法釋義學、法理論分析 | 是否掌握該領域的核心學說與論爭 |
| 某項政策實施後產生什麼效果 | 政策評估、量化統計分析 | 資料是否可取得、是否具備統計能力 |
| 特定行動者為什麼這樣決策 | 質化訪談、個案研究、過程追蹤 | 是否接觸得到受訪者、是否需要研究倫理審查 |
| 某個概念或理論本身如何被建構 | 理論分析、思想史考察 | 是否讀得了原典、是否掌握學術脈絡 |

## 研究倫理與資料取得檢核

- [ ] 若要訪談，我確認過是否需要研究倫理審查，以及所需時間。
- [ ] 若使用未公開的實務資料（案件、內部文件、當事人資訊），我確認過取得管道與去識別化方式。
- [ ] 若引用實習或工作期間接觸的資訊，我確認過保密義務的界線。
- [ ] 我的資料來源是可查證的（法規、判決、公報、官方統計、學術文獻），不是憑印象。

## 送出前的六個自省問題

- [ ] 我的題目是聚焦的具體爭議，而不是宏大主題？
- [ ] 我能用一句話說出核心研究問題，而且它是一個問句？
- [ ] 我的方法真的能回答這個問題，而不是掛在那裡好看？
- [ ] 這個題目在碩士兩年內做得完，資料我拿得到？
- [ ] 我能說清楚「為什麼是我來研究這個問題」，並連得上修課、專題或實務經歷？
- [ ] 我寫出了研究限制，而不是假裝方法沒有弱點？

> 資料查詢入口：全國法規資料庫（law.moj.gov.tw）查現行與歷次修正條文；立法院法律系統（lis.ly.gov.tw/lglawc/lglawkm）查立法沿革與立法理由；司法院裁判書查詢（judgment.judicial.gov.tw）做判決檢索；憲法法庭（cons.judicial.gov.tw）查裁判與解釋；學術文獻用 Google 學術搜尋與臺灣期刊論文索引系統（tpl.ncl.edu.tw）。
