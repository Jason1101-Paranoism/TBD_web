# Growth Compass — 漏斗規劃與免費服務定義

> 這份文件回答兩個綁在一起的問題：
> 1. 這是一個**怎麼樣的免費服務**？
> 2. 它作為漏斗的一環，**該怎麼規劃**？
>
> 上位定位見 `positioning.md`；範圍見 `growth-compass-v0.1-scope.md`；欄位見 `growth-compass-reflection-design.md`。

## 一、這是什麼免費服務

> **一個免費的「把你散落的經歷，變成一個關於你自己的故事開頭」的工具——而且它會誠實地讓你看到：你卡住的地方不是經歷不夠，是還講不清楚自己。而那一段，正是顧問接手的地方。**

類比：**個人成長版的 Duolingo（持續累積）× LinkedIn（經歷整理），但核心不是記錄，是「被看懂」——而且它知道自己的終點是把人交給一個真人。**

### 從學生角度：拿到什麼
不是填資料、不是考測驗拿分數，而是一段體驗：
1. 被一句話戳中（「大部分人不是沒經歷，是不知道自己有什麼」）
2. 花 30 秒講一件做過的事 → 拿回一句自己沒講出來的那層意思 → 第一次覺得「它懂我」
3. 一次加一件、一次答一題 → 一條「這好像就是我」的主線浮現
4. 走到某點意識到「我做了很多，但不知道怎麼講成故事」→ 它告訴你：這段有人能幫你

零成本、秒開（IG bio 可點）、無壓力、而且**真的有用**——給的是「被看懂」和「故事開頭」，不是冷冰冰的雷達圖。

### 從 TBD 角度：在生意裡是什麼
**漏斗入口，不是產品本體。** 它做三件事：
1. **降低近用門檻**——讓不會主動找顧問的人零成本先進來
2. **沉澱敘事原料**——使用者在「被看懂」過程中順手留下顧問最需要的素材，讓顧問服務又快又便宜
3. **製造一個 TBD 剛好能解的問題**（「你缺的不是經歷，是呈現」）→ 自然交棒付費顧問

**錢不在免費工具裡，在顧問。** 免費服務的工作是「發現問題 + 把人帶到對的人面前」。

### 誠實的交易
學生零成本拿到真實價值（被看懂、故事開頭、結構化起點）；TBD 拿到合格潛客 + 預收的敘事原料。雙方都拿到對自己有用的東西——這就是它能免費的原因，也是它**必須真的有用**的原因（體驗一假，沒人走到顧問那步，漏斗就斷）。

### 它刻意不是什麼
| 不是 | 因為 |
|---|---|
| ❌ 經歷紀錄系統 | 記錄層是 Lucker/Notion 地盤，外包出去 |
| ❌ 給分數/雷達圖的測驗 | 自評量表＝策略劇場，量不出真正的你 |
| ❌ 會說「你適合 OO 系」的 AI | 那是顧問＋高風險決策才準的判斷，軟體不假裝會 |
| ❌ 要你每天登入的 SaaS | 季節性、里程碑觸發的陪伴，不是日活工具 |

## 二、漏斗規劃的第一原則

「低近用成本」「增加互動」「獲取資訊」**不是要權衡的三角，是同一個迴圈的三個面。**

分開做會互咬：多問資訊 → 抬高成本；要互動 → 要承諾 → 又抬高成本。把它們縫成一條**價值換資訊的階梯**，三者就合一：
- 每一階：使用者付出極小一點資訊 → 立刻拿回一口「被看懂」→ 資訊順手沉澱。
- **爬階梯這個動作本身就是「互動」**；爬的動力來自每階回報的價值，不是積分徽章。

核心排序原則：**價值前置，資訊後置。** 先給「被看懂」再要資訊；把資訊拆成很多顆極小的問題分散在多次低成本互動裡——於是「增加互動」變成「獲取資訊」的交付方式，而非對手。

## 三、互惠階梯（reciprocity ladder）

```
第 0 階  鉤子（無帳號、零資訊）
  一句戳中的問句／一句定位框架
  成本：讀一個畫面        回報：「這就是我」的認出感
      ↓
第 1 階  一筆經歷快速捕捉（無帳號）
  只問 origin + my_role（30 秒）＋ 一句「距離申請多久」路由
  成本：30 秒、一筆        回報：★第一口「被看懂」★ ← 整個漏斗的成敗點
      ↓
第 2 階  柔性開帳號（被價值正當化，不是閘門）
  「要不要存起來／再加一筆？」→ 這裡才拿 contact
  成本：留 email/LINE      回報：保存 + 繼續被看懂
      ↓
第 3 階  深掘（跨多次、可中斷）
  一次一題：turning_point → change → meaning
  成本：每次一題           回報：每答一題回拋一條連結
      ↓
第 4 階  主線浮現 → 依「跑道長短」走兩個出口之一
  ├─ 還有跑道（高一二/大一二）→ 導航：下一步往哪走 → 留住、季節觸發回來
  └─ 申請在即（高三/大三）   → 呈現：講不清楚的缺口 → CTA 交棒顧問
```

> 路由訊號在第 1 階就輕輕問一句「你現在幾年級／距離申請大概多久？」，據此決定第 4 階走哪個出口。詳見下節。

## 三-B、兩種模式、兩個出口（避免做成「只 for 高三」）

同一個引擎，依「距離申請多久」分兩種模式。差別只在**第 4 階輸出朝哪、出口是什麼**：

| | 累積／導航模式 | 呈現模式 |
|---|---|---|
| **對象** | 高一高二、大一大二（還有跑道） | 高三、大三（申請在即） |
| **核心問題** | 我正在長成什麼樣子？**下一步往哪走？** | 我有什麼？**怎麼把它講成故事？** |
| **第 4 階輸出** | 主線雛形 ＋「這條線目前只有想法、還沒對外成果，下一步可以試試…」 | 「你已有的這些可以這樣呈現」＋講不清楚的缺口 |
| **出口** | **留住**：學期末/比賽後回來看主線又長了什麼（陪伴累積） | **交棒顧問**：作品集/備審/面試（付費） |
| **賺什麼** | 信任、名單、長期關係、未來案例（錢遞延） | 立即轉付費 |

**為什麼非做不可**：終點若只有「交棒顧問做備審」，等於只服務高三；低年級會想「我又還沒要申請」就關掉。而你的長期飛輪只有從低年級接住並留住才轉得動——低年級是更大漏斗、更長關係、未來案例庫來源。

**導航模式的護欄**：「下一步」必須建立在**證據缺席**上（「你這條線缺的是對外成果」），而非預測「你適合 OO 系」。例：

> 「你對遊戲設計很有想法，但目前都停在『想』——下一步，把其中一個做出來給別人玩玩看，你就有第一個能講的作品了。」

這是方向，不是判斷；是引導，不是代筆。仍不做自動評分、科系預測、假精確缺口。

**低年級「復活」的模組**（曾因高三視角被降級，對低年級才是核心）：成長時間軸（看自己這學期又長了什麼）、下一步方向（前瞻版缺口）、季節/里程碑觸發回來——但只給低年級、只用質性。

## 四、成敗點：第 1 階那一口「被看懂」的品質

整條漏斗賭在這裡。30 秒講完一件事，回拋若是「聽起來你很有熱情！」這種罐頭，**鉤子當場崩成策略劇場**，後面全廢。它必須讓人覺得「你抓到了我沒講出來的那層」。做法由穩到險：

1. **反射式重述（最穩）**：把他的話換句話說、點出隱含的——「你說是被指派的，但你做的其實是 OO，這比指派的份量大」。不預測、不建議，只反射。
2. **針對回答型態的反思模板**：對 origin/my_role 的幾種典型回答預寫高品質反思骨架，填入關鍵詞。
3. **受約束的 LLM（最有力也最險）**：嚴格限制只能「反射 + 提問」，禁止「建議/判斷/預測科系」，否則幻覺 → 又掉回策略劇場。

**建議：v0.1 先用 1+2（可控、不幻覺）**，把 3 留到驗證過「被看懂」體驗成立之後。

## 五、什麼讓人回來（互動，不靠遊戲化）

**不要 streak / 積分 / 徽章**——跟品牌陪伴感、跟「季節性非日活」本質都衝突。誠實的回流引擎：

1. **開放迴圈（好奇缺口）**：「你已放 2 件，一條線開始浮現——再加一件我就能確定。」
2. **里程碑/季節觸發，不是月曆催**：「你又完成一件事，加進來看它接到哪條線」「申請季快到了」。
3. **正在成形的『關於我的故事』本身就有引力**（Duolingo × LinkedIn 的那股拉力）。

每次回流都該**可續、可中斷、一次一題**，絕不丟大作業。

## 六、漏斗對齊架構：低成本段公開、高價值段才進 app

順手解掉「帶後端 app 不該長在靜態官網 repo」的矛盾，也接上現有流量（IG Bio、LINE 選單）：

| 漏斗段 | 形態 | 放哪 |
|---|---|---|
| 第 0–1 階（鉤子＋首捕捉，無帳號） | 輕量互動，IG bio / LINE 選單可直接點、秒開 | 公開、輕量（client-side 反思模板即可） |
| 第 2–4 階（開帳號後深掘） | 帶登入、Supabase | 獨立 app（`app.tbd…`） |

**沿漏斗切架構**：最低成本頭段做成「IG bio 可直接點」的公開互動（秒開、零安裝、零帳號＝低近用成本的極致）；帳號與資料庫往後挪到使用者嚐過甜頭之後。

---

## 七、這一段量什麼（取代「100→30→10 重複盤點」）

舊 KPI 量「重做問卷」，與新設計不合。改量漏斗轉化：

- **鉤子 → 首捕捉率**（0→1）：頭段吸引力
- **首捕捉 → 續做率**（1→2）：那口「被看懂」有沒有成立 ← 最關鍵領先指標
- **捕捉 → 開帳號率**（2，拿到 contact）
- **開帳號 → 顧問 CTA 點擊 / 初談預約**（← 真正的金錢指標）
- **每人敘事完整度**（沉澱多少原料 → 決定顧問接手效率與成本）

> 把「啟用（activation）」重新定義成「**第一次被看懂的瞬間**」，不是「完成一次盤點」。

---

## 八、護欄

- 第一口價值**必須在帳號牆之前**；別讓帳號要求往階梯上爬。
- 反思品質寧可保守（反射式）也不要罐頭或幻覺——這是命門。
- 頭段資料保持低敏感（**鉤子階段不要證明文件上傳**）；未成年個資/家長同意是上線前置。
- 不做成癮機制；回流靠好奇缺口與季節觸發，不靠 streak。
