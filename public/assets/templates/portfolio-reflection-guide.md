# 學習歷程「反思」寫作引導

> 先選結構再下筆。對著空白頁想「我學到什麼」寫不出東西，是因為那個問題太大了。
>
> 三種結構出自 `/pages/resources/reflection-in-portfolio.html`。

## 反思不是「我學到了很多」

「收穫很多」「讓我成長」「更確定自己的興趣」——這些句子的共同問題是，
**換成任何一個活動都成立**。它們沒有傳遞任何關於你的資訊。

有效的反思幾乎都是這三種結構之一。挑一種，把空格填掉，再改寫成一段話。

## 結構 A：我以為 X，但發現其實是 Y

最有說服力的一種。它展示你動手之前有一個預設，做完之後這個預設被修正了。

> **範例**：我以為機器學習的難點在於寫模型，但實際操作後發現清理資料才是最耗時的部分，
> 也讓我意識到資料品質比演算法選擇更根本。

比「我學到了資料清理很重要」有力得多——差別在於前者有一個**被推翻的預設**。

| 這段經歷是 | 我原本以為…… | 但實際做了之後發現…… |
|---|---|---|

## 結構 B：這件事讓我發現了一個我之前沒想到的問題

做完一個活動，不是得到答案，而是發現了一個更深的問題。這種反思展示的是**問題意識的深度**，
也是研究型學生最重要的特質之一。

> **範例**：做完這個科展後，我反而對自己的研究方法產生了疑問——我的樣本是否有足夠的代表性？
> 這讓我想在大學階段系統性地學習研究設計。

| 這段經歷是 | 做完之後我沒有得到答案，反而發現…… | 這讓我想在大學階段…… |
|---|---|---|
| | | |
| | | |

寫成一段話：

## 結構 C：這個經歷確認了或改變了我的方向選擇

關鍵是**具體**。不是「讓我更確定要讀這個系」，而是「我知道了我在這個領域最想解決的問題是什麼」，
或「這個過程讓我意識到我更想做 X 而不是 Y」。

## 寫完之後自我檢查

- [ ] 把活動名稱換成別的活動，這段話還成立嗎？（成立＝太空泛，重寫）
- [ ] 有沒有具體到只有你寫得出來的細節？
- [ ] 有沒有一個**改變**——預設被推翻、問題被發現、方向被確認？沒有的話那不是反思，是心得

## 別等到考前才補寫

反思最難的地方不是寫，是**回想**。三個月後你不會記得當時卡在哪、為什麼那樣判斷。
在活動當下記兩行，比事後憑印象補一篇有用得多——這也是 Side Project 追蹤板裡
「每次卡關當下就記一筆」那一列的用意。
