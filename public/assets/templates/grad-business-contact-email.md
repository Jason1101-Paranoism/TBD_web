# 商管財經套磁信結構模板（商管與財經研究所）

> 商管財經的套磁不一定是必要條件，但用得好可以確認研究方向、了解教授是否收生、預先了解研究資源，也為研究計畫與口試做準備。一封有效的信，要讓教授快速知道：你是誰、做過什麼、為什麼和這個研究方向合。
>
> **匯入 Notion**：Import → Markdown。**用 Google Docs**：直接貼上。

## 七段信件結構

| 段落 | 要寫什麼 | 你的草稿 |
|---|---|---|
| 1. 主旨 | 「碩士班研究方向詢問 — 姓名／學校系級」 |  |
| 2. 簡短自我介紹 | 學校、系級、目前的申請方向（一兩句） |  |
| 3. 相關經驗 | 實習、競賽、專題或資料分析經驗，具體到你負責什麼、用什麼方法 |  |
| 4. 讀過教授的研究 | 提到一篇論文或一個研究方向，說出你的想法或問題（最關鍵） |  |
| 5. 契合點 | 你想研究什麼、為何和這位教授的方向合 |  |
| 6. 明確請求 | 想確認的具體問題（是否招生／研究方向是否契合／建議補強什麼） |  |
| 7. 附件與結尾 | 附上精簡 CV 或成果摘要，禮貌結尾 |  |

## 商管財經特別適合呈現的內容

- [ ] 商業競賽成果（名次之外，說明你負責的分析與產出）
- [ ] 實習中的分析報告或提案
- [ ] 課程專題或自主研究
- [ ] 財務模型、估值或財報分析
- [ ] 市場研究與消費者調查
- [ ] 資料分析作品（SQL／Python／R／視覺化）
- [ ] 問卷設計與統計分析經驗
- [ ] 國際交換或跨文化經驗
- [ ] 英文能力與專業證照

## 不建議的做法

- 尚未做任何功課就寄信
- 群發同一封模板信
- 只問「老師會不會收我」
- 沒有具體內容就過早聯繫
- 把信寫成自傳全文

## 寄信前檢核

- [ ] 這封信有針對這位教授客製，不是群發罐頭信？
- [ ] 有具體提到教授的某篇研究或方向，並說出自己的想法或問題？
- [ ] 信中有明確的問題，而不是只表達「有興趣」？
- [ ] 附件（CV／成果摘要）都附上、稱呼與姓名正確、沒有錯字？
- [ ] 時機是否避開教授九月開學後的教學與行政高峰？

## 先判斷這封信該不該寄

- [ ] 我讀過這位教授近三到五年的論文，看得出方法取向
- [ ] 我說得出他用量化還是質性、資料從哪裡來
- [ ] 我的研究問題和他的方法訓練接得上
- [ ] 我有一個具體的問題可以談，不只是想加入
- [ ] 把教授名字換掉，這封信就不成立
