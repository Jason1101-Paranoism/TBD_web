# 教育類群聯繫教授信結構模板

> 教育類群寄信給教授，目的是對齊四件事：學術流派、政策取向、現場資源、指導方向。這四項查不到，只有他答得出來。先用第一節判斷該不該寄，再用第二節的七段結構寫，最後用檢核表確認不要寄出一封只有熱忱的罐頭信。
>
> **匯入 Notion**：Import → Markdown。
> **用 Google Docs**：可直接貼上。

## 一、先判斷：這封信該不該寄

### 適合主動聯繫

- [ ] 我的研究方向與該教授近三年的研究有具體交集
- [ ] 我需要確認的資源只有他答得出來（合作學校、實習場域、研究計畫）
- [ ] 我想確認他今年是否收生、是否指導這類型的題目
- [ ] 我有一份可讀的研究計畫摘要或作品（教案、專題、個案報告）
- [ ] 我讀過他的研究，說得出他用什麼理論、在哪些場域蒐集資料
- [ ] 我的方法取向（質性／量化／行動研究）需要先確認是否合得來

### 不適合聯繫

- [ ] 只看過系所頁面的研究興趣欄位，沒讀過他的研究
- [ ] 只想詢問錄取機率或分數門檻
- [ ] 想問的事情官網查得到（名額、考科、修業年限）
- [ ] 使用群發模板，只換教授名字
- [ ] 信裡只有「我對教育很有熱忱」
- [ ] 手上還沒有任何可談的現場經驗或研究方向

> 上面兩組各勾幾項？「適合」欄勾到兩項以上、且「不適合」欄一項都沒勾，才建議寄。

## 二、七段信件結構

| 段落 | 要寫什麼 | 我的內容 |
|---|---|---|
| 1. 簡短自我介紹 | 校系、年級、姓名，兩行以內 |  |
| 2. 教育現場或專業背景 | 待過哪個場域、多久、什麼身分 |  |
| 3. 目前關注的問題 | 一句話講清楚，要有對象與情境 |  |
| 4. 與教授研究的具體連結 | 讀過哪篇、哪個取徑與我的問題相關 |  |
| 5. 想確認的學術或實務問題 | 只問一個，且要是他才答得出來的 |  |
| 6. 相關作品或附件 | 研究計畫摘要／教案／個案報告／專題 |  |
| 7. 禮貌結尾 | 感謝＋不強求回覆 |  |

## 三、寫作原則：把「熱忱」換成具體內容

不要只寫：

> 我對教育很有熱忱，希望能跟隨老師學習。

要具體回答教授真正想知道的三件事：

1. 你觀察到什麼教育問題？（哪個場域、哪類對象、什麼狀況重複發生）
2. 你想怎麼研究？（大致的方法方向與可取得的對象）
3. 我的專長為什麼能幫助你？（他的哪個研究、哪個取徑、哪個場域）

## 四、值得問的問題（挑一個）

有效的問題要有實質學術內容、有現場情境、在方法或政策層面具體：

- 系上或老師的研究是否有長期合作的學校或機構，學生能否進入
- 老師是否指導過使用某種方法（例如行動研究、課室觀察）的碩士生
- 某個研究中心的計畫目前是否仍在進行、碩士生有沒有參與空間
- 我的研究問題在該所的訓練取向下是否合適，或需要調整到什麼方向

## 五、可附上的作品（挑一到兩份）

重點不是附件多，而是要有一份東西能替代空泛的熱忱宣告：

- [ ] 大專生研究計畫（含成果或進度）
- [ ] 研究計畫摘要（一頁以內）
- [ ] 教案設計＋實施後的反思
- [ ] 個案報告或輔導紀錄整理（**務必去識別化**）
- [ ] 教學研究或專題報告
- [ ] 現場經驗整理表

## 六、寄信前檢核

- [ ] 信件長度控制在螢幕一頁內，細節放附件
- [ ] 全信只有一個明確問題，且不是「老師會不會收我」
- [ ] 我認真讀過教授近三年的研究，題目與年份沒有寫錯
- [ ] 附件已去識別化，沒有可辨識的學生、學校或個案資訊
- [ ] 附件連結實測可開、不需密碼
- [ ] 收件人姓名、職稱、系所沒有沿用上一封信
- [ ] 避開九月開學後的教學與行政高峰
- [ ] 沒有回覆時，最多禮貌追蹤一次

## 寄信時機

| | 適合做什麼 |
|---|---|
| 7-9 月 | 詢問明年度招生名額與指導量能 |
| 10-11 月送件期 | 信要更短，直接附研究計畫與 CV |
| 大三下或在職期間 | 適合詢問能否旁聽課程或參與研究團隊 |

## 好壞寫法對照

| | 範例 |
|---|---|
| 沒有作用的寫法 | 我對教育充滿熱忱，希望能在您門下學習 |
| 可用的寫法 | 我在○○國中代課兩學期，反覆遇到△△的狀況；您在□□那篇處理的正是這個機制 |
| 差別 | 從具體事件寫起，不是從教育熱忱寫起 |
