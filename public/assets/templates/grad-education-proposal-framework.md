# 現場痛點轉研究問題與計畫可行性檢核表（教育研究所）

> 教育研究計畫最常見的三種寫法——教學方案設計、實習心得、教育熱忱陳述——都不是研究計畫。這份模板帶你走完「現場痛點 → 研究問題 → 文獻缺口 → 可行的研究設計」，並在每一節附上檢核點。
>
> **匯入 Notion**：Import → Markdown。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 〇、先過一個測試

**我的題目有沒有一個「還不知道答案」的問題？**

- 教學方案的答案是已知的（做這套課程）
- 心得的答案是已發生的（我學到什麼）
- 研究計畫必須有一個目前沒人清楚回答、而你打算用某種方法去回答的問題

這個測試通不過，後面寫得再細都沒有用。

## 一、現場痛點 → 研究問題（五步轉換）

| 步驟 | 要做什麼 | 我的內容 |
|---|---|---|
| 1. 寫下具體事件 | 有時間、地點、人、行為。不是「學習動機低落」 |  |
| 2. 確認是否重複發生 | 不同班級／時間／學生身上都出現嗎？ |  |
| 3. 問「為什麼」而不是「怎麼辦」 | 怎麼辦導向方案，為什麼導向研究 |  |
| 4. 收斂對象與情境 | 哪個階段、哪類學生、哪種場域 |  |
| 5. 確認可觀察、可蒐集 | 我做得到的訪談／觀察／問卷能取得答案嗎 |  |

**自我檢查**：把研究問題唸給一個非教育領域的朋友聽。他若問「所以你想知道什麼？」代表還沒收斂；他能複述你的問題，通常就過關了。

## 二、十節架構（每節都要回答一個問題）

| 節次 | 內容 | 要回答的問題 | 我的內容 |
|---|---|---|---|
| 1 | 題目 | 看得出對象、情境與焦點嗎？ |  |
| 2 | 研究動機 | 這個困惑從哪個真實現場來？ |  |
| 3 | 研究背景 | 這件事在台灣的脈絡是什麼？ |  |
| 4 | 研究問題與目的 | 我要回答的具體問題是哪一到兩個？ |  |
| 5 | 文獻探討 | 前人做到哪裡？缺口在哪？ |  |
| 6 | 研究方法 | 這個方法為什麼能回答我的問題？ |  |
| 7 | 研究對象與資料蒐集 | 對象怎麼來？資料怎麼取得？ |  |
| 8 | 研究倫理 | 誰同意？怎麼保護？ |  |
| 9 | 預期貢獻 | 對學術與現場各有什麼意義？ |  |
| 10 | 研究限制與時程 | 我知道自己的方法有什麼做不到？ |  |

> 第十節常被省略，但它是加分項——主動說明限制，代表你理解方法的邊界，而這正是口試想確認的能力。

## 三、文獻探討：四個必答問題

- [ ] 這個題目在國內外被研究到哪裡？主要理論取徑有哪幾種？
- [ ] 前人的結論是否一致？不一致的差異出在對象、情境還是方法？
- [ ] 還缺什麼？（缺對象群體／缺情境／缺方法／缺台灣脈絡驗證／缺新政策的實證檢視）
- [ ] 我的研究補的是上面哪一塊？

> 寫法：依**議題或概念**分組，不要依文獻順序逐篇摘要。每一塊結尾收一句「這塊已經清楚的是什麼、還沒處理的是什麼」，缺口就會自然浮現。
> 查詢：碩博士論文用「臺灣博碩士論文知識加值系統」（ndltd.ncl.edu.tw）；期刊與國際文獻用 Google 學術搜尋。讀論文先看摘要、研究問題、方法、結論四段再決定要不要細讀。

## 四、方法選用對照

| 方法 | 適合回答的問題 | 要考慮的事 | 我的選擇 |
|---|---|---|---|
| 量化問卷／既有資料分析 | 有多少、哪些因素相關、兩組有無差異 | 樣本取得、量表來源與信效度 |  |
| 質性訪談 | 他們怎麼理解、為什麼這樣決定 | 受訪者選取邏輯與人數依據 |  |
| 課室觀察 | 現場實際發生什麼、互動細節 | 進場次數、記錄方式、觀察者角色 |  |
| 行動研究 | 在我的現場，某種調整會帶來什麼變化 | 需要一個能長期進出的現場 |  |
| 個案研究 | 特定學生／班級／學校／單位的深入理解 | 個案選取理由、資料多元性 |  |
| 文件與政策分析 | 政策文本、課綱、校務資料的分析 | 文件取得範圍與分析架構 |  |

**工作量換算**（超過一年半就該收斂）：訪談幾人＿＿／逐字稿幾小時＿＿／進場幾次＿＿／問卷幾份＿＿／要不要跑統計＿＿

## 五、研究對象取得與倫理

- [ ] 研究對象從哪裡來？（自己的場域／教授的合作學校／公開招募）
- [ ] 需要誰同意？（學校端、家長或監護人、學生本人意願）
- [ ] 是否涉及特定學校師生？行政程序的時間成本算進時程了嗎？
- [ ] 是否涉及諮商個案或特教學生？保密與去識別化怎麼規劃？
- [ ] 是否需要研究倫理審查（IRB／REC）？**依各校規定與研究性質而定，以就讀學校規範為準**；申請階段至少要顯示知道有這一關並算進時程
- [ ] 參與者能不能中途退出？資料存多久、怎麼銷毀？

> 這一節不需要長，但一定要有。寫出「對象怎麼來、誰同意、怎麼保護、時程怎麼算」，就勝過大部分只寫一句「將遵守研究倫理」的計畫。

## 六、常見失分寫法

| 失分寫法 | 為什麼扣分 | 改成 |
|---|---|---|
| 研究動機寫成教育熱忱 | 沒有可檢驗的問題 | 從具體事件寫起 |
| 題目大到兩年做不完 | 可行性為零 | 收斂對象、情境與問題數 |
| 方法寫成教科書定義 | 沒有資訊量 | 說明在我的題目上怎麼用 |
| 文獻逐篇摘要 | 看不出缺口 | 依議題分組並收缺口 |
| 研究對象沒有著落 | 計畫執行不了 | 寫清楚管道與同意流程 |
| 倫理一句話帶過 | 顯示沒想過現實 | 補上同意、保密與退出機制 |

## 七、送出前的五個檢核

- [ ] 我的研究問題是否來自具體的教育現場？
- [ ] 是否已找到核心文獻與明確的研究缺口？
- [ ] 方法是否真的能回答我的問題？
- [ ] 研究對象是否可以取得？
- [ ] 是否考慮了倫理與隱私問題？
