# 備審主線整理表

> 把所有經歷攤開來，再用「與目標科系的關聯」找出能串成一條主線的那幾項。
>
> **匯入 Notion**：Import → Markdown 後，下表會變成 Notion 表格；建議再切換成資料庫（Database）方便篩選與排序。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 第一步：把所有經歷列出來

| 經歷／活動 | 時間 | 類型 | 我做了什麼（具體） | 學到／展現的能力 | 與目標科系的關聯 | 佐證連結／檔案 |
|---|---|---|---|---|---|---|
| 範例：自製選課小工具 | 2025 暑 | Side Project | 用 Python 寫出能自動比對課表衝堂的小程式 | 程式實作、解決真實問題 | 資工系：問題意識與動手能力 | GitHub 連結 |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |

> 「類型」可填：Side Project／競賽／自學／研究／志工／幹部／課程專題

## 第二步：找出主線

- [ ] 圈出「與目標科系的關聯」最強的 3–5 項
- [ ] 看這幾項之間有沒有共同的方向或主題
- [ ] 用一句話寫出主線：我是一個 ＿＿＿＿ 的學生，因為我持續在做 ＿＿＿＿
- [ ] 其餘經歷，作為支撐或補充，不一定每個都要寫進備審

> 主線不是「最多的活動」，而是「最有邏輯的故事」。

## 主線整理完，接著對照校系

主線回答的是「你是誰」，落點回答的是「哪些校系接得住你」。兩件事要一起看，志願序才排得出來。

TBD Growth Compass 可以把你想比的校系存成一份工作集，用歷年篩選標準算出你的相對位置：

→ https://tbd-web.vercel.app/pages/placement.html?utm_source=tbd-web&utm_medium=template&utm_campaign=admission-main-thread

基本功能免費，資料存在你自己的帳號裡，換裝置也還在。
