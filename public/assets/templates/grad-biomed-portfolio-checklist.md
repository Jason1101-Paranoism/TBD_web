# 生醫與公衛備審 Checklist（CV／自傳／專題）

> 生醫與公衛備審不是比誰經歷最多，而是看研究經驗是否可信、技術是否真實、專業是否有累積。逐項勾完再送件。
>
> **匯入 Notion**：Import → Markdown。**用 Google Docs**：直接貼上。

## 學術 CV 欄位

- [ ] Education
- [ ] Research Interests
- [ ] Research Experience
- [ ] Experimental Skills
- [ ] Statistical／Programming Skills
- [ ] Projects
- [ ] Publications／Posters／Presentations
- [ ] Awards
- [ ] Relevant Coursework
- [ ] Certifications（僅保留真正相關者）

## 技術清單：具體化，不只列名詞

| 避免只列 | 建議具體化 |
|---|---|
| PCR | 能獨立完成 qPCR 前處理、反應配置與基本結果判讀 |
| 細胞培養 | 具備哺乳類細胞培養、傳代與污染監測經驗 |
| SPSS／R | 用 R 完成資料清理、描述統計、迴歸分析與視覺化 |

## 專題經歷應呈現

- [ ] 問題與你的角色
- [ ] 方法與實驗／分析次數
- [ ] 遇到的失敗與如何修正
- [ ] 最終結果與個人貢獻
- [ ] 研究限制（誠實寫出失敗與迭代，比完美結果更可信）

## 自傳檢核

- [ ] 如何從課程、實驗或研究形成研究興趣
- [ ] 為何選擇特定研究方向
- [ ] 為何申請此校所與教授（連結教授近年研究）
- [ ] 既有能力如何支撐下一階段研究
- [ ] 未來希望解決什麼問題

## 一致性檢核

- [ ] CV、自傳、研究計畫講的是同一條研究主線
- [ ] 技術清單裡的每一項，口試都能解釋細節
- [ ] 沒有誇大或無法佐證的敘述
