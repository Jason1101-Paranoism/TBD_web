# 口試立場論證與反駁答辯檢核表（法政研究所）

> 法政口試與理工、商管最大的不同：研究問題往往沒有絕對正確的答案。教授追問的不是「你答對了嗎」，而是**你的立場站不站得住、推論前後一不一致、面對反駁時能不能理性處理**。教授刻意提出反方觀點，是在測試你是否真的理解自己選的立場——不是要你辯贏。

## 第三段：六步答題框架

被追問時照這個順序走，不會慌。

1. **確認問題**——「老師的意思是，如果從○○的角度來看，我的推論會有問題，是嗎？」
2. **表明核心立場**——不迴避、不模糊。
3. **提供理論或資料依據**——說出你為什麼這樣選。
4. **說明限制**——主動承認方法答不了什麼。
5. **回應反例**——正面處理教授提出的情況，不要繞開。
6. **提出修正範圍**——說明哪些可以調整、哪些是核心不動。

**被指出矛盾時的句型**（先抄下來，再改成自己的話）

> 這個質疑確實指出目前計畫的一個限制。原先我的立場是基於＿＿＿，但若納入老師提到的情況，我會將研究範圍重新界定為＿＿＿，並補充＿＿＿方法或文獻來檢驗。

**不要出現的三種反應**

- [ ] 硬凹到底，把口試當辯論賽要贏。
- [ ] 立刻全面棄守，教授一問就說「老師說得對，我會全部改」——這代表你原本的立場沒有想過。
- [ ] 情緒化表述，用價值宣稱代替論證（「我覺得這樣才是正義的」）。

## 第四段：上場前檢核

- [ ] 我準備過至少兩種與我對立的觀點，並知道它們最強的論據是什麼。
- [ ] 我知道自己研究方法最大的限制，也想好了補足規劃。
- [ ] 我能分清楚：哪些是可以修正的技術細節，哪些是動了就不是這個研究的核心立場。
- [ ] 我讀過口試委員（不只指導教授）的研究方向，能預判他們會從哪個角度問。
- [ ] 我的計畫書裡沒有任何一句是我答不出出處的。
- [ ] 我練習過被打斷、被質疑語氣追問時的反應，不只是順順地講一遍。
- [ ] 我知道自己不會的題目要怎麼回答——誠實說明目前的理解程度與後續會怎麼補，而不是硬編。
- [ ] 服裝、時間、地點、線上設備與備援方案都確認過。
