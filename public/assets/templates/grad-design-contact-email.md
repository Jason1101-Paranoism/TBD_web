# 設計類群聯繫教授信結構模板（設計傳播研究所）

> 設計套磁與其他學群最大的不同：**你的作品比你的自我介紹更有說服力，但作品也最容易被誤讀**。一封只有文字的信，教授看不出你的視覺判斷；一封塞了 30 頁作品集的信，教授不會打開。這份模板的重點是「怎麼在一封信裡讓作品被看見，而且被看成你想要的樣子」。
>
> **先判斷該不該寄**：設計所的套磁必要性依學校差異很大。實務創作型的系所常常更看重作品集本身；學術研究型、或指導教授制明確的系所，事前聯繫的價值才高。
>
> **匯入 Notion**：Import → Markdown 後可切換成資料庫。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 第一段：先判斷該不該寄

兩組條件，任一組成立才值得寄。都不成立就把時間花在作品集上。

| 判斷條件 | 我的情況 | 成立？ |
|---|---|---|
| 該系所明確採指導教授制，入學即分配或需事先聯繫 |  |  |
| 我的研究方向明確對應到某位教授的近期作品或論文 |  |  |
| 我有具體問題要問（課程外的合作、實驗室設備、業界連結） |  |  |
| 系所公告或榜單上寫明鼓勵事前聯繫 |  |  |

- [ ] 我查過這位教授**近三年**的作品／展覽／論文，不是只看系網頁的研究興趣欄。
- [ ] 我說得出他最近一件作品在做什麼，而且我的說法不是抄簡介。
- [ ] 我不是同一封信群發給五位教授。

## 第二段：七段信件結構

| 段落 | 這一段要做到 | 我的版本 |
|---|---|---|
| 主旨 | 一眼看出身分與意圖：「請教研究方向｜OO大學OO系 王小明」 |  |
| 自我定位 | 一句話：學校、背景、目前在做什麼 |  |
| 為什麼是他 | 指名一件具體作品／論文，說出你看到什麼，不是稱讚 |  |
| 你的方向 | 你想探討的問題，一到兩句，可以還不成熟但要具體 |  |
| 作品連結 | 一個連結，指向精選版不是全集 |  |
| 具體請求 | 你希望他做什麼：回覆是否收生、10 分鐘線上談、或只是知會 |  |
| 收尾 | 感謝＋不強求回覆，附上完整聯絡方式 |  |

- [ ] 全信在 300 字以內，手機一屏讀得完。
- [ ] 沒有任何一句可以原封不動貼給另一位教授。
- [ ] 「為什麼是他」那段拿掉之後，這封信就不成立——如果拿掉還通順，代表你寫的是罐頭。

## 第三段：作品怎麼附

設計套磁最容易失敗的一步。教授不會下載附件，也不會看 30 頁。

| 方式 | 適用 | 我的選擇 |
|---|---|---|
| 線上作品集連結（個人網站／Behance／Notion） | 幾乎所有情況的預設 |  |
| 三件精選的單頁 PDF（3MB 以內） | 對方明說可寄附件時 |  |
| 內文直接嵌一張代表圖 | 想讓對方不點連結也看得到一眼 |  |
| 完整作品集 | **不要在套磁信階段寄** |  |

- [ ] 連結是**精選版**：三到五件，不是全部。
- [ ] 每件作品旁有一句話說明「這件在解什麼問題」，不只有標題與年份。
- [ ] 連結不需要密碼、不需要登入、手機打得開。
- [ ] 排在最前面的那件，和我在信裡講的研究方向有關。

## 第四段：寄信前八項檢核

- [ ] 收件人姓名與職稱正確（教授／副教授／助理教授不要寫錯）。
- [ ] 系所名稱與學校全名正確，沒有殘留上一封信的名字。
- [ ] 主旨有身分、有意圖，沒有「您好」這種空主旨。
- [ ] 作品連結我自己用無痕視窗開過一次，確定打得開。
- [ ] 全信讀出來沒有錯字，專有名詞（設計運動、方法論、軟體名）拼寫正確。
- [ ] 沒有要求對方「指導我準備考試」或「幫我看作品集」——那是超出初次聯繫的請求。
- [ ] 寄件時間避開深夜與假日。
- [ ] 我接受不回覆也是一種答覆，而且不會再寄第二封追問。
