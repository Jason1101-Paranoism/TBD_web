# 理工研究計畫書架構模板

> 理工計畫書的定位：技術匹配度與即戰力的佐證。每一節都在回答教授心中的一個問題。
>
> **匯入 Notion**：Import → Markdown。**用 Google Docs**：直接貼上，逐節填寫。

## 七節架構

| 章節 | 要回答的問題 | 檢查點 |
|---|---|---|
| 1. 研究背景 | 這個領域現在的狀態是什麼？ | 有沒有收斂到具體的子題，而不是整個領域的教科書介紹？ |
| 2. 問題意識 | 我要解決的具體問題是什麼？為什麼值得解？ | 問題是從你做過的事長出來的，還是從網路上抄來的？ |
| 3. 相關文獻與技術 | 別人怎麼做？做到哪裡？ | 有沒有讀過目標教授的近年論文並引用？ |
| 4. 研究方法 | 我打算用什麼工具與方法做？ | 每個工具與方法，你在修課／專題／實習中真的用過嗎？ |
| 5. 預期成果 | 做完會得到什麼？怎麼驗證？ | 碩士兩年內做得完嗎？需要的設備與數據拿得到嗎？ |
| 6. 與目標實驗室的關聯 | 這個題目和教授的研究有什麼實質接點？ | 這一節換一間實驗室還能用嗎？能用就是沒做功課。 |
| 7. 自己已有的基礎 | 我憑什麼做得動這個題目？ | 每項宣稱都能在 CV 的專題、課程、實習中找到依據嗎？ |

## 送出前的三個檢核問題

- [ ] 計畫中的核心工具與方法，能在我過去的修課、專題或實習中找到實際操作的依據嗎？
- [ ] 我的研究方法是立足於已掌握的技術做延伸，還是跳進一個尚未具備核心能力的新領域？
- [ ] 這個題目與目標教授近年的研究計畫或論文，有實質關聯嗎？

## 四種常見的失分寫法

- 文獻整理式：通篇沒有自己的問題意識與技術足跡
- 跨度過大：題目和自己的背景脫節，方法段落寫不出細節
- 與實驗室無關：教授找不到收你的理由
- 不可執行：範圍大到像博士論文，或設備數據拿不到
