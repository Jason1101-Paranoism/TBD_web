# 實驗室與教授評估表（農生與環境研究所）

> 這個類群選錯實驗室的代價特別高——你的研究能不能做完，取決於經費、儀器、樣區與耗材，而這些跟著實驗室走、不跟著校名走。查清楚再放進同一張表比較，決策才會清楚。

> 兩個提醒：**空白格本身就是資訊**——查不到經費、問不到畢業狀況，代表這間的資訊透明度低，那是判斷的一部分，不是「還沒查完」。**每一間都要寫出一個你最擔心的地方**，三間都完美通常代表查得不夠深。

## 查證管道

- [ ] 近三年論文：看方法、材料與作者序，判斷技術線與碩士生參與程度
- [ ] 計畫清單：教授個人頁或實驗室網頁，看經費的連續性
- [ ] 系所碩士論文庫：翻近幾屆題目與完成年份，推出畢業節奏與題目規模
- [ ] 學長姐：問可驗證的事實，不要問「好不好」
- [ ] 實驗室參訪或旁聽 meeting：判斷生活型態最直接的方式
- [ ] 系所簡章與招生名額公告：確認今年是否真的收生

## 陷阱檢核

- [ ] 我沒有只看校名排序，而是先比資源與生活契合度
- [ ] 我確認過需要的儀器在**這間**實驗室排得到，不是「學校有」
- [ ] 我問過耗材由誰支應，而不是假設實驗室會出
- [ ] 我確認過樣區的可進入季節，而不是假設全年都能去
- [ ] 我知道這間近三年有沒有人延畢，以及原因
- [ ] 我沒有把教授過去的代表作，當成他現在還在做的方向
- [ ] 我確認過明年是否真的收生（名額、休假、退休三種都問過）

## 填完後的三個檢核問題

- [ ] 這間實驗室的經費、儀器、樣區與耗材，足以支撐我想做的題目而不會延畢嗎？
- [ ] 照顧生物或進行野外採樣的週期，符合我的生活步調嗎？教授對假日與駐點的態度我確認過嗎？
- [ ] 近幾年的碩士生畢業狀況與去向，跟我想走的方向對得上嗎？
