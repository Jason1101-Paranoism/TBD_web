## 陷阱檢核

- [ ] **關鍵字相同 ≠ 取徑相同**：我讀過目標教授近三年的至少一篇論文，看得出他用什麼材料、引哪一批學者、方法怎麼寫。
- [ ] **系名相同 ≠ 傳統相同**：我比較過同名系所在時期、學派、方法、區域與實務導向上的差異，不是只看排名。
- [ ] 同一個關鍵詞在不同教授手上方法完全不同，這件事已確認過
- [ ] 系所資訊以官方課程結構與當年度簡章為準

## 填完後檢核

- [ ] 研究題目已界定時期、對象、材料與議題
- [ ] 了解目標教授使用的理論與方法，不只是他研究什麼
- [ ] 讀過目標系所近年的碩士論文
- [ ] 選校不再只依靠排名與系名
- [ ] 名單中保留一所方法訓練與資料取得明確可行的底線選項

## 查證管道

| 查證管道 | 說明 |
|---|---|
| 臺灣博碩士論文知識加值系統 | 讀近年碩士論文，是投報率最高的一件功課 |
| Google 學術搜尋 / 華藝線上圖書館 | 查教授近三年論文，看方法段與引用的學者 |
| 官方課程結構與必選修清單 | 判斷方法訓練有沒有真的開課 |
| 當年度招生簡章 | 評分配比與招生方式，每年會變 |
| 現任學生與學長姐 | 指導方式、館藏實際可用性、田野經費 |

> 查法提示：系所官網的課程地圖與修業規定，看它在訓練什麼人；教授近三到五年的發表看「怎麼研究」而不只是「研究什麼」；**近年碩士論文清單是投報率最高的一份資料**，它直接顯示這裡實際做得出什麼題目、用什麼材料、寫到什麼深度。建議每所至少讀三到五本論文的摘要與目次。
