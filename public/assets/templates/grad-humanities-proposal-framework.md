# 研究問題形成與文獻對話整理表（人文與社會科學研究所）

> 人文社科研究計畫的核心，是證明你能從既有文獻中辨識尚未被充分回答的問題。這份模板分四段：問題收斂五步、十節架構、文獻對話表、範圍與可行性檢核。
>
> **匯入 Notion**：Import → Markdown 後，表格可切換成資料庫。
> **用 Google Docs / Sheets**：表格可直接貼上。

| 3 解釋不足 | 哪類對象沒被看／哪種機制沒被檢驗／哪個時期沒被處理 |  |

| 節次 | 要回答的問題 | 常見失分 | 我的內容 | 完成 |

| 2 問題意識 | 為什麼值得問既有解釋哪裡不夠 | 只描述現象沒指出縫隙 |  |  |
| 3 研究問題 | 一到三個可回答的問句主問題只有一個 | 沒有出現問句 |  |  |

## 常見失分點自我對照

- [ ] 寫成主題介紹沒有出現問句
- [ ] 寫成文獻摘要集合學者之間沒有對話
- [ ] 寫成個人興趣陳述
- [ ] 寫成社會議題評論沒有研究設計
- [ ] 方法段沒回答為什麼能回答我的問題
- [ ] 範圍過大且答不出縮小方案

## 送出前檢核

- [ ] 研究問題是一個問句而且主問題只有一個
- [ ] 問題是從既有解釋的縫隙裡長出來的
- [ ] 節次 2-4 是同一條線
- [ ] 材料數量與取得方式都寫清楚了
- [ ] 兩年內做得完且材料拿得到

> 現象或文本 → 既有解釋 → 解釋不足 → 研究問題 → 分析方法

> 檢核：第 2、3、4 節必須是同一條線上的三個刻度。問題意識講 A、研究問題問 B、文獻回顧整理 C，是最常見的失敗模式。
