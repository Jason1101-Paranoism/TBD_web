<section class="article-section" id="why-now">
## 為什麼現在比以前更重要

幾年前，做一個個人網站需要學 HTML、CSS、JavaScript，或者花時間搞懂 WordPress 的設定。這個門檻讓「有個人網站」成為一個有意義的能力指標——因為能做出來代表你花了時間學了東西。

現在，AI 工具讓這個技術門檻幾乎消失了。任何人都可以用幾個小時做出一個像樣的個人網站。

這個變化帶來兩件事：第一，沒有個人網站的成本提高了——因為現在做一個網站「很難」不再是借口。第二，有個人網站的差異化改變了——不再是「你會不會做」，而是「你在網站上展示了什麼、這個網站有多清楚地說明了你是誰」。

個人網站從一個技術門檻，變成了一個主動性和自我定位的指標。
</section>

<section class="article-section" id="what-it-shows">
## 個人網站展示的不只是技術

當一個教授、面試官或招生委員在書審之前或之後搜尋你的名字，如果他找到一個整理得清楚的個人網站，他得到的資訊會比任何備審文件都更直接：

**你的方向感。** 網站的主題和你放上去的內容，會告訴他你長期在關注什麼、往哪個方向在走。一個一直在做 AI 教育相關 Side Project 的學生，和一個只有活動清單的學生，給人的印象完全不同。

**你的整理能力。** 能把自己的經歷整理成一個讓別人看得懂的頁面，這本身是一種能力——你要知道什麼重要、什麼不重要，你要能說清楚自己做了什麼。

**你的主動性。** 不是因為學校要求，不是因為申請需要，而是你自己決定建立一個對外展示自己的地方——這個主動性，在評審眼裡是一個有意義的訊號。
</section>

<section class="article-section" id="levels">
## 三個層級的個人網站

個人網站不需要從一開始就做得很完整，可以按照你的階段和需求逐漸建立。

**Level 1：整理頁面（最快，立刻可以開始）**

一個 Notion 頁面，整理你的自我介紹、在做的 Side Project、以及你的聯絡方式和 GitHub 連結。這不是一個「真的網站」，但它讓你有一個可以分享的 URL，裡面有比 LinkedIn 個人頁更清楚的內容。Notion 頁面可以設定公開，直接分享連結。

**Level 2：靜態網站（門檻低，效果明顯）**

用 GitHub Pages、Vercel 搭配一個簡單的 HTML 模板，或者用 Framer、Webflow 等工具，做出一個有基本設計感的個人頁面。包含：自我介紹、作品集、技能方向、聯絡方式。這個層級的網站，對大部分高中生來說已經足夠有說服力。

**Level 3：客製化網站（展示工程能力）**

用 React、Astro 或 Next.js 從頭做，自己部署到 Vercel 或 Netlify。這個層級的網站，除了內容本身，做出來的過程本身就是一個值得放進備審的 Side Project——你學了某個技術、做出了一個真正上線的作品。對資工、AI 方向的學生，這是最有說服力的個人網站形式。
</section>

<section class="article-section" id="tools">
## 從哪裡開始

**最快開始：Notion**
把你目前有的東西整理到一個 Notion 頁面，設定公開，你今天就有一個可以分享的個人頁面了。

**好看但不需要寫程式：Framer / Webflow / Squarespace**
這些工具有現成的模板，拖拉就能做出有設計感的網站。適合設計、商管、傳播方向的學生，或者想快速有一個好看頁面的人。

**有 GitHub 連動、免費部署：GitHub Pages**
在 GitHub 上建一個 repository，放進一個 HTML 檔案，就能直接用 `username.github.io` 的網址存取。適合已經在用 GitHub 的學生，是最自然的延伸。

**有工程感的方向：Astro / Next.js + Vercel**
學習成本較高，但做出來的網站是一個完整的工程作品。如果你打算申請[資工或 AI 相關科系](/pages/resources/cs-ai-application.html)，這是最值得投資的選擇——因為做網站的過程就是在展示能力。
</section>

<section class="article-section" id="content">
## 網站裡放什麼最重要

個人網站最大的問題，通常不是技術，而是**不知道要放什麼、或者放了一堆東西卻沒有重點**。

優先放這幾件事：

**清楚的自我介紹（兩到三句話）**：你在哪讀書、你對什麼有興趣、你目前在做什麼。不需要很長，需要的是讓第一次看到你頁面的人在十秒內知道你是誰。

**一到三個你最重要的作品**：選你最有代表性的，每個作品用一段話說清楚：這是什麼、為什麼你做它、你在過程裡學到了什麼。附上 GitHub 連結、Demo 連結或截圖。

**你的方向和興趣**：不只是技能清單，而是說清楚你在往哪個方向走、你對什麼問題有長期興趣。

**聯絡方式**：Email、GitHub，有需要的話加上 LinkedIn 或其他社群帳號。

不需要把所有活動都放上去。個人網站不是備審的複製，它是你主動整理和策展的結果——放最能代表你的東西，讓看的人能快速形成一個清楚的印象。
</section>
