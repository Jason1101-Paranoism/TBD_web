# 研究問題形成與文獻對話整理表（人文與社會科學研究所）

> 人文社科研究計畫的核心，是證明你能從既有文獻中辨識尚未被充分回答的問題。這份模板分四段：問題收斂五步、十節架構、文獻對話表、範圍與可行性檢核。
>
> **匯入 Notion**：Import → Markdown 後，表格可切換成資料庫。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 一、問題收斂五步

> 現象或文本 → 既有解釋 → 解釋不足 → 研究問題 → 分析方法

| 步驟 | 要回答什麼 | 我的內容 |
|---|---|---|
| 1. 現象或文本 | 我真正好奇的對象是什麼（具體到可以指出來） |  |
| 2. 既有解釋 | 目前學界怎麼解釋它（列出兩到三種） |  |
| 3. 解釋不足 | 哪一類對象沒被看、哪一種機制沒被檢驗、哪一個時期沒被處理 |  |
| 4. 研究問題 | 寫成一個問句，主問題只有一個 |  |
| 5. 分析方法 | 用什麼材料與方法回答這個問句 |  |

### 縮小題目的六個追問

- [ ] 哪一類對象？（年齡、身分、地域、社群）
- [ ] 哪一個平台、文本或場域？
- [ ] 哪一種行為、現象或面向？
- [ ] 哪一個時間區間？
- [ ] 既有研究怎麼解釋這件事？
- [ ] 目前還缺什麼？

## 二、十節架構

| 節次 | 內容 | 完成度 | 備註 |
|---|---|---|---|
| 1 研究背景 | 現象、文本或議題的脈絡 |  |  |
| 2 問題意識 | 為什麼值得問、既有解釋哪裡不夠 |  |  |
| 3 研究問題 | 一到三個可回答的問句 |  |  |
| 4 文獻回顧 | 既有討論的地圖、爭論與缺口 |  |  |
| 5 理論視角 | 用哪套概念工具、為什麼是它 |  |  |
| 6 研究材料 | 文本、史料、受訪者、檔案，數量與來源 |  |  |
| 7 研究方法 | 怎麼處理材料，步驟具體到可被檢驗 |  |  |
| 8 研究範圍 | 時間、地域、對象、面向的界線 |  |  |
| 9 預期貢獻 | 回答之後既有討論會多出什麼 |  |  |
| 10 可行性與限制 | 材料拿不拿得到、做不到的是哪些 |  |  |

> 檢核：第 2、3、4 節必須是同一條線上的三個刻度。問題意識講 A、研究問題問 B、文獻回顧整理 C，是最常見的失敗模式。

### 兩個寫作檢核

- [ ] 把段落開頭的學者姓名全部拿掉，這段還讀得懂嗎？（讀得懂＝在整理觀點；讀不懂＝還停在摘要）

## 四、範圍、可行性與限制

| 項目 | 要回答什麼 | 我的內容 |
|---|---|---|
| 時間範圍 | 做哪一段時期，為什麼 |  |
| 地域範圍 | 做哪個地區或場域 |  |
| 對象範圍 | 幾份文本／幾位受訪者／哪一批檔案 |  |
| 面向限定 | 只處理其中哪一個機制或面向 |  |
| 材料取得 | 是否開放、需不需申請、有無語言門檻 |  |
| 時間可行性 | 兩年內做得完嗎，最花時間的是哪一步 |  |
| 研究倫理 | 需不需要審查，要多久 |  |
| 已知限制 | 結論適用到哪裡為止 |  |
| 替代方案 | 材料取得失敗時改用什麼 |  |

## 五、常見失分點

- [ ] 寫成主題介紹：通篇說明議題有多重要，沒有出現一個問句
- [ ] 寫成文獻摘要集合：每段「某某（年）指出……」，學者之間沒有對話
- [ ] 寫成個人興趣陳述：談自己怎麼喜歡上這個題目（那屬於自傳）
- [ ] 寫成社會議題評論：有批評與呼籲，沒有研究設計
- [ ] 方法段沒有回答「這個方法為什麼能回答我的問題」
- [ ] 範圍過大，被問「你做得完嗎」答不出縮小方案
