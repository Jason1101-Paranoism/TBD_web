## 五步答題框架

> **確認問題 → 說明原始設計 → 解釋技術依據 → 承認限制 → 提出替代方法**

| 步驟 | 作用 | 我的練習 |
|---|---|---|
| 1 確認問題 | 確保答的是他問的，也替自己爭取思考時間 |  |
| 2 說明原始設計 | 證明有想過，不是隨便排的 |  |
| 3 解釋技術依據 | 支撐這個設計的原理或文獻 |  |
| 4 承認限制 | 這個設計確實不能排除什麼 |  |
| 5 提出替代方法 | 如果重新設計會怎麼補 |  |

> 價值在第 4、5 步。多數人被質疑時的直覺是防守或投降，兩者都錯過了委員真正想看的東西——能不能理性處理批評並提出修正。

## 常見失分點自我對照

- [ ] 一句話說明講成研究背景，三十秒還沒進到自己要做什麼
- [ ] 只答得出技術的優點，答不出限制與盲點
- [ ] 被指出對照組問題時只道歉，沒有提出替代設計
- [ ] 準備了實驗設計與方法類，卻在「這台儀器排得到嗎」這種可行性題卡住
- [ ] 統計方法答不出為什麼選它、樣本數夠不夠
- [ ] 假設被推翻時，說不出論文還能怎麼寫
- [ ] 備審寫了、但講不出細節的技術
