## 二、CTA Tracking（UTM 參數）

### 目標
在主要 LINE 諮詢 CTA 加 UTM，追蹤哪個頁面帶來最多諮詢。

### UTM 結構
```
?utm_source=website&utm_medium=cta&utm_campaign={頁面名稱}
```

### 涵蓋範圍

| 頁面 | utm_campaign |
|------|-------------|
| 首頁 Hero | `home-hero` |
| 首頁底部 CTA | `home-footer` |
| 服務內容頁 | `services` |
| 成功案例頁 | `cases` |
| 合作流程頁 | `process` |
| 知識庫頁 | `resources` |

### 範圍限制
- 只改 `src/pages/*.html` 內的「預約策略諮詢」、「免費諮詢」LINE 連結
- `src/partials/nav.html`、`src/partials/footer.html` 的 LINE icon **不加 UTM**（避免污染數據）

## 三、build.py 部署檢查

### 新增功能（build 結束後自動執行）

**1. 產生 sitemap.xml**
- 來源：`src/config.json` pages 資料 + resources 子頁
- 輸出：根目錄 `sitemap.xml`
- 格式：標準 XML sitemap，含 `<loc>` 與 `<lastmod>`

**2. description 完整性檢查**
- 掃描 config.json 每一頁的 `description` 欄位
- 空白則警告：`[WARN] missing description: resources/index`

**3. 內部 href 存在性檢查**
- 掃描所有 `pages/**/*.html` 的 href 屬性
- 過濾外部連結（http、mailto、tel、#）
- 指向不存在檔案則警告：`[WARN] broken link: /pages/xxx.html`

### 不在本次範圍
- 重複 id 檢查（複雜度高，效益低）

## 執行順序
