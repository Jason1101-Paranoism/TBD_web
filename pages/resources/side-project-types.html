Side Project 指南

高中生可以做哪些 Side Project？

Side Project 不等於「大型專題」。這篇文章整理了五大類型的高中生作品方向，並依科系目標提供具體範例，幫助你找到適合自己的起點。

五大類型的 Side Project

高中生可以做的 Side Project，大致可以分成五類。每一類都能對應不同的科系方向，也各自需要不同程度的技術基礎。

  • AI / 程式類：Chatbot、個人網站、自動化工具、資料分析 Dashboard、Discord Bot。適合資工、AI、電機、資訊管理方向。
  • 研究 / 資料分析類：科展延伸、文獻整理、問卷研究、Kaggle Notebook。適合生科、醫學、心理、社科、統計方向。
  • 社群 / 品牌 / 商業類：Instagram 主題帳號、Podcast、小型創業 MVP、商業企劃書。適合商管、行銷、傳播、創業方向。
  • 工程 / Maker 類：Arduino、IoT、機器人、3D 列印、循跡車。適合機械、電機、工程、Robotics 方向。
  • 教育 / 學習工具類：自製講義、題庫網站、AI 教學工具、Discord 學習社群。適合教育、AI、傳播、心理方向。

重點不是選「最熱門」的類型，而是選「最能連結你申請方向」的類型。一個跟科系方向直接掛勾的小專案，說服力遠超過跟申請方向無關的大型競賽。

不同科系方向的具體建議

以下依科系方向列出最適合的 Side Project 類型，以及評審通常最在意的能力重點。

  • 資工 / AI / 電機：重點在「能不能把系統做起來並說清楚」。可以從 GitHub Project 開始，搭配 APCS、Hackathon 或 Kaggle 競賽，讓作品有可驗證的能力軌跡。成果建議放在 GitHub，並附上 Demo 連結或操作影片。
  • 商管 / 創業：重點在「有沒有對市場和使用者的真實觀察」。品牌經營、社群數據分析、小型電商測試都是好起點。成果可以是一份商業企劃書、社群帳號數據、或 MVP 網站。
  • 醫學 / 生科 / 心理：重點在「問題意識與研究能力」。問卷研究、科展延伸、文獻回顧都是可行的形式。不需要得大獎，但要能說清楚「你發現什麼問題」以及「你怎麼試著回答它」。
  • 設計 / 傳播：重點在「視覺表達和敘事能力」。UI/UX Prototype、短影音企劃、品牌設計都適合。成果可以放在 Behance 或個人網站，Figma Prototype 附上操作說明效果很好。
  • 工程 / 機械：重點在「動手實作與系統整合」。Arduino、IoT、Robotics 都是可以從高中開始累積的方向。成果建議有 Demo 影片，加上電路圖或技術說明文件。

難度分級：從入門到申請亮點

Side Project 不需要一開始就做到「申請等級」。比較好的方式是逐步累積——先完成一個小的，再延伸成更完整的成果。

  • 入門型（Level 1）：個人網站、學習筆記整理、簡單 Discord Bot、Notion 學習系統、Instagram 主題帳號。目標是「先完成，不求完美」，建立動手做的習慣與留下成長紀錄。
  • 進階型（Level 2）：AI 摘要工具、Kaggle Notebook、Arduino 感測器專題、小型問卷研究、社群行銷分析。目標是能展示方法、數據與優化過程，開始讓評審看到你的思考方式。
  • 申請亮點型（Level 3）：可公開使用的 AI 工具、完整研究報告、小型創業 MVP、機器人競賽作品、有使用者回饋的教育平台。這個等級的成果可以直接放進備審、面試，或國外申請材料。

多數高中生從 Level 1 起步，在高二前後進入 Level 2，高三有一到兩個 Level 3 的代表作就很夠了。

什麼樣的 Side Project 真正有說服力？

好的 Side Project 不一定規模最大，但通常具備五個元素：

  • 問題意識（Problem）：你想解決什麼問題？這個問題從哪裡來？是自己觀察到的，還是老師指定的？前者說服力遠高於後者。
  • 執行過程（Process）：你怎麼研究、設計、測試、修正？過程中遇到什麼困難，你怎麼處理？這部分通常是面試最常被追問的地方。
  • 具體成果（Product）：最後做出了什麼？可以展示的東西（網站、報告、影片、資料集）遠比「我有做」三個字有說服力。
  • 可驗證的證據（Proof）：GitHub、網站連結、操作影片、使用者回饋、競賽紀錄。讓評審可以自己去確認，不需要相信你說的。
  • 反思成長（Reflection）：做完後，你學到了什麼？下次想怎麼改？這件事如何影響你對這個領域的理解？

一個把這五件事說清楚的小型專案，比十個只有名字沒有說明的大型活動更讓評審記住你。

還沒想好要做什麼？先從這裡開始

選題目最常見的錯誤，是先問「現在最熱門的是什麼」。這種做法做出來的通常是跟一堆人一樣的東西，很難形成差異。

比較好的起點是這三個問題：

  • 我想申請的科系，最在意什麼能力？
  • 我平常在做什麼讓自己忘記時間的事？
  • 我生活、學校或社區裡，有什麼我覺得可以更好的地方？

從這三個問題的交叉點出發，通常能找到一個你真的有動機做、又能連結申請方向的題目。具體的選題流程，可以參考這篇文章：Side Project 可以怎麼開始？如何從科系方向反推專案主題？
