# 研究計畫書架構模板（設計傳播研究所）

> 設計研究計畫和其他學群最大的不同：**你可能不是要「研究一個現象」，而是要「透過創作去探究一個問題」**。這兩條路的計畫書長得不一樣，而多數人失敗的原因是把兩者混在一起寫——用學術型的架構包裝一個創作計畫，最後兩邊都說不清楚。
>
> 先決定你走哪一條，再填對應的那一欄。
>
> **匯入 Notion**：Import → Markdown 後可切換成資料庫。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 四大架構檢核

- [ ] 研究問題那格是一個問句不是一個題材
- [ ] 動機與脈絡寫得出至少一個具體的觀察或經驗不是我從小就喜歡設計
- [ ] 方法說得出為什麼是這個方法不只是列出方法名稱
- [ ] 設計學生最常想不清楚的是動機與脈絡和方法我已經特別檢查過這兩格

## 收斂檢核

- [ ] 最終問句拿給非設計背景的朋友看他能複述我在問什麼
- [ ] 我說得出這個題目兩年做得完的理由
- [ ] 我的研究問題是問題不是領域（AI 與設計是領域 AI 生成工具如何改變新手設計師的發想流程才是問題）

## 第五段：常見錯誤自檢

- [ ] 把計畫書寫成文獻回顧堆滿引用卻看不到自己的問題與觀點
- [ ] 研究問題太大寫成一個領域而不是具體提問
- [ ] 方法和問題對不上（說要探討使用者經驗方法卻只有自己創作沒有任何使用者參與）
- [ ] 計畫和作品集脫節計畫談的方向在作品集裡完全看不到伏筆
- [ ] 我沒有把我想做一個很酷的作品寫成研究問題
- [ ] 我引用的文獻與作品是我真的看過的
- [ ] 我的計畫書裡有一段承認限制而不是全篇都在保證會成功
