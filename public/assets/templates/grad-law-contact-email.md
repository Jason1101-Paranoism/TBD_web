# 法政類群聯繫教授信結構模板

> 法政類群比多數領域更重視嚴密的邏輯與文獻處理能力。也因此，只有「我對老師的研究很有興趣」的群發信，幾乎必然石沉大海——那封信沒有提供任何可以判斷你的資訊。有效的聯繫，是在報名前精讀教授近期產出、提出一個具體的學術問題，並用一份文字作品證明自己的論證能力。
>
> **匯入 Notion**：Import → Markdown 後可直接當寫信工作區使用。
> **用 Google Docs**：整份貼上後，把「信件七段」逐段填成草稿。

## 第一步：先判斷該不該寄

兩組條件都成立才值得寄。任何一組不成立，先補齊再寄——寄一封沒有內容的信，比不寄更傷。

**條件組 A：我有沒有東西可談**

- [ ] 我已精讀過這位教授近五年的至少兩篇產出（期刊論文、專書篇章或研究計畫成果）。
- [ ] 我能說出他目前關注的核心議題，以及他用什麼理論取徑與方法處理。
- [ ] 我確認過他的研究方向近年有沒有轉向——不是拿五年前的專長頁面當現況。
- [ ] 我手上有一份能證明論證能力的文字作品（課堂研究報告、小論文、大專生研究計畫、法律爭點分析或政策分析）。

**條件組 B：我問得出真問題**

- [ ] 我能針對他的某一項具體產出，提出一個他答得出、而別人答不出的問題。
- [ ] 這個問題不是查得到的行政資訊（招生名額、報名時間、簡章內容）——那些請查系所公告。
- [ ] 我的研究方向與他的專業相容，不只是「都在法律系」或「都做政治」。

## 第二步：信件七段結構

| 段落 | 要寫什麼 | 我的草稿 |
|---|---|---|
| 1. 主旨 | 具體、可辨識。例如「○○大學○○系學生 王小明 請教關於○○修法爭議的研究方向」，不要用「詢問」兩字了事。 |  |
| 2. 簡短自我介紹 | 校系、年級、目前修課或研究重心。三行以內。 |  |
| 3. 目前的研究興趣 | 用一到兩句說清楚你想處理的爭議或問題，要具體到能被追問。 |  |
| 4. 已完成的相關研究或文字作品 | 做過什麼、用什麼方法、得到什麼結果。這一段是你的可信度來源。 |  |
| 5. 與教授研究的具體連結 | 明確指出是他哪一篇、哪一個論點與你的方向相接，說明怎麼接。 |  |
| 6. 一個高品質的學術問題 | 全信最關鍵的一段。讓他在一分鐘內看出你確實做足功課。 |  |
| 7. 禮貌結尾與附件 | 說明附件內容（代表作、簡歷），表達希望得到指教，不要施壓要求回覆。 |  |

## 第三步：可以附上的作品清單

勾選你手上實際有的，挑最能證明論證能力的一到兩份，不要全附。

- [ ] 課堂研究報告（法律爭點分析、政策分析、政治理論評述）
- [ ] 小論文或期刊投稿稿件
- [ ] 大專學生研究計畫（國科會）成果報告
- [ ] 專題或畢業論文初稿
- [ ] 法律扶助、法服社、法院旁聽的觀察記錄與分析
- [ ] 國會助理、政策研究或倡議工作的產出（須注意保密與去識別化）
- [ ] 模擬法庭、辯論、模擬聯合國的書面資料
- [ ] 一頁式簡歷（CV）

## 第四步：寄信前八項檢核

- [ ] 這封信只寄給這位教授，沒有任何一句是可以原封不動換名字寄給別人的。
- [ ] 我沒有把「我對老師的研究很有興趣」當成主要內容。
- [ ] 我提到的那篇論文，我真的讀完了——被追問細節時答得出來。
- [ ] 我的問題有學術含金量，不是查得到的行政資訊。
- [ ] 全信在一頁之內，教授兩分鐘讀得完。
- [ ] 附件檔名清楚（姓名＋文件性質），不是「文件1.pdf」。
- [ ] 收件人、稱謂、學校系所名稱、教授職稱全部再核對過一次。
- [ ] 沒有承諾自己做不到的事，也沒有暗示「老師收我我一定會來」這類施壓語句。

## 常見的三個失敗寫法

1. **通篇稱讚，沒有問題**：讀起來像仰慕信，教授無從判斷你的能力。
2. **問題太大**：「老師怎麼看兩岸關係的未來？」——這種問題誰都能問，也誰都答不完。
3. **把信當成研究計畫**：三千字的完整構想反而讓人讀不下去。信的任務是啟動對話，不是一次講完。

## 寄信時機

| | 適合做什麼 |
|---|---|
| 7-9 月 | 詢問明年度招生與指導量能 |
| 10-11 月送件期 | 信要更短，直接附文字作品與研究計畫 |
| 大三下 | 適合詢問能否旁聽課程或參與研究計畫 |

## 好壞寫法對照

| | 範例 |
|---|---|
| 沒有作用的寫法 | 我對貴系的研究方向很有興趣，希望能有機會學習 |
| 可用的寫法 | 您在○○那篇對△△的解釋，若套用到□□這類事實，是否會得出不同結論？ |
| 差別 | 針對一項具體產出提出可辯論的疑問 |
