# 理工口試自我檢核表

> 理工口試是技術答辯：教授會指著你的圖表問「為什麼長這樣」。上場前逐項檢核。
>
> **匯入 Notion**：Import → Markdown 後，勾選項會變成 to-do。

## 簡報

- [ ] 簡報做成模組化版本，時間被壓縮時知道先講什麼
- [ ] 每張數據圖表有一句話結論＋一段原理說明
- [ ] 針對目標實驗室調整過內容（不是每間都用同一份）
- [ ] 專題中「我負責的部分」在簡報中清楚可辨

## 數據答辯

- [ ] 每張圖能從原理或演算法邏輯推導「為什麼長這樣」
- [ ] 不理想的數據能說明原因、修正方式與學到的事
- [ ] 誤差來源、樣本數、實驗限制都想過答案
- [ ] 方法的替代方案比較過，答得出「為什麼不用另一種」

## 追問應對

- [ ] 練過「不會的問題」的回應：承認邊界＋提出查證或實驗路徑
- [ ] 「這個題目和貴實驗室的關係」答案與研究計畫書一致
- [ ] 「未來想研究什麼」有具體方向
- [ ] 找同學或學長姐模擬過限時追問

## 行政與現場

- [ ] 各校口試形式、時間、資格已按簡章逐校確認
- [ ] 備審與計畫書裡寫的每段經歷都重新讀過（都可能被問）
- [ ] 領域核心術語的英文說法整理過（部分系所有英文提問）
- [ ] 設備備援：簡報檔多格式備份、線上口試測試過鏡頭與麥克風

## 上場前的三個核心問題

- [ ] 教授指著數據問「這張圖為什麼長這樣」，我能從原理推導答案嗎？
- [ ] 被問到不理想的數據，我能說明原因與改進方式嗎？
- [ ] 被問到不會的問題，我能提出下一步的查證方法，而不是卡住嗎？
