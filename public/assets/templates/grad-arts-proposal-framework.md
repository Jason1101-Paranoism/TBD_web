# 創作母題發展與研究計畫模板（藝術研究所）

> 藝術研究計畫不是感性描述，也不是替創作外掛理論，而是一份把既有創作往前延伸的工作計畫。先用第一節從作品裡辨認母題，再用第二節的十節提綱寫，最後用可行性檢核確認這兩年做得完。

## 三個核心問題

| 三個核心問題 | 我的答案 |
|---|---|
| 作品從哪裡來（追到具體經驗不是籠統的主題） |  |

## 節次架構

| 節次 | 要回答什麼 | 常見失分 | 我的內容 | 完成 |
|---|---|---|---|---|
| 1 創作背景 | 從哪裡開始創作與目前實踐狀態 | 抽象語彙沒有具體產出 |  |  |
| 2 問題意識 | 持續在處理什麼問題 | 說不出貫穿的問題 |  |  |
| 3 創作母題 | 問題長成什麼母題出現在哪些作品 | 母題與作品對不起來 |  |  |
| 4 相關藝術家與文獻 | 誰在處理相近問題我和他們的差別 | 理論引用與創作無關 |  |  |
| 5 既有作品脈絡 | 過去作品的發展順序與各自位置 | 新舊作品之間斷裂（最常被省略的一節） |  |  |
| 6 媒材與方法 | 為什麼是這個媒材技術如何服務概念 | 只描述成果沒有方法 |  |  |
| 7 未來創作計畫 | 分幾階段各階段解決什麼問題 | 研究範圍過大 |  |  |

## 常見失分點自我對照

- [ ] 抽象語彙沒有具體產出
- [ ] 理論引用與創作實踐無關
- [ ] 研究範圍過大
- [ ] 新作品與既有作品之間斷裂
- [ ] 只描述成果沒有說明方法
- [ ] 忽略製作時程與成本

## 送出前檢核

- [ ] 計畫延續既有作品能指出至少兩件線索
- [ ] 清楚說明媒材與形式的選擇理由
- [ ] 能指出相關藝術家並說明自己與他們的差別
- [ ] 提出具體可執行的創作方法
- [ ] 評估過製作時間設備需求與材料成本
- [ ] 能在碩士修業年限內完成
- [ ] 已針對投遞校所調整資源與對話對象
- [ ] 不熟悉我創作的人讀完說得出我要做什麼怎麼做

> 檢查：把你的母題敘述換成任何一位同學的名字，還成立嗎？「我關注人與環境的關係」放在誰身上都對，那它還不是問題意識，只是題材類別。

> 第 5 節最常被省略，卻是藝術類群差最多的一節。沒有既有作品脈絡的計畫，等於要教授相信一個他沒看過證據的承諾。

> 寫得出「差別在哪」，才算真的讀過。引用密度不重要——每個概念都能拿掉而不影響論述的話，那些引用就是裝飾。
