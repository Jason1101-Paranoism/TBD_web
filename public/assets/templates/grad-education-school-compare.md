# 校所、次領域與教授比較表（教育研究所）

## 陷阱檢核

- [ ] **系名相同 ≠ 訓練相同**：我比較過同名系所在學術取向、方法訓練與實習制度上的差異，不是只看排名。
- [ ] 讀過目標教授近三年研究，並判斷過方法訓練能否支持我的題目
- [ ] **教授資深 ≠ 適合指導我**：我讀過目標教授近三年的研究，看得出他用什麼方法、關注什麼問題，也判斷過他的方法訓練能不能支持我的題目。
- [ ] 心諮與特教的實習、修業與資格規定，已以系所公告和當年度簡章確認
- [ ] 同一份計畫在不同系所會得到完全不同的評價，該所的理論偏好已確認過
- [ ] 實務訓練延長修業時間的可能性，已含在經濟規劃裡算過

## 填完後檢核

- [ ] 已寫下自己的次領域、教育階段與研究問題，並用來對照系所

- [ ] 確認需要的研究場域在該所進得去且有管道
- [ ] 看過目標教授近年指導的碩士論文

## 查證管道

| 查證管道 | 說明 |
|---|---|
| 系所公告與當年度簡章 | 心諮與特教的實習與資格規定一律以這裡為準，不要靠口耳相傳 |
| 臺灣博碩士論文知識加值系統 | 每所至少看三到五本目標教授指導的論文摘要與目次 |
| Google 學術搜尋 | 查期刊論文與研究計畫；看引用了誰就知道他的學術社群 |
| 現任學生與學長姐 | 研究場域怎麼找、實習有幾個名額、教授多久看一次進度、論文通常寫多久 |
| 幾年前的心得文 | 可信度最低，法規會變 |

> 查法提示：系所官網的課程地圖告訴你他們想訓練什麼人；教授的個人頁面告訴你他關注什麼；但**近年的碩士論文是投報率最高的一份資料**——它直接顯示這裡實際做得出什麼題目、用什麼方法、資料從哪來、做到什麼深度。建議每所至少看三到五本目標教授指導的論文摘要與目次。碩博士論文可在國家圖書館「臺灣博碩士論文知識加值系統」（ndltd.ncl.edu.tw）以校所或教授姓名檢索；期刊與研究計畫可用 Google 學術搜尋。系所文化與場域細節官網通常只寫得到一半，問學長姐時要問得具體：找研究場域是系上介紹還是自己談、實習機構有幾個選擇怎麼分配、老師多久看一次進度、論文平均幾年寫完。
