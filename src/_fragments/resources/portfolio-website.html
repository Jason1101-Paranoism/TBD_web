個人網站與 Portfolio 怎麼做？

Portfolio 不只是作品展示，而是在建立你的「個人品牌與能力敘事」。這篇文章說明高中生適合用哪些工具、Portfolio 的基本架構應該長什麼樣，以及最常見的問題。

為什麼 Portfolio 越來越重要？

以前學生的成果大多存在電腦裡、散落在雲端，或者整理成 PDF 才能讓人看到。Portfolio 改變了這件事：它讓你的能力和方向可以用一個連結傳遞，讓評審、教授或面試官在幾分鐘內自己去瀏覽。

尤其在 AI、資工、設計、商管、研究、工程等領域，Portfolio 幾乎已經等於你的「數位名片」。備審 PDF 是申請的時候遞交，Portfolio 則是一個可以持續更新的展示平台——兩者的定位不一樣，但可以互相補強。

高中生不需要做到公司產品等級。真正重要的是：能讓別人快速看懂你在做什麼、為什麼做，以及你正在往哪個方向成長。

高中生適合用哪些工具？

選工具的原則是：先把內容做好，再考慮工具是否夠炫。一個內容清楚的 Notion 頁面，遠比一個設計很酷但看不懂在做什麼的網站更有說服力。

  • Notion：最適合入門。好上手、排版簡單、免費，適合整理學習歷程、Side Project 紀錄和研究筆記。很多學生的第一個 Portfolio 就是 Notion 頁面，沒有任何問題。
  • GitHub Pages：適合資工、AI、工程方向。免費，可以直接串連 GitHub，適合放作品集和技術文章。如果你已經有 GitHub 習慣，這是最自然的延伸。
  • Vercel + React / Next.js：適合想展示前端能力、或想做客製化網站的學生。部署快、免費額度高，做出來的網站本身就是一個作品。
  • Behance：適合設計、傳播、UI/UX 方向。設計師群體廣泛使用，容易被領域內的人找到，也適合作為主 Portfolio 的補充。
  • WordPress / Webflow：適合需要部落格或內容型網站的學生。如果你想長期寫學習紀錄或技術文章，這類工具比 Notion 更適合公開發布。

Portfolio 的基本架構

一份好的 Portfolio，應該讓別人在三分鐘內知道你是誰、做過什麼、想往哪裡走。以下是建議的基本架構：

  • 自我介紹（About）：不要只寫「我是某某高中學生」。說明你對什麼有興趣、目前在做什麼方向的事，以及你正在累積什麼能力。讓人看完知道「這個學生在往某個方向長期投入」。
  • Side Project / 作品（Projects）：Portfolio 的核心。每個專案建議包含：專案介紹（解決什麼問題）、使用技術或方法、Demo 截圖或連結、遇到的挑戰、學到了什麼。Demo 很重要——教授通常沒時間自己把你的專案跑起來。
  • 競賽與研究（Achievements）：不只是放得獎紀錄，而是加上背景、過程和反思。「我參加科展並得到佳作」沒什麼說服力；「我在科展中研究了某個問題，遇到什麼困難後用什麼方法解決」才是評審想看的。
  • 技能（Skills）：按方向分類整理，不要把所有東西列成一長條。資工方向列程式語言和工具；設計方向列軟體；研究方向列分析工具和方法。
  • 聯絡方式（Contact）：Email、GitHub、Behance，讓想進一步了解的人有辦法找到你。

Portfolio 最常見的問題

  • 太像資料堆積：放了一堆圖片、證書、活動名稱，但沒有故事。評審看完不知道這個學生對什麼有真正的興趣。
  • 完全沒有主線：一下 AI、一下設計、一下商管，看不出任何一致的方向。這比活動數量少更讓評審困惑。
  • 只有成果，沒有過程：每個專案只說「我做了 X」，但沒有說「為什麼做」、「遇到什麼問題」、「怎麼解決」。評審真正想看的是你的思考過程。
  • Demo 完全缺失：程式碼只有 GitHub 連結但沒有說明，或者設計作品只有截圖沒有說明設計決策。沒有 Demo 的 Portfolio 等於讓別人猜你做了什麼。
  • 排版很亂：顏色過多、字體雜亂、資訊沒有層次。Portfolio 的視覺設計本身也是一種能力展示，即使你不是設計系，也值得花時間讓版面乾淨易讀。

真正強的 Portfolio 核心是一致性

很多學生看到別人的 Portfolio 會覺得「我是不是也要做得超專業、超炫」。其實不需要。高中生最重要的是：清楚、有整理、有方向、有成長感。

真正強的 Portfolio 通常會讓人感覺「這些東西彼此有關聯」。例如：APCS → AI Tool → GitHub → 個人網站；科展 → 資料分析 → Kaggle；品牌帳號 → 商業分析 → Podcast。

這種一致性不是刻意安排出來的，而是你長期在某個方向投入之後自然形成的。Portfolio 的真正功能，其實不只是展示成果，而是讓你自己整理清楚：我真正在做什麼、我往哪裡走、我為什麼在乎這件事。
