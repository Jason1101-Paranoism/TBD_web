# 研究問題拆解與可行性檢核表（商管與財經研究所）

> 商管財經研究計畫最常見的失分，是把「熱門議題」當成「研究問題」。這份表把問題拆解五步、十節架構與可行性檢核放在一起，寫完自己先驗收一遍。
>
> **匯入 Notion**：Import → Markdown。**用 Google Docs**：直接貼上。

## 第一步：把現象收斂成研究問題

| 步驟 | 要回答什麼 | 你的內容 |
|---|---|---|
| 現象 | 你觀察到什麼商業或財經現象？ |  |
| 對象 | 縮到哪一群人、企業或市場？ |  |
| 變數 | 哪些是可測量的變數？ |  |
| 關係 | 變數之間你想檢驗什麼關係？ |  |
| 方法 | 用什麼方法與資料回答？ |  |

> 檢核：走完五步後，你的題目應該從「AI 對企業的影響」這種主題，變成一個有對象、有變數、有關係的問句。題目變小是正確方向。

## 第二步：十節架構與檢核

| 節次 | 要回答的問題 | 你的重點 | 檢核 |
|---|---|---|---|
| 1 研究背景 | 這個產業或議題現在的狀況？ |  |  |
| 2 問題意識 | 你要解決什麼具體問題？ |  |  |
| 3 研究目的 | 目的是否明確、可達成？ |  |  |
| 4 理論或文獻基礎 | 用哪個理論的哪個概念解釋？為何適用？ |  |  |
| 5 研究問題／假設 | 是否明確、可檢驗？ |  |  |
| 6 研究方法 | 量化或質性？研究設計為何？ |  |  |
| 7 資料來源 | 資料從哪裡來？拿得到嗎？ |  |  |
| 8 分析方式 | 用什麼分析程序回答研究問題？ |  |  |
| 9 預期貢獻 | 對學術與實務各有什麼意義？ |  |  |
| 10 可行性與限制 | 有哪些限制？打算怎麼處理？ |  |  |

## 方法選用對照

| 你想回答的問題 | 適合的方法 |
|---|---|
| 有沒有關係、關係多強 | 問卷＋迴歸、次級資料分析、財務資料分析 |
| 某事件造成什麼影響 | 事件研究法、準實驗設計 |
| 為什麼會這樣、過程如何發生 | 個案研究、深度訪談 |
| 大量文字或評論透露什麼 | 文本分析、商業資料分析 |
| 是否有因果關係 | 實驗設計 |

## 可行性檢核

- [ ] 題目已收斂成一個可驗證的核心問題，而非一個做不完的藍圖
- [ ] 主要資料來源已確認可取得（企業資料／問卷回收／付費資料庫）
- [ ] 若主要資料拿不到，已想好備案（公開財報／政府統計／既有資料庫）
- [ ] 我具備執行這個方法的能力，口試被問到模型假設答得出來
- [ ] 若結果與假設不符，我知道下一步要怎麼檢驗
- [ ] 研究方向與目標系所的方法訓練接得上

## 常見失分點自我對照

- [ ] 題目是否還停在熱門議題層次？
- [ ] 理論是否只是列舉，沒有真的用上？
- [ ] 研究問題與研究方法是否對不上？
- [ ] 資料來源是否含糊帶過？
- [ ] 範圍是否大到碩士兩年做不完？
- [ ] 是否只寫順利的版本，完全不談限制？
