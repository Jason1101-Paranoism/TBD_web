  - q: 研究計畫的題目一定要和大學做過的東西有關嗎？

<section class="article-section" id="two-deaths">
## 兩種最常見的死法

法政研究計畫寫壞的方式，八成是這兩種：

**第一種：寫成一整篇文獻整理。**通篇在介紹「某個議題有哪些學說」「學者甲怎麼說、學者乙怎麼說」，讀完之後不知道你要問什麼。這種計畫的特徵是——**它有議題，但沒有研究問題**。議題是一個領域（例如「個資保護」），研究問題是一個問句（例如「某項規範在特定情境下產生什麼適用衝突」）。

**第二種：題目大到兩年做不完。**「AI 倫理」「兩岸關係」「轉型正義」「數位人權」——這些都是重要的題目，但它們是一輩子的研究方向，不是一份碩士論文。教授看到這種題目，第一個反應不是「這個學生很有企圖心」，而是「他還不知道研究是怎麼運作的」。

這兩種問題其實同源：**都是還沒有從「我對什麼有興趣」推進到「我要追問什麼」。**

好消息是，好的題目通常不需要從零開始找。它多半已經在你手上了——藏在大學期間的某一次課堂困惑、某一份寫得特別投入的報告、某一個你讀了覺得說不通的判決、某一段實習時看到的落差，或某一組你始終覺得沒被說服的理論衝突裡。
</section>

<section class="article-section" id="what-it-shows">
## 計畫真正要展示什麼

教授讀研究計畫，不是在檢查你的知識量。他在判斷五件事：

- **你能不能定義一個有意義的問題**——這個問題值得問嗎？不問會怎樣？
- **你能不能界定研究範圍**——你知道自己要做什麼、明確不做什麼嗎？
- **你能不能說明研究價值**——做完之後，學界或實務界會多知道什麼？
- **你能不能提出可行的方法**——這個方法真的答得了這個問題嗎？資料拿得到嗎？
- **你能不能解釋為什麼是你**——這個題目跟你的軌跡有什麼關係？

換句話說，計畫展示的是**研究能力**，不是知識存量。一份文獻豐富但看不出問題的計畫，和一份文獻精簡但問題鋒利、方法說得通的計畫，後者幾乎每次都贏。
</section>

<section class="article-section" id="narrow">
## 把議題縮小成爭點：五步

這是整份計畫最花時間、也最值得花時間的一段。建議每一步都寫出文字，不要只在腦中想過：

1. **起點**：我在哪一門課、哪一次報告、哪一段實務經驗中產生了這個困惑？寫下具體情境。
2. **議題**：用一句話寫出這個議題。此時它還很大，沒關係。
3. **收斂成爭點**：把議題縮小到一個具體的法制爭議、政策設計問題或理論衝突。**判準是：它必須可辯論**——正反雙方都說得出理由。如果所有人都同意，那不是研究問題，是常識。
4. **寫成研究問題**：改寫成一個問句。避免「探討○○」這種寫法——那不是問句，看不出你要回答什麼。
5. **界定範圍**：限定時間、地域、法規範圍、政策層級或個案數量，讓它兩年做得完。

**縮小的實際感覺**，可以用這組對照理解：

| 太大 | 收斂後 |
|---|---|
| AI 的法律規範 | 某一部特定法規草案中的演算法問責條款，在既有行政程序法制下產生哪些適用衝突？ |
| 兩岸關係 | 某一項特定的兩岸交流管制措施，在制定過程中不同行政機關的立場如何形成、如何被協調？ |
| 環境正義 | 某一類環境影響評估爭訟中，法院對特定利害關係人資格的認定標準如何演變？ |

注意收斂後的版本有什麼共同點：**都限定了對象、範圍與時間，而且都是問句。**

<section class="article-section" id="structure">
## 十節架構，每節要回答什麼

法政研究計畫的常見架構如下。重點不是節名，而是**每一節要回答的問題**——寫完一節就回頭確認它真的回答了：

| 節次 | 這一節要回答的問題 |
|---|---|
| 1. 研究背景 | 這個問題所處的法制、政治或政策脈絡是什麼？ |
| 2. 問題意識 | 為什麼這件事值得研究？現況出了什麼問題？ |
| 3. 核心研究問題 | 我要回答的那一個問句是什麼？ |
| 4. 文獻回顧 | 前人做到哪裡？留下什麼缺口？ |
| 5. 理論／法理架構 | 我用什麼理論或法理來分析？為什麼是它？ |
| 6. 研究方法 | 我怎麼取得與處理材料？ |
| 7. 研究範圍 | 我做什麼、明確不做什麼？ |
| 8. 預期發現或貢獻 | 做完之後，學界或實務界會多知道什麼？ |
| 9. 可行性 | 兩年內做得完嗎？資料拿得到嗎？ |
| 10. 研究限制 | 我的方法答不了什麼？ |

幾個容易被低估的節：

- **第 4 節文獻回顧**不是摘要清單，是**評述**。要看得出你的立場：你認為前人哪裡處理得好、哪裡還沒處理，而你的問題落在哪個縫隙。
- **第 7 節研究範圍**必須包含「不做什麼」。只寫做什麼，等於沒有界定範圍——口試時這一點一定會被問。
- **第 10 節研究限制**不是扣分項，是加分項。成熟的研究者不會假裝方法沒有弱點，主動講清楚反而顯示你想過。

各校對頁數與格式的要求不同，**一律以當年度簡章為準**。
</section>

<section class="article-section" id="method">
## 方法不是裝飾，是橋樑

「研究方法」這一節最常見的寫法是四個字：「文獻分析法」。這等於沒寫——它沒有告訴任何人你實際要怎麼做。

方法要說明的是**你打算怎麼從材料走到結論**。先確認你的問題屬於哪一類，再選方法：

| 我的問題長什麼樣 | 常見的對應方法 | 要先確認的可行性 |
|---|---|---|
| 某項規範在實務上如何被適用 | 判決分析、實務見解整理 | 判決是否公開可檢索、樣本量是否足夠 |
| 兩個以上法域對同一問題的處理差異 | 比較法研究 | 是否具備語言能力、是否有可靠的二手文獻 |
| 某項法制在規範層面是否融貫 | 規範分析、法釋義學、法理論分析 | 是否掌握該領域的核心學說與論爭 |
| 某項政策實施後產生什麼效果 | 政策評估、量化統計分析 | 資料是否可取得、是否具備統計能力 |
| 特定行動者為什麼這樣決策 | 質化訪談、個案研究、過程追蹤 | 是否接觸得到受訪者、是否需要研究倫理審查 |
| 某個概念或理論本身如何被建構 | 理論分析、思想史考察 | 是否讀得了原典、是否掌握學術脈絡 |

寫方法這一節時，具體到這種程度會比較安全：材料從哪裡來（[全國法規資料庫](https://law.moj.gov.tw/)的哪些法規、[司法院裁判書查詢](https://judgment.judicial.gov.tw/FJUD/default.aspx)的哪個期間與關鍵字、[立法院法律系統](https://lis.ly.gov.tw/lglawc/lglawkm)的哪次修法紀錄）、怎麼篩選、怎麼分析、預計處理多少量。

**如果要做訪談**，記得處理研究倫理與資料取得：是否需要倫理審查、受訪者怎麼接觸、資料怎麼去識別化。如果材料來自實習或工作期間接觸的資訊，還要確認保密義務的界線——這一點在法政領域特別重要，寫進計畫前先想清楚。
</section>

<section class="article-section" id="why-me">
## 「為什麼是我」的證據鏈

這是法政計畫裡最容易被忽略、卻最能拉開差距的一段。教授心裡的問題是：**這個題目為什麼由你來做？**

答不好的版本：「因為我對這個議題很有熱忱。」熱忱不是證據。

答得好的版本是一條可以被驗證的鏈：

> 某一門課讓我第一次注意到這個問題 → 我在該課的報告裡處理過它的一小部分 → 某段實習或旁聽經驗讓我看到規範與實務的落差 → 我後來讀了哪些文獻，發現這個缺口還沒被處理 → 所以我要在研究所裡把它做完

這條鏈的每一環都應該在你的 CV 或自傳裡找得到對應。**如果研究動機完全與既有軌跡脫節，讀起來就會像臨時找了一個題目**——而教授看過太多這種計畫。

跨領域轉向也適用同樣的邏輯，只是轉折點要寫清楚：是哪一堂課、哪一次經驗讓你從原本的領域轉過來？你已經開始補哪些訓練？有明確觸發點的轉向，說服力反而比一路直線更強。
</section>

<section class="article-section" id="mistakes">
## 常見錯誤與自我檢核

法政研究計畫的常見失分：

- **題目過大**：兩年做不完，範圍沒有界定。
- **只有議題沒有研究問題**：讀完不知道你要回答什麼。
- **文獻堆疊但沒有立場**：整理了很多，看不出你的判斷。
- **方法寫得模糊**：只有方法名稱，沒有操作方式。
- **研究範圍不清**：沒寫「不做什麼」。
- **沒有連結個人學術軌跡**：看不出為什麼是你。
- **沒有討論限制**：迴避弱點，反而讓人懷疑你沒想清楚。
- **理論掛著好看**：第 5 節掛了一個理論名字，第 6 節之後完全沒用到。

送出前的六個自省：

- [ ] 我的題目是聚焦的具體爭議，而不是宏大主題？
- [ ] 我能用一句話說出核心研究問題，而且它是一個問句？
- [ ] 我的方法真的能回答這個問題，而不是掛在那裡好看？
- [ ] 這個題目在碩士兩年內做得完，資料我拿得到？
- [ ] 我能說清楚「為什麼是我來研究」，並連得上修課、專題或實務經歷？
- [ ] 我寫出了研究限制，而不是假裝方法沒有弱點？

計畫定稿之後，下一步是把它和 CV、自傳整合成一致的備審——[法政備審怎麼準備](/pages/resources/law-graduate-cv.html)會談三份文件的分工。
</section>
