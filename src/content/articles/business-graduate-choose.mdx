## 為什麼不能只看排名

商管財經的選校，很多人第一個動作是打開排名表，從上往下挑。排名不是沒有意義——在商管財經，校名與系所品牌的影響確實比某些領域更直接——但只看排名的問題在於，它完全看不出你未來兩年會被訓練成什麼樣的人。

因為在商管財經，**名稱相似的系所，實際內容可能完全不同**。同樣叫企管所，有的以理論與研究方法訓練為主、要求你讀大量文獻並產出可發表的論文；有的偏管理實務，課程大量使用個案教學、與企業合作專案；有的則以量化分析為核心。財金所也一樣，有的偏財務工程與計量，有的偏公司理財與實務。

這些差異會直接決定：你每天在讀什麼、寫什麼、用什麼方法思考，以及畢業後最順的出路在哪裡。所以建議用這個順序收斂名單：

> **系所定位 → 教授與研究方向 → 職涯與校友網絡 → 校名與地點**

把校名放到最後，不是說它不重要，而是它應該是在前面三層都對得上之後的加分項，而不是決定一切的第一個篩選條件。
</section>

<section class="article-section" id="positioning">
## 第一層：系所定位

第一層要回答的是：這個系所在訓練什麼樣的人？商管財經的系所可能偏向學術研究、財務量化、金融市場、管理實務、行銷與消費者行為、科技管理、商業分析、資訊管理、人力資源，或產業與政策分析。定位不同，你要準備的材料與能力也不同。

判斷定位時，建議確認這幾件事：

- **偏學術還是偏實務**：課程是文獻研讀與研究方法為主，還是個案分析與企業專案為主。
- **是否重視研究方法**：有沒有必修的研究方法、計量或統計課程，論文要求的強度如何。
- **是否有企業合作**：產學專案、企業導師、實習學分或業界共授課程。
- **是否有交換、雙聯或國際課程**：對想走國際職涯或外商的人，這一項權重會很高。
- **偏就業還是偏博士訓練**：從課程結構與畢業生流向就看得出來。
- **招生簡章的實際評分方式**：書審、口試、成績各佔多少，這會直接影響你該把力氣放在哪。

查法上，系所官網的課程地圖與必選修清單、修業規定與論文要求、招生簡章的評分配比，是最直接的三份文件。花一個下午把三所的這三份文件讀完，你對「這裡在訓練什麼人」的判斷會清楚很多——這比讀十篇心得文有用。
</section>

<section class="article-section" id="professor">
## 第二層：教授與研究方向

即使你不打算讀博士，教授這一層仍然值得查，因為他決定了你碩士兩年的訓練內容與資源。建議確認：

- **教授近年的研究主題**：看近三到五年的發表與計畫，而不是十年前的代表作。
- **是否與你的研究計畫方向相符**：這關係到你的研究計畫能不能在這裡做，也是口試常被追問的點。
- **是否有指導碩士生**：有些教授以指導博士生為主，或當年度已經額滿。
- **研究方法是否適合你**：偏計量與大型資料分析、偏個案與訪談、偏實驗設計，訓練起來是完全不同的體驗。
- **是否有產學或資料資源**：業界合作、資料庫使用權、專案經費，這些會直接影響你能做什麼題目。
- **能不能提供你想要的訓練**：這是前面幾項的總結——你想學的東西，這位教授給得了嗎。

一個實用的做法：從系所師資頁挑三到五位方向接近的教授，各讀一篇近期論文的摘要與結論。你會很快發現自己對哪一類問題真的有興趣，這個發現對後面的研究計畫與套磁都有用（做法見[套磁信怎麼寫](/pages/resources/graduate-contact-professor.html#business-tips)）。
</section>

<section class="article-section" id="career">
## 第三層：職涯與校友網絡

商管財經有一個和純學術領域不太一樣的地方：**校友網絡與產業連結，本身就是這個學位的一部分價值**。所以第三層要看的是這個系所能把你帶到哪裡：

- **畢業生去向**：主要進哪些產業與職能，是金融、顧問、科技、製造，還是繼續讀博士。
- **企業連結**：有沒有固定合作的企業、產學專案或招募管道。
- **校友資源**：校友活動、業師制度、學長姐是否活躍。
- **實習機會**：課程中是否安排實習，或系所是否協助媒合。
- **證照與專業課程**：與 CFA、FRM、會計師、精算或資料分析相關的課程支援。
- **是否能銜接你的下一步**：不管是進特定產業，還是往博士班走。

這些資訊在官網上通常只有片段，最有效的做法是直接問人——系上的學長姐、參加過該系所說明會的同學，或在職涯活動上遇到的校友。問法要具體：「這一屆同學畢業後主要去哪裡？」「系上有沒有實質幫上忙的業界管道？」比問「這個系所好不好」有用得多。
</section>

<section class="article-section" id="fit">
## 最容易被忽略的契合度

前面三層都是查得到的資訊，但真正決定你讀得順不順的，是幾個只有自己能回答的問題。商管財經的學生特別容易在這裡誤判，因為推甄的準備過程往往被「錄取」這個目標主導，很少人停下來問自己：

- 我是不是真的喜歡做研究？還是我只是想要一個碩士學位。
- 我能不能接受大量閱讀與寫作？人文取向的管理領域，文獻量並不小。
- 我適不適合量化方法？如果對統計與計量長期抗拒，選一個以計量為核心的所會很辛苦。
- 我需不需要產學資源？想進業界的人，選一個純學術導向的所可能事倍功半。
- 我想走企業實務、金融專業，還是博士？三條路指向的系所選擇不完全相同。
- 教授的指導方式適合我嗎？緊盯進度與高度放手，對不同性格的人是完全不同的體驗。

這些問題沒有標準答案，重點是拿它們去對照你自己的個性、生活需求與職涯目標。同一個高強度、重量化訓練的所，對想進投資銀行或往博士走的人是理想環境，對想快速累積實務經驗的人卻可能是折磨——**契合度是相對於「你」而言的，不是絕對值。**
</section>

<section class="article-section" id="compare">
## 校所與教授比較表

查完三層之後，最後一步是把候選校所放進同一張表逐項比較。當資訊被攤開並排，原本模糊的直覺會變成清楚的取捨——哪一所定位最合但要求的量化能力偏高、哪一所資源最好卻離你的職涯方向有距離，一眼就看得出來。建議至少包含以下欄位：

| 項目 | 系所 A | 系所 B | 系所 C |

| 系所定位 |  |  |  |
| 研究方向 |  |  |  |

| 產學合作 |  |  |  |
| 校友去向 |  |  |  |
| 國際資源 |  |  |  |
| 與我的契合度 |  |  |  |

我們把這張表做成了可以直接填的模板：[校所與教授比較表（Markdown，可匯入 Notion）](/assets/templates/grad-business-school-compare.md)，下載後把每一欄的空格填滿，決策依據就會具體很多。

填完之後，用三個問題做最後檢核：這個系所的定位與課程，能不能給我想要的訓練？我讀過的那幾位教授，方向與方法跟我的研究計畫接得上嗎？畢業生的主要出路，和我的職涯方向一致嗎？三題都能明確回答，你的名單就收斂完成了。

收斂之後，下一步是主動出擊：用[套磁信聯繫教授](/pages/resources/graduate-contact-professor.html#business-tips)確認方向與契合度，並讓你的[研究計畫書](/pages/resources/business-graduate-proposal.html)真的連結上這個系所的方法訓練與資源。若想再對照一次不分科系的選所通則，也可以參考[研究所怎麼選校、選所、選指導教授](/pages/resources/graduate-choose-lab.html)。
