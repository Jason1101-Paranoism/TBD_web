# 教育口試自我檢核表（政策題、個案題與方法答辯）

> 教育所口試的重點不是自我介紹，而是教授在挑未來的研究夥伴與現場工作者。這份檢核表包含四類追問題庫、兩套答題框架、面對盲點的回應順序，以及上場前的完整檢核。
>
> **匯入 Notion**：Import → Markdown。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 一、教授實際在確認的五件事

- [ ] 我對自己的研究計畫理解得夠深（不是別人幫我組出來的）
- [ ] 面對方法漏洞時能說清楚設計理由
- [ ] 能處理教育現場的複雜情境
- [ ] 遇到案例或政策題有即時反應
- [ ] 面對盲點能承認限制並提出修正

## 二、四類追問題庫

### 第一類：研究計畫本身（主場，最不該失分）

- [ ] 請用一分鐘說明你的研究計畫
- [ ] 你的研究問題是怎麼來的？
- [ ] 為什麼這個問題值得研究？
- [ ] 前人已經做過什麼？你補的是哪一塊？
- [ ] 你預期會看到什麼結果？如果結果相反呢？

### 第二類：研究方法（最常見的攻擊面）

- [ ] 只訪談 5 位老師夠嗎？
- [ ] 你怎麼選研究對象？為什麼是這幾位？
- [ ] 這個方法真的能回答你的問題嗎？
- [ ] 研究對象你打算怎麼取得？學校會同意嗎？
- [ ] 涉及未成年學生或個案，你怎麼處理同意與保密？
- [ ] 這個規模在碩士兩年做得完嗎？

### 第三類：教育政策與時事

- [ ] 你怎麼看某項教育政策在現場的執行落差？
- [ ] 這項政策對你關注的那群學生有什麼影響？
- [ ] 如果你是決策者，你會怎麼調整？
- [ ] 你認為現場老師最大的困難是什麼？

**準備方式**：挑三到五個自己次領域的近年議題，各練一次「政策目標 → 現場條件 → 落差 → 可能的調整」四段講法。

| 議題 | 政策目標 | 現場條件 | 落差 | 可能的調整 |
|---|---|---|---|---|
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

### 第四類：個案與情境題

- [ ] 班上有學生長期不交作業但每天到校，你會怎麼理解與處理？
- [ ] 家長不同意孩子接受特教鑑定，你怎麼看？
- [ ] 個案在晤談中表達強烈負面情緒，你的第一步是什麼？
- [ ] 你的研究對象中途退出，你怎麼辦？

## 三、方法答辯五步框架

> **確認問題 → 說明原始設計 → 提出專業依據 → 承認限制 → 提出補強方式**

| 步驟 | 句型 | 我的版本 |
|---|---|---|
| 1. 確認問題 | 「老師的意思是……，還是……？」 |  |
| 2. 說明原始設計 | 「我這樣設計是因為……」 |  |
| 3. 提出專業依據 | 「這個方法取向追求的是……而不是……」 |  |
| 4. 承認限制 | 「這確實代表我的結論無法……」 |  |
| 5. 提出補強方式 | 「如果要提高可信度，我可以……」 |  |

**兩個要避免的極端**

- [ ] 立刻說「那我改成 20 位」（顯示沒有設計理由）
- [ ] 堅持「5 位就是夠」（顯示聽不進意見）

## 四、個案題六步流程

> **界定問題 → 蒐集資訊 → 套用專業理論 → 評估風險 → 提出介入方向 → 持續修正**

| 步驟 | 要說什麼 | 我的練習 |
|---|---|---|
| 1. 界定問題 | 觀察到什麼、還不確定什麼 |  |
| 2. 蒐集資訊 | 會問誰、看什麼（導師／家長／輔導紀錄／學習表現／同儕） |  |
| 3. 套用專業理論 | 發展階段／學習動機／家庭系統／行為功能分析／特教鑑定向度 |  |
| 4. 評估風險 | 安全、自傷、受虐或需即時通報的疑慮 |  |
| 5. 提出介入方向 | 具體、分階段、由誰執行；先講第一步 |  |
| 6. 持續修正 | 怎麼觀察成效、何時調整或轉介 |  |

- [ ] **第 1 步與第 4 步不可跳過**——太快進到「我會怎麼做」，是這類題目最常見的失分點
- [ ] 不用「我會很有耐心陪他」取代專業判斷

## 五、被問到沒準備到的問題

1. 先確認教授的邏輯：「老師的意思是……我理解得對嗎？」
2. 誠實說明限制：「這個部分我沒有讀到，這確實是我目前的不足。」
3. 提出能推的部分：從會的東西往那個方向推一段
4. 給出補救方向：「如果要處理，我會先去看某類文獻／資料。」

**要避免**：硬掰、沉默、過度道歉。假裝什麼都知道，比誠實承認不知道扣分更多。

## 六、上場前檢核

- [ ] 能在一分鐘內說清楚研究計畫（問題、方法、貢獻）
- [ ] 說得出每一個方法選擇的理由
- [ ] 知道研究最大的限制是什麼，也想好怎麼補強
- [ ] 準備了三到五個次領域相關的政策議題，能用四段結構講
- [ ] 練過至少三題個案或情境題，用六步流程拆解
- [ ] 心諮／特教：實際演練過實演，並回顧過自己的盲點
- [ ] 說得出最近在現場看到什麼、還在想什麼問題
- [ ] 遇到不會的問題時有固定的回應順序
- [ ] 備審裡每一段經歷都能被追問細節而不出錯

## 七、行政準備

- [ ] 確認時間、地點、報到方式與交通（線上口試則測試設備與網路）
- [ ] 簡報或紙本資料依簡章規定準備，份數確認
- [ ] 備審資料自己重讀一遍，並帶一份可翻閱的版本
- [ ] 服裝整潔，以不干擾對話為原則

## 常見失分點自我對照

- [ ] 研究動機講成教育熱忱，說不出具體事件
- [ ] 題目大到兩年做不完，被問到縮小方案時答不出來
- [ ] 方法答成教科書定義，說不出在我的題目上怎麼用
- [ ] 研究對象沒有著落，管道與同意流程講不清楚
- [ ] 倫理一句話帶過，沒想過同意、保密與退出機制
- [ ] 被問到政策時事只表達立場，沒有連回自己的研究問題
