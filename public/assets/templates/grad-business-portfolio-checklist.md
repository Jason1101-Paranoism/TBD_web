# 商管財經備審 Checklist（CV／自傳／經歷描述）

> 商管財經備審最大的問題通常不是經歷不足，而是經歷缺乏整理與連結。逐項勾完再送件。
>
> **匯入 Notion**：Import → Markdown。**用 Google Docs**：直接貼上。

> 順序：經歷盤點 → 主題分類 → 能力證據 → 申請方向連結。這一步做完，故事線是長出來的；跳過這一步，故事線就是編出來的。

## CV 欄位

- [ ] Education（系排或 GPA 若有優勢可附）
- [ ] Research Interests
- [ ] Internship Experience
- [ ] Project Experience
- [ ] Competition Experience
- [ ] Leadership & Activities
- [ ] Data／Technical Skills（Excel／SQL／Python／R／SPSS／Stata／Tableau）
- [ ] Language Skills
- [ ] Certifications（僅保留真正相關者）
- [ ] Awards
- [ ] Publications／Presentations（如有）

## 每段經歷應寫出的七件事

- [ ] 情境（組織或專案當時的狀況）
- [ ] 任務（你的目標）
- [ ] 行動（你實際做了什麼）
- [ ] 工具（問卷／訪談／財務模型／SQL／統計分析）
- [ ] 成果（能量化就量化）
- [ ] 個人貢獻（團隊專案中哪一塊是你）
- [ ] 與申請方向的關聯

| 避免只寫 | 建議具體化 |
|---|---|
| 參與行銷競賽 | 負責市場資料蒐集與消費者分群，用問卷與次級資料分析建立提案方向，最終完成品牌進入策略並進入決賽 |
| 擔任社團幹部 | 帶領六人團隊規劃全年活動，重整報名流程與經費控管，使參與人數較前一年成長四成 |
| 在某公司實習 | 於商業分析部門負責週報資料處理，用 SQL 整理交易資料並產出視覺化報表，供主管檢視通路表現 |

## 自傳檢核

- [ ] 我的興趣是怎麼形成的（具體的轉折點，而非「從小就有興趣」）
- [ ] 為什麼選擇這個領域
- [ ] 哪兩三段經歷最能證明我的能力（講深，不複述整份 CV）
- [ ] 為什麼申請這個校所（連結課程規劃或教授研究）
- [ ] 我未來要往哪裡發展

## 五份文件的分工

| 文件 | 回答什麼 |
|---|---|
| CV | 你做過什麼 |
| 自傳 | 你為什麼走到這裡 |
| 研究計畫 | 你接下來想研究什麼 |
| 讀書計畫 | 進入研究所後如何成長 |
| 推薦信 | 第三方如何證明你的能力 |

## 送件前五問

- [ ] 我的 CV 能不能在 30 秒內看出主軸？
- [ ] 每段經歷是否都有具體成果與個人貢獻？
- [ ] 自傳是否形成清楚的故事線（轉折可以有，跳躍不行）？
- [ ] 研究計畫是否與過去經歷、未來方向一致？
- [ ] 是否針對不同校所調整過版本？
