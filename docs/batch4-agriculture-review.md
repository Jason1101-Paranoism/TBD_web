## 發現 1｜農生是九個學群裡唯一頓號歸零的　🟡 表面層，建議修

實測九學群全部 CSV 的頓號出現次數：

| 學群 | 頓號 | | 學群 | 頓號 |
|---|---|---|---|---|
| **農生環境** | **0** | | 商管 | 33 |
| 法政 | 13 | | 生醫 | 67 |
| 人文 | 14 | | 理工 | 60 |
| 藝術 | 17 | | 設計 | 99 |
| 教育 | 19 | | | |

農生系統性地把頓號拿掉，導致並列項目黏成一串。實際受害的格子：

- `污染死亡天候中斷儀器故障數據不符` — 這是備審檢核表「卡在哪」那一列，五個並列詞完全黏死
- `名額休假退休`、`次數時數樣本數重複數`、`技術／論文／產業門票／公部門資格`（這格反而有分隔）

**同一份檔案裡兩種作法並存**，所以不是刻意的風格選擇，是漏做。
§07c「八份標點風格統一」由 YC 在 Batch 2 v2 處理，農生當時還沒產出，沒被涵蓋到。

**建議**：農生 5 份補回頓號，對齊其他八份。純文字替換，無結構風險。

## 發現 3｜農生的「倫理與資料取得」區塊沒有橫向擴散　🔴 這項比前兩項重要

農生 `proposal-framework` 有一個獨立的六列區塊，其他學群沒有對應物：

```
倫理與資料取得,是否確認
涉及動物實驗已確認 IACUC 審查與所需時間並算進時程
涉及人體樣本或問卷已確認 IRB 需求
野外採集已確認採集許可與保護區進入許可
涉及基改生物或病原已確認生物安全等級與操作規範
使用他人或單位的資料已確認授權與引用方式
樣區涉及私有地或原住民族地區已確認同意與溝通流程
```

九學群 `proposal-framework` 的倫理相關列數：

| 學群 | 列數 | 判斷 |
|---|---|---|
| 農生 | 6（獨立區塊）| 基準 |
| 教育 | 5（獨立區塊＋節次＋失分）| 充足 |
| 法政 | 3 | 尚可 |
| **生醫** | **2** | 🔴 **最該補而最缺** |
| 人文 | 1 | ⚠️ |
| 藝術／商管／設計／理工 | **0** | 設計（使用者研究訪談、個資）與藝術（人體、展演同意）該有 |

生醫只有兩句夾在別的區塊裡（`已考量 IRB／IACUC／生物安全規範且時程已算進去`、
`能取得足夠樣本且符合倫理與隱私規範`）。**生醫是 IRB／IACUC 最硬性的學群**，
卻比農生薄，這是實質缺漏不是風格問題。

**這也暴露一個機制缺口**：v5 §02 的規則與 `audit-templates.mjs` 都只擋「少一份檔案」
或「少一個結構欄位」，擋不住「某個學群做對的一列沒有擴散出去」。
A1／A2 是人工發現的，這次也是。要擋住得把它寫進稽核規則 —— 但依 batch2 checklist
末段的警告，**規則要比對概念不是比對字串**，且擴充前先用現有 45 份跑一遍確認沒有假紅燈。

## 發現 4｜這次是工具比文章完整，缺口在文章側　🟢 記錄，不急

附錄 C／D 的形狀是「文章有、工具沒有」。農生是反過來的：
上面那個倫理六列在 `agriculture-graduate-proposal.mdx` 裡找不到對應段落
（該文只在風險段提了一次「進場許可延遲」、對照表提了一次「該區的許可流程」）。

依 §05 的處理慣例（工具端的補強要回頭修文章），農生文章可補一段
「倫理與許可要算進時程」。優先度低於發現 3，因為工具端已經覆蓋，學生拿得到。
