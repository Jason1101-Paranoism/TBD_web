# 研究計畫口試答辯檢核表（人文與社會科學研究所）

> 人文社科口試不是朗讀研究計畫，而是一次學術對話。教授要確認的不是「你永遠不會錯」，而是你能否清楚論證、回應質疑，並在必要時調整主張。

## 二、五步答題框架

> **重述問題 → 提出核心判斷 → 說明依據 → 承認限制 → 補充修正方向**

| 步驟 | 作用 | 練習備註 |
|---|---|---|
| 重述問題 | 確認聽懂，並替自己爭取幾秒 |  |
| 提出核心判斷 | 先給立場，不要鋪陳到最後才講 |  |
| 說明依據 | 文獻、材料或邏輯，擇一即可 |  |
| 承認限制 | 說明結論適用到哪裡為止 |  |
| 補充修正方向 | 若要處理這個情況，我會怎麼做 |  |

## 四、遇到不知道的問題

不要硬湊學者、理論或史實。錯誤引用會被立刻聽出來，而且會讓委員開始懷疑你其他的引用。改用四步：

1. 坦白目前掌握的範圍
2. 說明初步判斷
3. 指出需要查證的材料
4. 提出後續閱讀或研究方法

- [ ] 我已經演練過一次「不知道」的回答，講得出來而不會慌

## 五、上場前的五個檢核

- [ ] 能在一分鐘內說明研究問題與核心主張（另備三分鐘版本）
- [ ] 能解釋文獻缺口在哪裡
- [ ] 能為材料與方法的選擇辯護（含選材標準與偏差）
- [ ] 準備過反例與批評，並主動找出至少一種反對我的解釋
- [ ] 面對不知道的問題時，能提出合理的查證路徑
- [ ] 已找人做過連續追問的模擬，練到被打斷也能維持邏輯

## 常見失分點自我對照

- [ ] 研究問題不是問句，是一個題材
- [ ] 問題意識、研究問題與文獻回顧講的不是同一件事
- [ ] 理論掛名字當裝飾，被追問時說不出怎麼用
- [ ] 材料數量與取得方式交代不清
- [ ] 被指出立場問題時只重述觀點，沒有處理反駁
- [ ] 範圍過大，答不出縮小方案
