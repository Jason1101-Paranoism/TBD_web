# 法政備審 Checklist（CV、自傳與文字作品）

> 法政備審的核心不是「我做過很多事」，而是**專業背景與研究背景的連結**。CV、自傳、研究計畫三份文件必須分工清楚、互不重複，並共同指向同一個研究方向。這份 Checklist 依「盤點 → CV → 自傳 → 一致性」四段使用。
>
> **匯入 Notion**：Import → Markdown 後可切換成資料庫逐項追蹤。
> **用 Google Docs / Sheets**：表格可直接貼上。

**盤點時容易漏掉的法政經歷**

- [ ] 課堂研究報告與期末論文（尤其是被老師肯定的那幾份）
- [ ] 小論文、期刊投稿、學生學術研討會發表
- [ ] 大專學生研究計畫（國科會）
- [ ] 法律扶助、法服社、法律諮詢志工
- [ ] 法院旁聽與判決評析
- [ ] 模擬法庭、辯論比賽、模擬聯合國
- [ ] 國會助理、議員辦公室、政黨或智庫實習
- [ ] 公民團體倡議、社會運動參與、公共政策提案
- [ ] 政府機關實習、公部門工讀
- [ ] 研究助理（協助教授計畫）
- [ ] 相關證照、語言能力、統計或資料分析訓練

## 第二段：學術 CV 十二欄位

CV 的任務只有一個：**證明你做過什麼**。條列、可查證、不寫感想。

| 欄位 | 要寫的內容 | 完成 |
|---|---|---|
| 1. 基本資料 | 姓名、聯絡方式（一行，不要放身分證字號） | [ ] |
| 2. 學歷 | 校系、期間、在校排名或 GPA（有優勢才寫） | [ ] |
| 3. 研究興趣 | 一到兩行，與研究計畫方向一致 | [ ] |
| 4. 法政核心科目表現 | 具體科目與成績（憲法、行政法、民法、刑法、政治學、國際關係、公共政策等） | [ ] |
| 5. 研究經歷 | 大專生計畫、研究助理、專題，寫清楚角色與方法 | [ ] |
| 6. 學術產出 | 小論文、研討會發表、投稿，附完整標題 | [ ] |
| 7. 課堂重要報告 | 挑二到三份與方向相關的，寫題目與處理的爭點 | [ ] |
| 8. 實務經歷 | 實習、法服、旁聽、國會、倡議，寫職務與實際工作 | [ ] |
| 9. 競賽與活動 | 模擬法庭、辯論、模擬聯合國等，寫層級與名次 | [ ] |
| 10. 語言與方法能力 | 外語程度、統計軟體、資料庫檢索能力 | [ ] |
| 11. 獎項與獎學金 | 名稱、頒發單位、年份 | [ ] |
| 12. 附件索引 | 代表作清單與對應頁碼 | [ ] |

**每段經歷該寫出的七件事**（缺三項以上，這段經歷等於沒寫）

1. 我在什麼脈絡下做這件事
2. 我的角色與職責（不是團隊做了什麼，是我做了什麼）
3. 具體處理的爭點、案件類型或政策議題
4. 使用的方法或工具
5. 可量化的規模（幾件、幾週、幾人、幾份文件）
6. 產出了什麼（報告、備忘錄、分析、提案）
7. 這段經歷讓我看見什麼問題——這一句是通往研究動機的橋

## 第三段：自傳的四個要素

自傳的任務是**研究動機的形成軌跡**，不是人生回顧。

- [ ] **研究興趣如何形成**：哪一堂課、哪一個案件、哪一次現場經驗讓你開始追問？
- [ ] **轉折點**：哪些經驗改變了你原本的想法？誠實寫出「原本以為 ⋯⋯ 後來發現 ⋯⋯」的過程。
- [ ] **能力累積**：你怎麼一步步取得處理這個問題所需的訓練（修課、方法、語言、實務）。
- [ ] **為什麼要繼續讀**：為什麼這個問題必須在研究所裡處理，而不是工作中處理？

**應該大幅壓縮或刪掉的**

- [ ] 家庭背景（除非它直接構成研究動機，且能被具體說明）
- [ ] 與研究方向無關的社團與課外活動
- [ ] 空泛的人格特質形容（積極、負責、抗壓性強）
- [ ] 已經在 CV 條列過的事實清單（自傳重複列一次是浪費篇幅）

## 第四段：三份文件的一致性檢核

| 文件 | 任務 | 時態 | 我的版本是否守住 |
|---|---|---|---|
| CV | 證明你做過什麼（客觀事實） | 過去 |  |
| 自傳 | 說明研究動機怎麼形成（軌跡） | 過去到現在 |  |
| 研究計畫 | 說明未來要處理什麼問題（規劃） | 未來 |  |

- [ ] 三份文件指向同一個研究方向，沒有互相矛盾。
- [ ] 同一件事沒有在三份文件裡各講一次（可以呼應，但角度要不同）。
- [ ] 研究計畫的題目，在 CV 與自傳裡找得到來源——不是憑空冒出來的。
- [ ] 若我的純學術資歷較少，我已把實務經歷提煉成「發現問題」與「法理推導」的能力證據，而不是只列活動名稱。
- [ ] 所有可查證的事實（成績、名次、期間、職務）都與正式文件一致。

## 送件前最後五問

- [ ] 陌生的教授只讀這三份文件，能不能說出我要研究什麼、憑什麼？
- [ ] 我最強的三段經歷，有沒有出現在最容易被看見的位置？
- [ ] 有沒有任何一句話是我在口試時答不出細節的？
- [ ] 檔案命名、頁碼、目錄、格式是否符合各校簡章要求？
- [ ] 推薦信的老師手上，是否有我這三份文件的最新版本？
