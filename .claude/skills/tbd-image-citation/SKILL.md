# TBD 圖片與引用規範（泛用）

這份 skill 把《TBD 知識庫圖片與引用規範 Style Guide v1.0》固化為所有知識庫文章共用的作法。
核心觀念只有一句：

> **事件只是入口，方法論才是產品。** 我們引用事件是為了說明方法，不是複製內容。

從這一句長出所有規則：文章主體必須是 TBD 的分析、整理與方法，新聞／社群只是佐證。

## 事件 vs TBD 方法論：20 / 80

- 外部事件、新聞、名人故事：**≤ 20%**
- TBD 原創分析、架構、模板、行動建議：**≥ 80%**
- 事件背景集中在導言（約全文 1/5 以內），不要每節重述名人故事。
- 讀者離開時該記住的是「怎麼建立系統」，不是「那個人做了什麼」。

## 這個站的關鍵限制：文章沒有 raster 圖基礎設施

[ArticleLayout.astro](../../../src/layouts/ArticleLayout.astro) 目前沒有圖片元件，全站文章也
不放外部圖檔。加上規範本身**禁止轉載新聞／Reel 截圖**（版權），所以在本專案，「原創圖」的
落地方式是 **純 CSS/HTML 圖示**，不是 `.png/.jpg`：

- 流程圖、架構圖、循環圖 → 用 `<figure class="article-figure">` + div/flex 排出來的原創圖示。
- 比較表、模板、checklist → 用現有 `.table-wrapper > .plan-table`，同樣包進 `<figure>` 加 caption。
- 需要真的截圖／照片時：**先確認授權**再說，預設不要做；沒有授權就改用原創圖示或純文字轉述。

這樣零版權風險、零外部資產、也自然滿足「原創圖 > 引用圖」。

## 圖片使用優先順序

| 優先 | 類型 | 在本專案怎麼做 |
|---|---|---|
| ⭐⭐⭐⭐⭐ | TBD 原創圖 | 優先，用 CSS 圖示／表格 |
| ⭐⭐⭐⭐ | 自製流程圖／模板 | 大量使用 |
| ⭐⭐⭐ | 官方新聞截圖 | 少量、僅背景說明、**須先確認授權** |
| ⭐⭐ | 官方影片關鍵截圖 | 少量分析用途、**須先確認授權** |
| ⭐ | 非官方轉載圖 | 不要 |

發布前確認：**原創圖數量 > 引用圖數量**。理想上引用圖為 0。

## 每張圖都要有 caption

格式（沿用 Style Guide，本站用 `<figcaption>`）：

> 圖 X．圖片內容（來源：XXX）

- 原創圖的來源寫 **TBD 原創圖／原創對照表／原創模板**。
- 引用圖的來源用下方「來源標示格式」。
- caption 要與內文呼應，並可補一句 **TBD 分析：……**（把「為什麼放這張圖」講出來）。
- 全文的「圖 X」連號一致，不要跳號、不要兩張都叫圖 1。

## 來源標示格式

文末「參考資料」與內文首次描述事件時都要標源。統一格式：

- **新聞**：`來源：媒體名稱｜〈文章標題〉｜發布日期（如有）｜網址`
- **社群**：`來源：官方 Facebook／Instagram／YouTube 貼文（附連結）`

規則：

1. 事件事實才需要標源；TBD 的方法分析是原創觀點，不必標源。
2. **第一次**完整描述事件時標源即可，不必每段重複同一則新聞。
3. 具體事實（屆數、時間、外貌、交叉比對等）要能對應到來源。
4. **相同轉載不算兩個獨立證據**：例如同一篇稿被 Yahoo 與 Cava 轉載，只能算一個來源，
   另一個標註「與 X 為相同轉載，僅作為另一個新聞入口，非獨立佐證」。
5. 沒有把握是原話就用**轉述**（「相關報導整理，……」），不要自行加直接引號。
6. 不虛構日期、頁數、時數；抓不到可靠日期就照實省略（日期是「如有」）。

## 影片引用

優先序：**嵌入官方影片 > 連結官方影片 > 少量關鍵截圖 > 不要重製**。

- 即使是官方 Reel，也仍受版權保護；**「有標來源」不等於可以自由使用**。
- 禁止：下載整支影片、重新上傳、用大量連續截圖重建整支內容。
- 本站沒有影片嵌入元件時，就用**連結**官方貼文（`<a target="_blank" rel="noopener">`），
  正文以自己的評論／轉譯為主。

## 合理使用（fair use）自我檢查

發布前逐項確認（多項為否就要重調）：

- [ ] 是以評論、分析為目的，不是搬運？
- [ ] 只用了必要的最少素材？
- [ ] 原創內容遠多於引用內容？
- [ ] 每則引用都標了來源？
- [ ] 沒有取代原作品的市場（不是讓人「看這篇就不用看原片／原新聞」）？

合理使用是個案判斷，本規則是降低風險的下限，不是保證。

## SEO

每張原創圖：描述性用途、與內文互相呼應、有 caption。CSS 圖示雖非 `<img>` 無 alt，
但 figcaption 就是它的文字語意，要寫得能單獨讀懂。避免純裝飾、與內文無關的圖。

- [ ] 每則引用有來源；相同轉載沒被當成多個證據
- [ ] 沒有轉載未授權的新聞／Reel 圖或影片
