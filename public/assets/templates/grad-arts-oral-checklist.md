# 口試作品答辯檢核表（藝術研究所）

> 藝術研究所口試不是面試的加強版，也不是朗讀作品說明，而是一場針對作品、創作選擇與未來計畫的學術對話。先用第一節逐題寫出答案再練口說，第二節套答題框架，第三節準備簡報，第四節做上場前檢核。
>

> **用 Google Docs / Sheets**：表格可直接貼上。

## 一、四類追問題庫

先寫答案，再練口說。寫不出來的題目，就是你目前最大的風險。

### 作品與母題

| 題目 | 我的答案 |
|---|---|
| 為什麼持續處理這個主題？ |  |
| 這個母題是怎麼形成的？ |  |
| 不同系列之間有什麼關係？ |  |
| 哪一件作品最能代表你？為什麼？ |  |

### 媒材與形式

| 題目 | 我的答案 |
|---|---|
| 為什麼使用這個媒材？ |  |
| 為什麼採取這種展示方式？ |  |
| 如果改用其他媒材會發生什麼？ |  |
| 技術選擇如何服務概念？ |  |

### 藝術脈絡

| 題目 | 我的答案 |
|---|---|
| 你受哪些藝術家影響？ |  |
| 作品和哪些藝術史脈絡有關？ |  |
| 你怎麼區別借鑑與模仿？ |  |
| 你的創作與當代議題有什麼關係？ |  |

### 研究計畫

| 題目 | 我的答案 |
|---|---|
| 進研究所後具體想做什麼？ |  |
| 為什麼需要這個系所？ |  |
| 計畫如何延續過去的作品？ |  |
| 如果作品發展不如預期怎麼辦？ |  |

> 最後一題最常被跳過、現場卻常被問到。承認計畫可能不成立、並說得出替代路徑，比堅稱一定做得到更有說服力。

## 二、五步答題框架

> **說明作品 → 指出選擇 → 補充脈絡 → 承認限制 → 提出下一步**

句型：

> 這件作品用的是＿＿，因為它能呈現＿＿，這是我試過的其他材料做不到的。這個處理方式接近＿＿的做法，但我把重點放在＿＿。目前的限制是＿＿，所以下一階段我會透過＿＿來測試。

| 步驟 | 我的代表作 1 | 我的代表作 2 | 我的代表作 3 |
|---|---|---|---|
| 說明作品 |  |  |  |
| 指出選擇 |  |  |  |
| 補充脈絡 |  |  |  |
| 承認限制 |  |  |  |
| 提出下一步 |  |  |  |

> 第四步是關鍵。主動指出限制不會顯得沒把握，反而顯示你對作品有判斷——那些問題教授本來就看得出來，你先講就變成你在主導對話。

## 三、一分鐘創作主張

練到能在一分鐘內講完，而且不需要看稿。

| 段落 | 秒數 | 我的內容 |
|---|---|---|
| 我持續在處理的問題 | 0–15 |  |
| 這個問題長成什麼作品（一到兩件） | 15–35 |  |
| 為什麼是這個媒材與形式 | 35–50 |  |
| 接下來想深化什麼 | 50–60 |  |

## 四、作品簡報設計

- [ ] 開場三十秒說清楚母題（不要從「我從小就喜歡畫畫」開始）
- [ ] 只選三到五件，講深不講多
- [ ] 每件只講一個重點（在系列裡負責什麼、或解決了什麼問題）
- [ ] 刻意留下可以被問的空間
- [ ] 結尾自然接到創作計畫
- [ ] 準備一分鐘與三分鐘兩個版本
- [ ] 至少對著一個不熟悉我創作的人講過一次

## 五、面對不同意見的五個步驟

| 步驟 | 做什麼 | 我的句型 |
|---|---|---|
| 1 | 先確認問題（把模糊的批評問成具體問題） |  |
| 2 | 說明原本的選擇（讓對方知道那是判斷） |  |
| 3 | 接受合理的質疑（對的部分直接承認） |  |
| 4 | 指出目前的限制（技術／時間／預算／經驗） |  |
| 5 | 提出可能的修正方向 |  |

> 兩種要避免的反應：**全盤退讓**（等於承認你對自己的作品沒有判斷）、**逐條反駁**（顯示你不能接受批評）。研究所兩年會有大量評圖，教授就是在測試這一點。

## 六、上場前檢核

- [ ] 能在一分鐘內說明自己的創作母題
- [ ] 能說明每件代表作的媒材與形式選擇理由
- [ ] 能指出相關藝術家與脈絡，並說明自己與他們的差別
- [ ] 已預想三個反對意見並準備回應
- [ ] 能說明進研究所後的具體發展，包括計畫不如預期時的替代路徑
- [ ] 作品簡報有一分鐘與三分鐘兩個版本
- [ ] 送件後的新作準備了一到兩張圖，能接回既有脈絡
- [ ] 若要帶實體作品或材料樣本，已確認現場條件並想好為什麼帶它
