# 研究計畫可行性檢核表（生醫與公衛研究所）

> 有說服力的研究計畫，不是文獻讀得多，而是能定義有意義的問題、提出可執行方法、辨識限制與風險並提出備援。這份表把十節架構與生醫／公衛的檢核點放在一起，寫完自己先驗收一遍。
>

## 十節架構與檢核

| 節次 | 要回答的問題 | 你的重點 | 檢核 |
|---|---|---|---|
| 1 研究背景 | 這個領域現在的狀況？ |  |  |
| 2 問題意識 | 你要解決什麼具體問題？ |  |  |
| 3 研究目的／假設 | 目的或假設是否明確、可驗證？ |  |  |
| 4 文獻缺口 | 既有研究還沒回答什麼？ |  |  |
| 5 研究方法 | 實驗或調查如何執行？有無對照？ |  |  |
| 6 統計與資料分析 | 用什麼方法回答研究問題？ |  |  |
| 7 預期結果 | 預期看到什麼、代表什麼？ |  |  |
| 8 限制與備援 | 有哪些風險？備援方案是什麼？ |  |  |
| 9 與目標實驗室的連結 | 為何這個實驗室做得成？ |  |  |
| 10 自身已有能力 | 你具備哪些技術支撐這個計畫？ |  |  |

## 生醫研究計畫檢核

- [ ] 聚焦特定分子機轉或明確生物問題，而非泛談
- [ ] 實驗設計有正、負對照組
- [ ] 說明樣本、細胞、動物或檢體來源
- [ ] 有替代實驗方案
- [ ] 時程能在碩士階段完成
- [ ] 已考量 IRB／IACUC／生物安全規範
- [ ] 具備所需設備與技術（或能在目標實驗室取得）

## 公衛研究計畫檢核

- [ ] 研究問題具體、可回答
- [ ] 母群體與樣本來源合理
- [ ] 變項操作化清楚
- [ ] 統計方法能回答研究問題
- [ ] 已考量偏差、混淆與資料缺失
- [ ] 能取得足夠樣本
- [ ] 符合研究倫理與隱私規範

## 送出前三問

- [ ] 計畫是否聚焦一個明確且可驗證的問題？
- [ ] 方法是否包含對照、統計分析與可替代方案？
- [ ] 計畫能在碩士時程內完成，而非理想化的大型研究？
