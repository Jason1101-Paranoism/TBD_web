# 校所與教授比較表（設計研究所）

> 設計研究所最大的選擇不是排名，是**你要走學術／研究型還是實務／創作型**——同樣叫設計碩士，畢業要交論文還是創作加論述，訓練完全不同。這張表把型態、師資、課程導向、資源與作品集要求放在一起看，選錯方向的風險最小。

## 陷阱檢核

- [ ] 已先決定學術型或實務型，不是準備完材料才回頭決定
- [ ] 沒有因為非設計背景就自我排除，已確認該所的補修機制
- [ ] 沒有把系所名聲當成職涯結果
- [ ] 教授的教學風格已從同儕評價或公開課程判斷過，不只看作品
- [ ] 已確認教授的名額、是否休假或即將退休
- [ ] 比較過同名系所在型態、畢業要求與設備上的差異

## 填完後檢核

- [ ] 已寫下自己的次領域、型態與想解決的問題並用來對照系所
- [ ] 該所的畢業要求（論文／創作＋論述）和我選的型態一致
- [ ] 需要的設備與工作坊確認可用、排得到且負擔得起
- [ ] 看過該所近年碩論或創作論述，以及新一代與金點新秀的產出
- [ ] shortlist 是 3-5 所且有衝刺／把握／保底的分層
- [ ] 名單中保留一所在型態與設備上明確可行的底線選項

> 寧可少而深——作品集客製化的品質不會被稀釋

## 查證管道

| 查證管道 | 說明 |
|---|---|
| 臺灣博碩士論文知識加值系統 | 查近年碩論與創作論述，看該所實際做得出什麼 |
| 新一代設計展線上展 | 依系所索引，看該所學生的實際產出 |
| 金點新秀設計獎歷屆入圍 | 依學校整理，判斷該所的水準與取向 |
| 系所公開課程與課程地圖 | 判斷課程導向是研究方法必修還是創作實作為主 |
| 當年度招生簡章 | 作品集件數格式與評分配比，每年會變 |
| 現任學生與學長姐 | 教學風格、設備排隊時間、產學專案的實際比重 |

> 查法提示：型態與畢業要求看**系所官網的修業規定與課程地圖**——要交創作展加論述還是研究論文，這一項就決定了你整份申請的重心。作品集的格式與份量要求看**當年度招生簡章**，多數設計所權重很高、有些是第一關門檻。教授方向看個人網站、近年發表或展覽、指導過的論文與創作。

> 兩個外部驗證管道比官網更誠實：[臺灣博碩士論文知識加值系統](https://ndltd.ncl.edu.tw/) 可依校所檢索近年碩論與創作論述——學術型有明確的研究方法與文獻回顧，實務型多是設計專案的論述與反思，一比就知道這裡把學生訓練成什麼樣子；[新一代設計展](https://www.yodex.com.tw/)線上展區與[金點新秀設計獎](https://goldenpin.org.tw/)歷年入圍名單都以校系分類，直接看得到完成度與題目取向。
