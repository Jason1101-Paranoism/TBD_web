# 聯繫教授信結構模板（農生與環境研究所）

> 這個類群的套磁信，只寫「我對您的研究很有興趣」幾乎沒有作用。教授在意的是三件事：**你能不能快速進入研究、你會不會誠實面對數據、你撐不撐得住長期執行**。這份表把信拆成可填的段落，並先幫你判斷該不該寄。
>
> **匯入 Notion**：Import → Markdown 後，下表會變成 Notion 表格。
> **用 Google Docs / Sheets**：表格可直接貼上。

## 先判斷：這封信該不該寄

兩組條件都成立才寄。任一組不成立，先補資料再說。

| 條件 | 是否成立 |
|---|---|
| 我讀過這位教授近三年的論文（不是只看研究方向那一段） | - [ ] |
| 我說得出他現在用的技術與材料 | - [ ] |
| 我的技術或經驗，和他的方法有實際交集 | - [ ] |
| 我有一個具體的問題或方向可以談，不只是「想加入」 | - [ ] |
| 我確認過他明年可能收生（或這封信就是要問這件事） | - [ ] |
| 這封信的內容換一位教授就不成立 | - [ ] |

> 最後一項是最有效的自我檢查。如果把教授名字換掉，信還讀得通，那就是群發罐頭信。

## 寄信時機

農生環境有一個別的學群較少見的時間因素：**教授要先知道明年有沒有經費與生物材料的量能，才能決定收幾個學生**。

| 時期 | 適合做什麼 |
|---|---|
| 7–9 月 | 黃金期。詢問明年度招生名額與指導量能，同時談研究方向 |
| 10–11 月 | 送件期。信要更短、更聚焦，直接附上研究計畫與 CV |
| 3–6 月（大三下） | 太早問名額，但適合表達興趣、詢問能否旁聽 meeting 或短期參與 |

## 七段信件結構

| 段落 | 要寫什麼 | 我的內容 |
|---|---|---|
| 1 簡短自我介紹 | 學校、系級、一句話定位 |  |
| 2 目前研究與專題背景 | 在哪個實驗室、做什麼題目、到什麼程度 |  |
| 3 具體技術與時數 | 能獨立操作的技術、田調時數、統計工具 |  |
| 4 代表成果 | 數據、圖表、報告、海報或競賽 |  |
| 5 與教授近期研究的連結 | 讀了哪篇、看到什麼接點、我能加入哪一塊 |  |
| 6 詢問明年度招生與方向 | 名額、指導量能、是否有適合的子題 |  |
| 7 附件說明 | CV、成果摘要、研究計畫（依情況） |  |

## 第 3 段怎麼寫得具體

這是農生環境最能拉開差距的一段。比較兩種寫法：

**沒有作用的寫法**

> 我有豐富的實驗經驗與田野調查經驗。

**可用的寫法**

> 我在○○實驗室完成專題，能獨立操作植物組織培養（繼代 40 次以上）與 qPCR（設計並驗證 6 組引子）；另在△△溪流域參與 12 次樣區調查、現地工作累計約 100 小時，負責樣點設置與水質量測；資料以 R 完成變異數分析。

差別在**具體項目、量、產出**三個東西。教授看得出哪一種是真的做過。

## 寄信前檢核

- [ ] 信裡點出了至少兩項我能獨立操作的具體技術，含量或時數
- [ ] 我讀過並在信中引用了他近三年的論文（不是十年前的代表作）
- [ ] 我提出的方向，能用他實驗室現有的技術與材料做出來
- [ ] 我沒有承諾自己做不到的技術
- [ ] 主旨具體（含學校系級與來意），不是「研究所諮詢」
- [ ] 信長度控制在螢幕一頁內，細節放附件
- [ ] 附件檔名有我的名字與日期
- [ ] 我確認過稱謂、姓名與系所沒有寫錯（換教授時最容易出錯的地方）
- [ ] 把教授名字換掉之後，這封信就不成立
